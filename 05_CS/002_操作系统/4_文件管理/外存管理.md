# 1. 空闲表法
属于文件连续分配方式, 分配与回收类似[[动态分区算法]]
再为外存的空闲区域建立一张空闲表
# 2. 空闲链表法: 
将所有的空闲盘/区拉成一条空闲链条, 根据构成链条的元素,
分成空闲盘块链和空闲盘区链
- 盘块链
	分配回收过程简单
	效率低
- 盘区链
	效率高
	分配复杂
# 3. 位示图法: 
也在外存中, 需要调入内存
字号位号(行号列号)
- 容易找到一个或一组空闲盘块; 占用空间少
- 随着容量增加而增大, 常用于小型计算机
# 4. 成组链接表:
[[UNIX]]常用, 使用了空闲盘块[[03_栈队列和数组|栈]]的思想
- 内存中的空闲盘块号栈存放了本栈中外存空闲盘块的数量
- 栈底记录的是下一个这样的一组数据所在的盘块号
- 栈底如果是0, 就是空闲盘块链的结束标志
- 栈中除了栈底记录的是空闲盘块号栈, 其他记录的都是空闲盘块
- 栈是临界资源, 需要互斥访问
- 分配盘块时
	从栈顶取出空闲盘块号分给用户, 然后栈顶指针向下一位, 记录的空闲数-1
	若已经到了栈底, 就把记录的下一个空闲盘块号所在的块复制进内存,
	并把原栈底对应盘块分配出去
- 回收同理, 若栈满则存入盘块, 再找新盘块作为栈底
最开始的时候容易找到连续的空闲块, 但是随着回收和分配的交替进行, 会打破连续性
