# 4. 文件共享

## 硬链接
基于[[文件目录|索引结点]]的共享方式, 一种文件目录的瘦身策略
共享只需要同时指向同一个索引结点即可, 但是有自己各自的系统[[文件系统|文件打开表]]
## 软链接
基于符号链的共享方式, 创建了一个新的 `link` 型文件, count 值为1
链接文件是一种特殊的文件, 保存了目标文件的存放地址
类“快捷方式”, 有自己独立的索引结点

# 5. 文件保护

## 口令保护
- 时间空间开销小
- 口令明文保存在系统中, 不安全
## 加密保护
- 使用密码来进行[异或]运算得到原文件
- 保密性强, 但是加密解密需要花费一定时间
## 访问控制
- 在 [[文件目录|FCB]] 中 增加一个访问控制列表 `ACL`, 记录了各个用户对该文件的权限 `rwx`
- 精简访问控制表: 以组为单位, 标记各个用户可以对文件执行哪些操作

# 6. [[文件系统]]
1. 物理格式化
即低级格式化: 划分扇区, 检测坏扇区, 并用备用扇区替换坏扇区

2. 逻辑格式化
[[磁盘管理]], 完成各分区的文件系统格式化
1. [[BIOS|MBR]]: 位于磁盘的0号扇区, 用来引导计算机
	MBR 后面紧跟着分区表, 给出每个分区的起始地址和结束地址
	表中的第一个分区就是活动分区, 活动分区的第一块即引导块 [[BIOS|PBR]] 
	
2. 引导块: 启动该分区上 OS 的引导代码
	
3. 超级块: 描述文件系统全局元信息
	文件类型、块大小、总块数、空闲块数
	总 inode 数、根目录 inode 号等
	
4. 空闲空间管理: 比如位示图
	
5. [[文件目录|索引结点]]区/i结点: 连续存放, 数组元素是索引结点, 支持随机存储
	
6. 根目录
- 目录的缓存: 加快目录检索顺序
- 系统打开文件表: 只有一张
- 用户/进程打开文件表: 每个进程一张, 存在 [[PCB]] 中

## 文件系统挂载与虚拟文件系统
1. 在 VFS 中注册新挂载的文件系统, 内存中的挂载表包含每个文件系统的相关信息
2. 新挂载的文件列表, 要向 VFS 提供一个函数地址列表, 对应VFS中的函数调用指针表项
3. 将新文件系统加到挂载点(父目录)中
