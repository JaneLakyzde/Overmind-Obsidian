# 进程调度
- 进程调度是CPU在内核态下完成的
- 进程调度基于[[中断的分类|中断]]机制
- 调度器 = 调度程序

### 非抢占调度方式
1. 正在执行进程执行完毕或无法继续执行
2. 正在执行的进程因提出IO请求而暂停执行
3. 进程通信或同步过程中执行了某种原语操作

### 抢占调度方式
1. 优先级高可抢占助理机
2. 短进程优先原则
3. 时间片原则

## 调度时机
- 主动放弃
	运行完毕, 正常终止
	运行过程中发生异常
	发生事件, 请求阻塞
- 被动放弃
	进程时间片用完
	有更高优先级进程进入就绪序列
	有更紧急的事件需要处理
- 不可切换
	处理中断时, 不能切换到另一个正常进程/线程
	进程处于内核临界区时(内核态不能被切换到用户态)
	执行原子操作时

# 调度目标
- CPU利用率
- 系统吞吐量
- 周转时间
- 带权周转时间
- 平均周转时间
- 平均带权周转时间
- 等待时间
- 响应时间

# 调度算法
1. 先来先服务 FCFS
	只能是非抢占式
	对长作业有利, 对短作业不利
	有利于 CPU 繁忙型, 不利于IO繁忙型
	
2. 短作业优先 SJF
	默认非抢占式, 如果是抢占式, 剩余时间为衡量标准
	作业越短, 优先级越高, 越先被调度
	平均等待时间和平均周转时间最优
	短作业有利, 长作业不利甚至饥饿
	时间相等时, 按照先后顺序来服务
	
3. 高响应比优先
	响应比 = 等待时间 / 服务时间
	每次调度选择响应度占比最高的作业投入运行
	克服了长作业饥饿问题
