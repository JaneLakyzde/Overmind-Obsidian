# 1. IO设备的概念和分类

1. 什么是IO设备
	输入/输出的计算机外部设备
	
2. 按使用特性分类
	人机交互的外部设备
	存储设备
	网络通信设备
	
3. 按传输速率分类
	低速设备、中速设备、高速设备
	
4. 按信息交换的单位分类
	块设备: 可寻址, 共享设备
	字符设备: 常用[中断驱动方式]

# 2. [[IO接口|IO控制器]]

1. 机械部件：鼠标等
2. 电子部件: 
	控制寄存器: 接受和识别CPU发出的命令
	状态寄存器: 向CPU报告设备的状态
	数据寄存器: 数据交换
	IO逻辑部件: 地址识别
3. 内存映射IO vs 寄存器独立编制

组成: CPU与控制器接口 + IO逻辑 + 控制器与设备的接口


# 3. [[IO控制方式]]

1、程序直接控制方式
轮询：完成一次读/写操作的流程
CPU干预频繁
每次读写一个字
实现简单
会使CPU忙等

2、中断驱动方式
让cpu发出io指令后做其它的事情
大量中断会使cpu效率低
每次读写一个字
cpu和io可并行工作

3、[[DMA]]方式：直接存储器存取
数据单位：连续的多个块
直接从设备到内存
减少了cpu干预
DR：数据寄存器
MAR：内存地址寄存器
DC：剩余读写字节数
CR：命令/状态寄存器

4、通道控制方式
弱鸡版cpu
通道程序：任务清单
cpu发送命令给通道，然后让通道处理IO操作就行了
处理完了，向cpu发送中断信号

# 4. IO软件层次结构

## 用户层软件
- 实现与用户交互的接口，向上提供方便易用的[库函数]
	
## 设备独立性软件
- 向上层提供统一的[[系统调用]]接口 `read/write` 
	设备保护, 类似文件保护
	差错处理
	设备的分配与回收
	数据缓冲区管理: 屏蔽各个不同设备之间的速率差异
	逻辑设备表 `LUT` 建立逻辑设备名到物理设备名[绝对号]的映射关系
	根据设备类型选择调用相应的驱动程序
- 它的目标是：**让上层看到统一的“设备”，而不是各种五花八门的硬件。**
## 设备驱动程序
- 写设备寄存器、检查设备状态
	操作设备寄存器
	配置 DMA
	维护命令队列
	处理设备状态
	提供注册中断处理程序
	实现设备无关软件要求的具体操作
	磁盘调度
- 它向上提供标准入口，向下控制具体设备。  
	换硬件时，通常只改驱动，不改设备无关软件和用户程序
	
## 中断处理程序
- 进行[[中断处理|中断]]处理, 只做最紧急的事
	中断处理程序负责“系统怎么响应中断”
	设备驱动程序负责“这个设备的中断具体怎么处理”
## 硬件
- 执行IO操作，有机械部件、电子部件组成

	输入进程和输出进程 - 外围控制机
	输入缓冲区和输出缓冲区
- 具体打印过程:
	1. 在[磁盘]输出井中为进程申请一个空闲缓冲区
	2. 为用户进程申请一张打印请求表存放相关信息
	3. 加入打印请求队列

## [[缓冲区管理]]

1. 什么时缓冲区？有什么作用？
	缓冲区是一个存储区域
	缓和CPU与IO设备之间速度不匹配的矛盾
	减少对CPU的中断频率
	解决数据粒度不匹配的问题
	提高CPU与IO设备之间的并行性
	
2. 单缓冲
	在内存中分配一块缓冲区
	处理一块时间=max（C,T)+M
	
3. 双缓冲
	在内存中分配两块缓冲区
	max(T,C+M)
	
4. 循环缓冲
	
5. 缓冲池
	由系统中共用的缓冲区组成。这些缓冲区可以分为：
	空缓冲队列、装满输入数据的缓冲队列、装满输出数据的缓冲队列

# 7. IO 请求具体流程
```
1. 用户程序           ← 调用 read(fd, ...)   
	↓ trap
2. 系统调用处理程序   ← 切到内核态、参数校验、分发到具体设备   
	↓
3. 设备驱动程序       ← 把通用请求翻译成磁盘控制器命令、启动 I/O   
	↓ 等待   
	（硬件传输数据）   
	↑ 完成
4. 中断处理程序       ← 响应磁盘"传输完毕"中断、唤醒等数据的进程   
	↑ 驱动收尾   
	↑ 数据返回用户进程
```
