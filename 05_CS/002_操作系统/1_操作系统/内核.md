# 资源管理
进程管理
存储管理
文件管理


系统调用发起处于用户态, 系统调用处理程序执行处于内核态
中断发生是外部设备产生中断请求, 外中断处理程序属于内核代码
时钟中断 进入内核态 进行进程调度 切换进程
上下文切换修改相关进程控制信息, 属于内核态
进程创建 / 终止 / 阻塞 / 唤醒 全都是内核态
缺页异常的处理在内核态执行
操作系统内核负责完成页面置换
页表的建立、修改、维护由操作系统完成，在内核态进行
设备驱动程序属于操作系统内核，在内核态执行
I/O 中断 → 中断处理程序 → 唤醒进程 → 调度
涉及 OS 管理的共享资源时，属于内核操作
系统调用可以导致进程阻塞和进程切换, 阻塞、调度、切换发生在内核

`malloc()` 本身是**用户态库函数**。
