# 中断的分类

| 类型          | 子类            | 触发原因     | 是否与当前指令相关 | 能否返回     | 典型例子        |
| ----------- | ------------- | -------- | --------- | -------- | ----------- |
| **外中断**     | 可屏蔽中断         | I/O 设备完成 | ❌ 无关      | ✅        | 键盘输入、磁盘 I/O |
|             | 不可屏蔽中断（NMI）   | 严重硬件故障   | ❌ 无关      | ✅（但可能关机） | 电源故障、内存错误   |
| **内中断（异常）** | **Trap（陷阱）**  | 程序主动请求   | ✅ 相关      | ✅（下一条指令） | **系统调用**、断点 |
|             | **Fault（故障）** | 可恢复错误    | ✅ 相关      | ✅（当前指令）  | **缺页中断**、除零 |
|             | **Abort（终止）** | 严重不可恢复错误 | ✅ 相关      | ❌        | 硬件故障        |
# 异常与中断 

## 核心区别 

- **异常 (Exception):** 一般是在**指令执行时**发现的（由 CPU 内部产生，如缺页、除零、非法操作码）。
- **中断 (Interrupt):** 中断请求信号一般是在**一条指令执行结束后**发现的（由 CPU 外部设备产生，如 I/O 完成）。
    

## 1. 异常的分类 内中断

- **(1) 故障 Fault:**
- 
    - **断点:** 发生故障的当前指令。
        
    - **特性:** 可以被处理并返回。返回后**重新执行**引起故障的那条指令（例如：缺页故障，调页后重新执行该指令）。
        
- **(2) 自陷 Trap:**
    
    - **断点:** 自陷指令的下一条指令。
        
    - **特性:** 程序员主动引发（如系统调用 `syscall`、断点调试）。返回到自陷指令的**下一条指令**执行。注：当自陷指令是转移指令时，返回到转移目标指令执行。
    - 自陷指令 = 访管中断 (访问操作系统内核态)
        
- **(3) 终止 Abort:**
    
    - **断点:** 无法确定或无意义。
        
    - **特性:** 严重的致命硬件故障（如内存奇偶校验错）。无法继续执行，直接调出操作系统内核的终止处理程序，重启或宕机。
        

## 2. 中断的分类 外中断

- **可屏蔽中断 (INTR):** 受 CPU 内部 `IF` (中断允许标志) 控制。打印机、键盘等普通外设的请求。
    
- **不可屏蔽中断 (NMI):** 不受 `IF` 标志限制，极其紧急的事件（如电源掉电）。
    
- 外中断的断点一般都是下一条指令的地址

# 易错点

| 误区                   | 正确理解                                             |
| -------------------- | ------------------------------------------------ |
| “系统调用是外中断”           | ❌ 系统调用是 **trap（内中断）**，由 `int` 或 `syscall` 指令主动触发 |
| “缺页中断是外中断”           | ❌ 缺页是 **fault（内中断）**，由 MMU 检测到页表项无效引发            |
| “[[时钟信号\|时钟]]中断是内中断” | ❌ 时钟中断是 **外中断**（由硬件时钟芯片发出）                       |
| “所有中断都来自外部”          | ❌ 内中断（异常）来自 CPU 内部执行过程                           |
配有[[通道]]的计算机系统中, 引起的中断是访管中断
