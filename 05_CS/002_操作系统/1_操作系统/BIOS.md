# 定义

- 全称：Basic Input/Output System
- 它是一组固化在主板上一个 [[主存储器|ROM]] 芯片内的软件程序。
	BIOS-ROM 属于[[主存储器]]
	需要区分自举程序`bootstrap`和操作系统引导程序`启动管理器`
	自举程序负责自检硬件, 按顺序找到可启动设备, 把该设备的**第一个扇区**放入内存, 交出控制权
	操作系统引导程序每个 OS 不同, 把内核从[[外存储器|磁盘]]装入内存并启动, 在硬盘不在BIOS中

# 引导过程

1. **激活 CPU**
	CPU 加电, 执行 `JMP` 指令跳转到 BIOS
	CPU 读取 ROM 中的 boot 程序, 将 PC 置为 BIOS 的第一条指令开始执行
	
2. **自检程序与初始化** 
	BIOS 在内存最开始的空间构建[[中断处理|中断向量表]]
	执行 POST 自检程序(会用到中断功能)检查硬件是否有问题
	BIOS 内置了一些最基础的硬件驱动程序（如键盘输入、屏幕显示、磁盘读写）
	
4. **主引导记录 MBR** 
	`Master Boot Record` 
	BIOS 根据 CMOS 中设定的启动顺序, 调 BIOS 中断服务读取找到可启动磁盘的第一个扇区到内存, 读取主引导记录 MBR `master boot record` 
	`MBR =446B 代码 + 硬盘分区表` 
	
5. 扫描硬盘分区表
	MBR 硬盘分区表中记录各个分区的起始位置, 并标记系统分区/活动分区
	找到活动分区的第一个扇区存放分区引导程序 PBR ,
	
6. **加载分区引导记录 PBR**
	`Partition/Volume Boot Record` 
	读取活动分区的第一个扇区, 这个扇区称为分区引导记录,
	作用是寻找并激活分区根目录下用于引导操作系统的程序(内核映像文件)装入并跳转
	
7. 加载启动管理器
8. 加载操作系统

CPU 找到ROM 中的BIOS 
BIOS 找到启动磁盘的第一个扇区中的 MBR
MBR 找到活动分区中第一个扇区的 PBR
PBR 找到分区根目录中的启动管理器

# UEFI
统一可扩展固件接口：
不像 legacy 无法保存硬件的内存分布信息,
UEFI 可以不自检, 直接进行初始化, 并行启动

| **特性**       | **Legacy BIOS**       | **现代 UEFI**                       |
| ------------ | --------------------- | --------------------------------- |
| **CPU 运行模式** | 16 位实模式（性能极低）         | **32 位或 64 位保护模式**（性能更强）          |
| **硬盘分区表**    | 仅支持 **MBR**（最大 2.2TB） | 支持 **GPT**（理论支持 9.4ZB）            |
| **启动流程**     | 必须顺序扫描硬件              | **支持硬件并行初始化**                     |
| **安全性**      | 基本没有安全验证              | 支持 **Secure Boot**（安全启动），防止木马植入底层 |
