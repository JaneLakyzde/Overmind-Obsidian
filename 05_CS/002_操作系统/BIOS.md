# 定义

- **全称**：**B**asic **I**nput/**O**utput **S**ystem（**基本输入输出系统**）。
- **本质**：它是一组固化在主板上一个 [[主存储器|ROM]] 芯片内的**软件程序**。BIOS-ROM 属于[[主存储器]]
    
# 具体

1. 自检程序 
	开机通电后, 首先执行 BIOS 里的 POST 自检程序, 检查硬件是否有问题
	
2. 硬件中断调用 
	BIOS 内置了一些最基础的硬件驱动程序（如键盘输入、屏幕显示、磁盘读写）。在操作系统完全接管电脑之前，电脑能认出你的键盘和显示器，全靠这些代码。

 3. 引导驱动程序 
	自检通过后，BIOS 会去寻找带有操作系统的硬盘（或者 U 盘），找到其主引导记录 MBR (master boot record)，然后启动**磁盘引导程序**。

4. MBR
	446B 代码 + 硬盘分区表
	硬盘分区表中记录各个分区的起始位置, 并标记系统分区
	可以有多个系统分区
	系统盘的第一个扇区存放**分区引导程序**, 可以引导该分区的**操作系统引导程序**, 启动操作系统

# UEFI
统一可扩展固件接口：
不像 legacy 无法保存硬件的内存分布信息,
UEFI 可以不自检, 直接进行初始化, 并行启动

| **特性**       | **Legacy BIOS**       | **现代 UEFI**                       |
| ------------ | --------------------- | --------------------------------- |
| **CPU 运行模式** | 16 位实模式（性能极低）         | **32 位或 64 位保护模式**（性能更强）          |
| **硬盘分区表**    | 仅支持 **MBR**（最大 2.2TB） | 支持 **GPT**（理论支持 9.4ZB）            |
| **启动流程**     | 必须顺序扫描硬件              | **支持硬件并行初始化**                     |
| **安全性**      | 基本没有安全验证              | 支持 **Secure Boot**（安全启动），防止木马植入底层 |
