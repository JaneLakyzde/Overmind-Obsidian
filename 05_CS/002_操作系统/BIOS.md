# 定义

- **全称**：**B**asic **I**nput/**O**utput **S**ystem（**基本输入输出系统**）。
- **本质**：它是一组固化在主板上一个 ROM 芯片内的**软件程序**。BIOS-ROM 属于主存
    
# 具体

1. 自检程序 
	当你按下开机键，电源开始供电。CPU 第一个执行的就是 BIOS 里的 POST 程序。它会去检查：CPU 正常吗？内存条插好了吗？显卡在不在？如果内存条坏了，主板发出的“滴滴”报警声就是 POST 程序触发的。

2. 硬件中断调用 
	BIOS 内置了一些最基础的硬件驱动程序（如键盘输入、屏幕显示、磁盘读写）。在操作系统完全接管电脑之前，电脑能认出你的键盘和显示器，全靠这些代码。

 3. 引导驱动程序 
	这是 BIOS 的“终极使命”。自检通过后，BIOS 会去寻找带有操作系统的硬盘（或者 U 盘），找到其主引导记录（MBR），然后把控制权交给操作系统的引导程序。

# UEFI
统一可扩展固件接口：

| **特性**       | **传统 BIOS**           | **现代 UEFI**                       |
| ------------ | --------------------- | --------------------------------- |
| **CPU 运行模式** | 16 位实模式（性能极低）         | **32 位或 64 位保护模式**（性能更强）          |
| **硬盘分区表**    | 仅支持 **MBR**（最大 2.2TB） | 支持 **GPT**（理论支持 9.4ZB）            |
| **启动流程**     | 必须按顺序扫描硬件，速度慢         | **支持硬件并行初始化**，启动速度极快              |
| **安全性**      | 基本没有安全验证              | 支持 **Secure Boot**（安全启动），防止木马植入底层 |
