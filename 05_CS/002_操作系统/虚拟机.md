- **VMM**：**Virtual Machine Monitor**，中文常译作**虚拟机监视器**，也叫 **Hypervisor**。  
    在操作系统虚拟化部分，VMM 负责创建、管理和调度虚拟机。
	特权级严格高于 Guest OS
	可模拟多种 ISA
    
- **ISA**：**Instruction Set Architecture**，中文常译作**指令集体系结构**或**指令集架构**。

# 第一类 VMM
- 直接运行在硬件上, 效率高
- 运行在内核态
- 客户OS 以为自己运行在内核态, 实际上是虚拟化内核态, 通过 VMM 执行相关操作

# 第二类 VMM
- 运行在操作系统之上的虚拟机, 例: VMware
- 运行在二类虚拟机管理程序上的操作系统叫作客户操作系统
	运行再底层硬件之上的叫底层操作系统
