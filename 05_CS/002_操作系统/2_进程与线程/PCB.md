进程实体 = 代码块 + 相关数据 + PCB

# PCB的主要内容

| 进程管理信息         | 存储管理信息    | 文件管理信息               |     |
| -------------- | --------- | -------------------- | --- |
| 进程 ID          | 页表/段表基址   | [[文件系统\|打开文件表]] |     |
| 进程状态           | 基地址和限长寄存器 | 当前工作目录               |     |
| 寄存器状态（如 PC、SP） |           | I/O 设备状态             |     |
| 进程优先级          |           |                      |     |
| 父进程 ID         |           |                      |     |
| 子进程信息          |           |                      |     |
| CPU 使用时间       |           |                      |     |

## 进程标识符
- 外部标识符: 字母 + 数字, 面向用户
- 内部标识符: 纯数字, 面向操作系统

## 处理机状态/[[寄存器]]
- 通用寄存器
- PC
- PSW
- 堆栈指针寄存器SP: 指向用户栈和内核栈的指针

## 进程调度信息
- 进程状态: 阻塞/就绪/运行
- 进程优先级
- 事件: 阻塞的原因
- 其他信息

## 进程控制信息
- 程序和数据的地址
	[[页表]]的起始地址
- 进程同步和通信机制: 消息队列指针, 信号量
- 资源清单: 运行期间所需要的全部资源(CPU除外)
- 连接指针: 所在队列中下一个进程的PCB起始地址

# TCB

| 线程管理信息<br>（独有执行上下文）                | 存储管理信息<br>（共享资源）     | 文件管理信息<br>(共享资源） |
| ---------------------------------- | -------------------- | ---------------- |
| **线程 ID (TID)**                    | 所属进程的**页表/段表基址**<br> | 指向所属进程的文件打开表，共享  |
| **线程状态**（运行/就绪/阻塞）                 | 共享所属进程的虚拟地址空间布局      | 共享所属进程的当前工作目录    |
| **寄存器状态**<br>PC、SP、通用寄存器           |                      | 共享所属进程的 I/O 设备状态 |
| **线程优先级**<br>若支持线程级调度              |                      |                  |
| **所属进程 ID (PID)** <br>指向所属 PCB 的指针 |                      |                  |
| **线程 CPU 使用时间**                    |                      |                  |
| **私有栈基址**<br>（用户栈 + 内核栈指针）         |                      |                  |
线程切换/[[进程调度|线程调度]]时, 不切换页表基址寄存器
