# 哈夫曼树
构造过程遵循**贪心策略**，通过反复合并当前权值最小的两棵树，自底向上构建最优二叉树。

1. **初始化森林**  
    将给定的 n 个权值 w1,w2,…,wn 视为 n 棵单结点的树，这些树构成森林 F
2. **选取与合并** 
    在 F 中选出**根结点权值最小**的两棵树，作为左、右子树构造一棵新树。新树的根结点权值为左右子树根结点权值之和
3. **删除与加入**  
    从 F 中删除被合并的两棵旧树，并将新树加入 F
4. **重复**  
    重复步骤 2 和 3，直到 F 中只剩下一棵树——这棵树就是哈夫曼树

所有初始节点都是叶子节点, 且权值越小的节点路径长度越大
共新建了 n-1 个节点, 哈夫曼树的节点总数为 2n-1
每次构造都选择 2 棵树作为新节点的孩子, 硬刺哈夫曼树中不存在度为 1 度结点
