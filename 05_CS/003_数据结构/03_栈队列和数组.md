- [[卡特兰数公式]]:
	当n个不同元素进栈时,出栈元素不同排列个数为
$$
C_n = \frac{1}{n+1} \binom{2n}{n} = \frac{(2n)!}{(n+1)!\,n!}, \quad n \geq 0.
$$
- 共享栈: 节省存储空间, 降低发生上溢的可能
- 某个元素 $x$ 出栈, 则在 $x$ 之前的未出栈的元素一定逆序出栈 (从大到小)

- 区分队列满还是空, 有三种方法:
	1. 牺牲一个单元, 当 `(rear+1) % MaxSize == front` 时队满
		`MaxSize` = 可用队列单元数 + 1
	2. 增设 `size` 数据成员, 队空为 0 , 队满为 Maxsize
	3. 增设  `tag` 数据成员, 插入置为 1 , 删除置为 0

- 中缀表达式转后缀表达式: 
	1. 加括号
	2. 运算符后移
	3. 去括号
	
- 运算符优先级:
	1. 若当前运算符的栈外优先级高于栈顶运算符的栈内优先级，则当前运算符入栈；
	2. 若当前运算符的栈外优先级低于或等于栈顶运算符的栈内优先级，则反复弹出栈顶运算符并输出，直到满足入栈条件；
	3. 左括号具有：最高栈外优先级 + 最低栈内优先级;
	4. 右括号具有最低栈外优先级, 遇到右括号时不断弹栈直到左括号.

- 三对角矩阵: 所有非零元素都集中在主对角线及其相邻的两条对角线上, 其余全为 0.
- `稀疏矩阵 = 行数 + 列数 + 非零元素个数 + 三元组表` 也有[[十字链表]]的存储方式
	`三元组表 = 行号 + 列号 + 元素值`
	显示记录非零元素个数有助于算法实现
