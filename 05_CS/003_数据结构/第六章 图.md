# 6.1 图的基本概念
## 图论核心考点

### 无向图（n个顶点）
1. **度之和公式** $\sum \deg(v) = 2|E|$ 
2. **连通无向图最少边数**  $|E|_{\min} = n-1$（树结构） 当 $|E| >= n$ 时，必存在回路
3. **非连通无向图边数最多为**   $|E|_{\max} = \binom{n-1}{2}  = \frac{(n-2)(n-1)}{2}$
4. **无向完全图边数**  $|E| = \binom{n}{2} = \frac{n(n-1)}{2}$
---
### 有向图（n个顶点）
1. **度关系**   出度之和 = 入度之和 = $|E|$     总度之和：$= 2|E|$
2. **强连通有向图性质**  最少边数：$|E|_{\min} = n$（有向环结构）
3. **有向完全图边数** $|E| = 2 \times \binom{n}{2} = n(n-1)$
---
