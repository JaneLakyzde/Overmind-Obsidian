KMP 算法通过预处理模式串，计算其各个前缀的最长相等真前缀与真后缀长度。当匹配过程中出现失配时，利用已经匹配部分的前后缀关系，排除不可能成功的对齐位置，使模式串指针直接回退到仍有可能继续匹配的位置，而主串指针无需回退，从而实现对主串的单向遍历。
# 算法思想
1. 设置指针, 发现模式串某位失配
2. 指针保持不动, 寻找模式串在指针之前的部分, 寻找该子串的前后缀交集最长元素
3. 将前缀移动到原本后缀的位置, 即保持指针左侧的模式串长度为最长相等前后缀的长度
	移动 n 位, 对应长度为 k-n 的前后缀进行匹配, 而这可以通过对模式串自身的结构进行分析得到. 
	如果大于最长相等前后缀的长度, 则必然失败, 不存在匹配的可能; 
	如果等于最长相等前后缀的长度, 则仍然保留匹配的可能
	
4. 移动完毕后, 指针即可继续扫描进行新一轮的匹配

# next 数组
next 数组就是对模式传自身结构分析得到的产物, 将每个位置的前缀子串中的最长相等前后缀(一下简称“前缀”)的长度保存起来, 表示下一次比较时, 模式串应该跳过这个长度

指针跳转到前缀的后一个元素(下标即前缀的长度)

1. 初始化
2. 处理前后缀不相同的情况
3. 处理前后缀相同的情况
4. 更新 next




# 算法题代码实现
- 在多数考研《数据结构》教材中，`next[j]` 表示模式串第 `j` 个字符失配后，模式串指针 `j` 应该跳转到的位置。
- 代码里的 `next[i]` 实际存储的是 **PMT/LPS 长度**。两者本质上使用同一份“最长相等前后缀”信息
	将 PMT 整体右移一位，再把每个有效元素加 1，就得到传统 `next` 数组；同时单独规定 `next[1]=0`。
	公式是：

$$\boxed{next[1]=0}$$
$$\boxed{next[j]=PMT[j-1]+1,\quad j\ge 2}$$

```cpp
class Solution {
public:
int strStr(string s, string p) {
	int n = s.size(), m = p.size();
	if(m == 0) return 0;
//设置哨兵
	s.insert(s.begin(),' ');
	p.insert(p.begin(),' ');
	vector<int> next(m + 1);
//预处理next数组
	for(int i = 2, j = 0; i <= m; i++){
		while(j and p[i] != p[j + 1]) j = next[j];
		if(p[i] == p[j + 1]) j++;
		next[i] = j;
	}
//匹配过程
	for(int i = 1, j = 0; i <= n; i++){
		while(j and s[i] != p[j + 1]) j = next[j];
		if(s[i] == p[j + 1]) j++;
		if(j == m) return i - m;
	}
	return -1;
}
};
```
