# 单源最短路径问题

## BFS 算法
**适用场景**：**无权图**（或每条边权值相等的图）的单源最短路径。

-   **算法思想**：
    1.  从源点 `s` 开始，将 `s` 入队，距离 `dist[s]=0`
    2.  当队列不空时，出队一个顶点 `u`，遍历 `u` 的所有未访问邻接点 `w`
    3.  对每个 `w`，设置 `dist[w] = dist[u] + 1`，并将 `w` 入队
    4.  **核心**：BFS 按层遍历，第一次访问到某个顶点时的路径长度就是最短路径长度。
    -   需要两个辅助数组：`dist[]` 记录最短距离，`path[]` 记录前驱顶点用于回溯路径。

-   **时间复杂度**：
    -   **邻接表**：$O(|V| + |E|)$
    -   **邻接矩阵**：$O(|V|^2)$

## Dijkstra 算法
**适用场景**：**带权图**（边权非负）的单源最短路径，也可用于无权图。

-   **算法思想**（[[贪心算法|贪心策略]]）：
    1.  初始化：将源点 `s` 的距离设为 `0`，其余顶点设为 $\infty$。集合 `S` 存放已确定最短路径的顶点。
    2.  重复以下步骤直到 `S` 包含所有顶点（或目标顶点已确定）：
        -   从尚未加入 `S` 的顶点中，选出当前距离值最小的顶点 `u`，将其加入 `S`
        -   **松弛操作**：遍历 `u` 的所有邻接点 `v`，若 `dist[u] + w(u,v) < dist[v]`，则更新 `dist[v]` 为更小值，并记录前驱。
    -   需要辅助数组 `dist[]`, `path[]`, `visited[]`
		（标记顶点是否已加入 `S`）

-   **时间复杂度**：
    -   **朴素实现**（邻接矩阵 + 线性扫描选最小）：$O(|V|^2)$，适合**稠密图**。
    -   **堆优化**（邻接表 + 最小堆）：$O((|V|+|E|) \log |V|)$，常简记为 $O(|E|\log|V|)$，适合**稀疏图**。

-   **与 Prim 算法的关系**：
    -   **相似点**：两者都基于贪心，都维护一个不断扩大的顶点集合，每一步都选择一条最小边/最小距离对应的顶点加入集合。
    -   **本质区别**：
        -   **Prim** 选的是**离集合最近**的顶点（更新时比较的是邻接点到集合内顶点的最小权值）。
        -   **Dijkstra** 选的是**离源点最近**的顶点（更新时比较的是源点经过已确定顶点到目标的总路径长度）。
    -   **一句话记**：Prim 算的是“两棵树之间的最短枝”，Dijkstra 算的是“从树根到各个节点的最短路径”。

-   **不适用于带有负权值的情况**：
    -   **原因**：当顶点加入集合 \(S\) 后，其最短路径就被认为“确定”了。若后续出现负权边，可能使得已经确定的最短路径还能变得更短，但算法不会再回头更新它，因此会导致错误。
    -   **负权边场景**：应改用 **Bellman-Ford 算法**，它可以处理负权边并能检测负权回路。

# 顶点间最短路径问题
**问题定义**：求图中**每一对顶点**之间的最短路径长度。

## Floyd 算法
使用邻接矩阵来存放
**适用场景**：求每对顶点间的最短路径，允许负权边，但图中**不能存在负权回路**。

-   **算法思想**（动态规划）：
    1.  设置一个 \(n \times n\) 的矩阵 \(A^{(k)}\)，其中 \(A^{(k)}[i][j]\) 表示从顶点 \(i\) 到顶点 \(j\) 且**中间顶点只允许经过编号不超过 \(k\) 的顶点**时的最短路径长度。
    2.  初始状态 \(A^{(-1)}\) 就是图的邻接矩阵（无边记为 \(\infty\)，自身到自身记为 \(0\)）。
    3.  依次将每个顶点 \(k\)（\(k=0,1,\dots,n-1\)）作为**中间点**，对所有顶点对 \((i,j)\) 进行试探：
        -   若经过 \(k\) 能让路径更短，即 \(A[i][k] + A[k][j] < A[i][j]\)，则更新 \(A[i][j]\)。
    4.  递推公式：\(A^{(k)}[i][j] = \min\left( A^{(k-1)}[i][j],\ A^{(k-1)}[i][k] + A^{(k-1)}[k][j] \right)\)。
    5.  最终矩阵 \(A^{(n-1)}\) 就给出了所有顶点对间的最短距离。

-   **时间复杂度**：\(O(|V|^3)\) （三重循环，外层为中间点 \(k\)）。
-   **空间复杂度**：\(O(|V|^2)\)（直接在原矩阵上迭代更新即可，可原地工作）。
-   **路径记录**：通常维护一个 `path[i][j]` 矩阵，记录 \(i\) 到 \(j\) 路径上 \(j\) 的前一个顶点，通过递归输出完整路径。
-   **其他方法**：也可对每个顶点都运行一次 **Dijkstra**（非负权时）或 **BFS**（无权时），复杂度分别为 \(O(|V|^3)\) 或 \(O(|V|^2+|V||E|)\)，在稀疏图上用堆优化 Dijkstra 重复运行可能优于 Floyd。
