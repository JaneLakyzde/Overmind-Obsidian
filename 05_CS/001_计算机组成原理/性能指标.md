[[主存储器]]
这里详细描述 CPU 的各项性能指标和计算方式

## 一、 核心时间指标


- **时钟周期**
    
    - 计算机中最基本、最小的时间单位，即**主频的倒数**。在一个时钟周期内，CPU仅完成一个最基本的动作
        
    - **秒 (s)**， 通常为纳秒(ns)      $10^{-9}$ 数量级
        
    - 时钟周期越短，CPU速度越快。
        
- **主频** -- 时钟频率
    
    - 也叫**时钟频率**，表示CPU每秒产生的时钟脉冲数，即**时钟周期的倒数**
        
    - $主频 = 1/时钟周期$ 
        
    - **单位**：**Hz**（如GHz、MHz）。例如主频为4.1GHz，表示每秒有 $4.1 \times 10^9$ 个时钟周期 。
        
    - 主频不能直接等同于运算速度。虽然提高主频通常能缩短程序执行时间，但实际性能还受CPI（每条指令周期数）和指令集架构的影响 
        
- **CPI**  -- `Cycle Per Instruction`
    
    - **执行一条指令所需的平均时钟周期数** 
        
    - 由于不同指令的复杂程度不同，因此CPI是一个**加权平均数**
        
    - $CPI = 执行程序所需总时钟周期数 / 所执行的指令条数 (IC)$ 
        
- **CPU 执行时间**
    
    - 执行整个程序所需的总时间（通常仅指CPU时间，不包括I/O等待时间）
        
        1. $CPU执行时间 = (总时钟周期数) \times 时钟周期时间$ 
            
        2. **$CPU执行时间 = 指令条数 (IC) \times CPI \times 时钟周期时间 = (IC \times CPI) / 主频$** 
        
        
- **IPS** -- `Instrcutions Per Second`
    
    - **每秒执行多少条指令** 
        
    - $IPS = 主频 / CPI = 1/CPI*时钟周期$
        

## 二、 常用量化指标

- **MIPS**
    
    - **定义**：**每秒执行百万条指令**
        
    - **公式**：$MIPS = 主频(Hz) / (CPI \times 10^6)$ 。
        
    - **典型例题**：某计算机主频1.2GHz，平均CPI为3，则 $MIPS = (1.2 \times 10^9) / (3 \times 10^6) = 400$。
        
    - **局限性**：不同机器的指令集不同，MIPS的横向比较意义有限；且MIPS动态变化，同一机器运行不同程序MIPS值也不同。
        
- **FLOPS**
    
    - **定义**：**每秒浮点运算次数**
        
    - **单位体系**：
        
        - **MFLOPS**：$10^6$ 次/秒
            
        - **GFLOPS**：$10^9$ 次/秒
            
        - **TFLOPS**：$10^{12}$ 次/秒
            
        - **PFLOPS**：$10^{15}$ 次/秒 （“神威·太湖之光”曾达93PFLOPS，即 $9.3\times 10^{16}$ 次/秒，常称“亿亿次”）
            
        - **EFLOPS**：$10^{18}$ 次/秒
            
    - **考研点拨**：专门用于衡量浮点运算能力，常用于科学计算和超级计算机性能评价 。
        

## 三、 补充：非时间指标

虽然上述为CPU核心指标，但考研大纲也常涉及以下**非时间指标**，它们从架构层面影响性能：

- **[[字长]]**：CPU**一次能处理整数的位数**（即ALU的宽度），决定了计算的精度和范围。例如64位处理器字长为64位 。
    
- **总线宽度**：数据总线**一次能并行传送的最大信息位数** 。
    
- **主存容量与带宽**：存储器所能容纳的总信息量及数据传输速率。
