# 一、 基本概念

DMA (Direct Memory Access) 是一种**完全由硬件（DMA控制器，简称 DMAC）执行 I/O 交换**的工作方式。

- **核心思想：** 在外设和主存之间开辟一条“直接数据通道”。数据传输时，**CPU 让出总线控制权**，由 DMAC 接管总线，数据直接在主存和外设之间传送，全程**不需要 CPU 执行程序介入**。
    
- **适用场景：** 磁盘、显卡、网卡等**高速设备**的大批量数据块传输。

# 二、 传送方式

当外设和 CPU 同时请求访问主存时，总线使用权的分配有三种策略：

**1. 停止 CPU 访存**

- **机制：** DMA 开始传输时，直接向 CPU 发出一个总线请求信号。CPU 交出总线控制权并彻底停工，直到 DMA 把一整块数据传完，CPU 才恢复工作。

- **评价：** 控制简单；但 CPU 处于不工作状态，主存利用率未达到最高，适合高速外设。

**2. 周期挪用 / 周期窃取** 

- **机制：** DMA 仅在需要传送一个字（或字节）的数据时，**偷偷“挪用”（窃取）主存的一个存取周期**（即一个机器周期或总线周期）。
    
- **三种细分情况：**
    
    1. **CPU 此时不需要访存**（如在内部做乘法）：DMA 顺理成章使用主存，互不干扰。
    2. **CPU 正在访存**：DMA 等待当前存取周期结束，然后再窃取。
    3. **CPU 和 DMA 同时请求访存（冲突）**：**DMA 优先！** 因为高速设备的数据如果不及时传走就会丢失。
        
- **评价：** 既保证了高速 I/O，又兼顾了 CPU 的效率，是现代计算机最常用的方式。
    

**3. DMA 与 CPU 交替访存**

- **机制：** 将一个 CPU 周期分为两半（例如 C1 和 C2 阶段），一半给 CPU 访存，一半给 DMA 访存。
- **评价：** 硬件逻辑极度复杂，且要求主存的工作速度极快（通常是时钟频率的两倍）。不需要总线使用权的申请和归还，传输速率最高。

## 三、 DMA 的传送过程

这是 DMA 完整生命周期的时序轨迹，一定要分清哪一步是软件做的，哪一步是硬件做的：

**1. 预处理**

- CPU 执行几条 I/O 指令，向 DMA 控制器写入初值：测试设备状态、设置主存起始地址(MAR)、设置传送字数(WC)、指明传送方向（读/写）、启动外设。
- 外设准备好一个字的数据 $\rightarrow$ 向 DMAC 发出 DMA 请求 (DREQ)。
- DMAC 向 CPU 发出总线请求 (HRQ)。

**2. 数据传送**

- CPU 在**当前机器周期结束时**响应，让出总线 (HLDA)
- DMAC 接管总线，控制主存和外设完成一个字的数据交换，MAR 加 1，WC 减 1
- 重复上述过程，直到 WC 计数溢出（通常是从负数加到 0，或从正数减到 0）

**3. 后处理**

- 当 WC 溢出归零时，表示一整块数据传完了。
- **DMAC 此时会向 CPU 发出真正的“I/O 中断请求”**。
- CPU 响应中断，在**指令周期结束后** 执行中断服务程序，校验数据是否出错，决定是否继续下一次 DMA 传送。

## 四、 终极对决：DMA 方式和中断方式的区别


| **比较维度**         | **程序中断方式**           | **DMA 方式**                      |
| ---------------- | -------------------- | ------------------------------- |
| **数据传送的执行者**     | 软件                   | *硬件                             |
| **中断的作用**        | 用于**传输数据本身**         | 仅用于**后处理** (报告传送结束或出错)          |
| **响应的时机 🌟**     | **指令周期** 结束时         | **机器周期 (总线周期)** 结束              |
| **响应条件**         | CPU 必须开中断 (`IF=1`)   | 不受 CPU 内部标志位限制                  |
| **是否保存断点/现场 🌟** | **必须保存** (PC 和寄存器入栈) | **完全不保存** (因为 CPU 没切特权态，只是让出总线) |
| **响应优先级**        | 低于 DMA               | **高于所有外中断**                     |
| **处理数据粒度**       | 字 / 字节 (低速设备)        | 数据块                             |
|                  |                      |                                 |
