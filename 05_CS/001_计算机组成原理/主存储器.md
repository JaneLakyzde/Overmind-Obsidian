# MAR 与 MDR

- MAR 的位数反映了存储单元的个数；MDR 的位数反映了存储字长
- 存储单元中的一个存储元代表一个bit，存储容量 = 存储单元大小（存储字长）* 个数，存储单元 的大小通常代表 [[字长|机器字长]] ，也就是 MDR 的大小
- MAR 的位数 与 主存地址空间(理论) 一一对应, 与 CPU 有关, 与实际主存储器容量无关
注：IR MAR MDR 是 CPU 的内部工作寄存器，对程序员是[[透明性]]的

# 存储器的分类
主要考察 按存取方式分类：


 1. 随机存取 RAM/ROM
    RAM : Random Access Memory
    SRAM - Cache
    DRAM - 电容/主存
    ROM -  只读/Flash/SSD

2. 串行访问 Serial
    SAM - 顺序存取 SAM: 磁带
    DAM - 直接存取 DAM: 磁盘
	    先直接找道/后顺序找扇区
	特点：读取时间受物理位置影响
	
3. [[相联存储器]] CAM
    按内容检索
    TLB- 快表: SRAM + 比较器实现


- 注意区分 存取时间 与 存取周期 的差别，存储周期中包含了操作后的复原时间！
- cache 数据调动是透明的，但是 主存-辅存 数据调动对汇编程序员是 不[[透明性]] 的

# 存储器基本概念

### 存储元

MOS管+栅极电容 = DRAM 存储元；双稳态触发器（六 MOS ）= SRAM 存储元

- 电容 (Capacitor)：存储电荷（即存储二进制 0/1）
    
    - 因为电容会自然漏电，所以 DRAM 必须要有刷新机制，且刷新操作是按**行**进行的。这是区分它与 SRAM（使用双稳态触发器，不需要刷新）的关键点。
        
- MOS管：作为通电“开关”
    
### 存储芯片的结构

- **存储矩阵 / 存储体 
    
    - 存储体由多个*存储单元* 构成，每个存储单元由多个 *存储元*  构成。
    - 为了减少芯片的引脚数量，现代芯片的存储矩阵通常采用二维排列。
        
- **译码驱动电路**
    
    - 将 $n$ 位地址线信号转化为 $2^n$ 根字选通线的高低电平。
        
    - 如果采用单译码（线选法），$n$ 根地址线需要 $2^n$ 根选择线，体积庞大，仅适用于小容量存储器。考研中常考的双译码（重合法）则有行译码器和列译码器。
        
- **读写电路 
    - 包含读出放大器（Sense Amplifier）和写入电路，每次读/写一个**存储字**。
        
- **外部引脚
    
    1. 地址线：决定了寻址空间。如果有 $n$ 根地址线，则可寻址单元数为 $2^n$ 个。单向
        
	2. 数据线 ：决定了芯片一次能并行读写的数据位数（即**存储字长**）。如果有 $m$ 根数据线，说明每个存储单元包含 $m$ 个比特。双向
        
    3. 片选线 ：用于选择当前操作哪一块芯片。在**存储器扩展**时，高位地址通常与译码器相连，产生片选信号。
        
    4. 读写控制线：可两根， 可一根
            
	存储器引脚总数 = 地址引脚 + 数据引脚 + 片选线 + 读写控制线 （+电源线）
	即 $[MAR]  + [MDR]  + 1 + 1 / 2$ 
	注意：DRAM 采用地址复用技术，地址引脚减半！

### 寻址 与 编址


- 编址：现代计算机通常按字节编址
	内存中的每一个字节都有一个独立的地址编号。底层的物理编号都是以字节为单位的。
    
- 寻址：（通常协同工作）

1. 按字节寻址：给出的地址直接对应1个字节。总容量如果是 4GB，地址空间就是 4G = 2^{32}，需要 32 根地址线。
2. 按字寻址：一次读写一个“字”，[[字长]]对应机器字长
3. 按半字寻址：一次读写半个字
4. 按双字寻址：一次读写两个字

# RAM
## SRAM 和 DRAM

| **对比维度**   | **SRAM (静态随机存取存储器)** | **DRAM (动态随机存取存储器)**       |
| ---------- | -------------------- | -------------------------- |
| **存储原理**   | 双稳态触发器 (Flip-Flop)   | 电容存储电荷 (Capacitor)         |
| **破坏性读出**  | 否 (读出不破坏原状态)         | 是 (读出会放空电荷，需立刻恢复)          |
| **是否需要刷新** | 否 (只要不断电，状态一直保持)     | 是 (电容会自然漏电，需定期安排刷新)        |
| **运行速度**   | 快 (纳秒级别，与 CPU 速度较匹配) | 较慢 (需要充放电和刷新等待时间)          |
| **集成度**    | 低（6 个 晶体管）           | 高 (1个存储元 = 1 个晶体管 + 1 个电容) |
| **存储容量**   | 小 (受限于低集成度)          | 大 (得益于高集成度)                |
| **发热与功耗**  | 大                    | 小                          |
| **制造成本**   | 高                    | 低                          |
| **地址引脚/线** | 不复用 (行、列地址一次性同时送入)   | 复用 行、列地址分两次送入              |
| **主要用途**   | 制造高速缓存 (Cache)       | 制造计算机主存                    |
## 刷新机制
1. 集中刷新：一个刷新周期 2ms 中，拿出一长段连续时间（死区）进行刷新
	死区期间不能访问存储器
2. 分散刷新：随机存取 与 顺序刷新 操作交替进行
	无死区，但是造成大量时间浪费
3. 异步刷新：将集中刷新的时间分散开来避免死区

**构成存储器的所有芯片同时按行刷新**

- !! DRAM 没有特殊说明，默认采用地址复用技术,地址线是原来的 1/2.
- 每一次 访问周期 = 存取时间 + 恢复时间，而一次刷新操作 = 假读取时间 + 恢复时间，两者时间上是相等的
- 现代采用 SDRAM ， DDR 是其中的一个分支,具体见[[时钟信号]] 
- 刷新操作对程序员和 CPU [[透明性]]，存储器内部实现

# ROM
rom常用于[[外存储器]]
## 分类与定义
1. **MROM (掩膜式只读存储器)** 
	存储内容由半导体制造厂按用户提出的要求在芯片的生产过程中直接写入。无法修改。
        
- **PROM (一次可编程只读存储器)**
    存储内容由用户用专门的设备（编程器）一次性写入。写入后无法修改
        
- **EPROM (可擦除可编程只读存储器)**
    - 修改次数有限，写入时间很长
    - **细分类型**：
        - **UVEPROM**：用紫外线==全部==擦除
        - **EEPROM**：电擦除选择性擦除
    
- **Flash Memory (闪存)**
	由 EPROM 演化而来,闪存的写速度一般比读速度更慢。因为写入前必须先进行擦除
    - **特点**：如 U 盘，SD 卡
        
- **Solid State Drives (固态硬盘 / SSD)**
    - **构成**：控制单元 + FLASH 芯片
        
## 注意事项

1. “只读”可写：很多 ROM 芯片叫“Read-Only”属于历史遗留叫法
    
2. RAM 与 ROM 的对比
    - ROM 芯片是非易失性的
    - 很多 ROM 也具有“随机存取”的特性
    
3. 主存储器中也有 ROM - [[BIOS]]，该 ROM 和 RAM 共同组成主存储器 MM

### 双端口 RAM (Dual-port RAM)

通过增加一套独立的读写控制电路，实现空间上的并行

- **功能**：支持两个 CPU（或两个端口）同时访问 RAM    
    1. **可同时读/写不同**存储单元        
    2. **可同时读相同**存储单元。
    3. **不可同时写**（或一读一写）同一个存储单元。
        
- **冲突处理**： [[读者-写者问题]]
