# 1. [[移位运算]]
- 定点数移位运算，左移叫溢出，右移叫精度丢失
	- 有符号数的算术左移：符号位与最高位数值不一致，左移就会溢出。
	- 无符号数的逻辑左移：制药溢出的最高位是 1 ，就会发生溢出


# 2. [[加减运算]]
首先，显然 只有“同号相加”或“异号相减”才可能溢出。
### 2.1单符号位法
也叫 `模2补码` 逻辑表达式为:
$$V = A_s B_s \bar{S_s} + \bar{A_s} \bar{B_s} S_s$$
$ABS$ 分别代表两个加数的符号以及结果的符号，
即只有当出现 负负得正 或者 正正得负时，发生溢出


---
### 2.2 进位判断法

我们要观察最前面的两个关键进位：
1. **$C_s$**：符号位向更高位的进位（实际产生的丢弃进位）。
2. **$C_1$**：最高数值位向符号位的进位。

逻辑表达式：$V = C_s \oplus C_1$
- **若 $C_s \oplus C_1 = 0$**：无溢出。
	    - 说明符号位的进位和数值位的进位“抵消”了，结果符号正确。
		    符号位进位，说明是负数相加，若不溢出，答案也为负数，则需要最高位进位；
		    符号位为1时，数值越大，绝对值越小
		    符号位不进位，说明是正数相加，那么要保证符号位为0，则最高位不能进位。
    
- **若 $C_s \oplus C_1 = 1$**：有溢出。
	    - 说明要么数值位往符号位顶进去了 $1$（导致正+正变负），
	    - 要么符号位借位了而数值位没补上（导致负+负变正）。

> 1000 0001 = -127，补码符号为负时，补码的数值位越小，绝对值越大

### 2.3 双符号位法（变形补码/模4补码）

- 在预处理阶段（进入ALU之前），硬件会复制补码的符号位送入 ALU。
- 对运算的结果进行判断：
    - `00`：正数
    - `11`：负数
    - `01`：上溢（结果本该是正数，但太大了，冲进了第一符号位）
    - `10`：下溢（结果本该是负数，但太小了，冲进了第一符号位）
- 结论：
    
    运算结果的符号位为 $S_1 S_2$：
    - $S_1 \oplus S_2 = 0$：无溢出（`00` 或 `11`）。
    - $S_1 \oplus S_2 = 1$：有溢出（`01` 或 `10`）。
    
    > **注意：** 存储时通常只存一位，运算时会复制一位。

---
### 2.4 无符号数
通过查看 `Carry Flag` 寄存器的值来进行判断
加法：最高位进位 = 1 时 溢出
减法：最高位进位 = 0 时 溢出

# [[乘法运算]]

- 无符号数：乘积寄存器前 n 位不全为 0 时，溢出
- 带符号数：乘积寄存器前 n+1 位有不同的数值时，溢出

- 无论带不带符号，溢出时统一将 OF = CF = 1，并调用溢出自陷指令，执行异常处理程序
