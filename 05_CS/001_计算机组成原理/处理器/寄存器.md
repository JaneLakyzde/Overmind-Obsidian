寄存器是由触发器构成的高速暂存单元，CPU 中有寄存器，其他功能部件和 [[IO接口|IO接口]] 中也可以设置寄存器。
# 可见
- 通用寄存器组 GPRs
- 基址寄存器、变址寄存器、堆栈指针
- 程序计数器 PC
- 标志寄存器 FR (PSW中的一部分, 用户只读)

# [[透明性|透明]]
- 指令寄存器 IR
- 存储器地址寄存器 MAR
- 存储器数据寄存器 MDR
- 页表基址寄存器

# PSW

`Program Status Word` 程序状态字
是一个重要的寄存器，用于记录CPU当前运行的状态和关键信息。

1.  反映运行结果：保存上一条算术或逻辑运算指令的执行结果状态（如进位、是否为零等），为后续的条件转移指令提供判断依据。
2.  控制CPU模式：通过其中的状态位来区分CPU当前是内核态（管态/核心态） 还是用户态（目态）。
3.  保障程序恢复：在中断发生时，PSW会被保存，以便中断处理完成后能精确恢复被打断程序的现场。子程序调用的时候不需要保存 PSW

通常包含以下几类关键标志位：

| 类别 | 标志位（缩写） | 含义与功能 |
| :--- | :--- | :--- |
| 状态标志 | 进位标志 (CF) | 表示无符号数运算时最高位是否产生进位或借位。 |
| | 零标志 (ZF) | 表示运算结果是否为0。 |
| | 符号标志 (SF) | 表示运算结果的符号，与运算结果的最高位相同。 |
| | 溢出标志 (OF) | 表示有符号数运算时是否发生了溢出。 |
| | 辅助进位标志 (AF) | 表示运算时低4位（BCD码）是否向高4位进位或借位。 |
| | 奇偶标志 (PF) | 表示运算结果中“1”的个数是否为偶数。 |
| 控制/系统标志 | 方向标志 (DF) | 控制串操作指令中地址指针是递增还是递减。 |
| | 中断允许标志 (IF) | 控制CPU是否响应可屏蔽中断。 |
| | CPU模式位 | 标识CPU当前处于内核态（0）还是用户态（1）。 |
