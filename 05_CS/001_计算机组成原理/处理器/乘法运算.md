# 1 无符号数乘法运算：

 逐位相乘，错位相加
### 1.1 电路实现逻辑

 - n 位无符号数相乘，需要 1 个 $n$ 位寄存器和一个 $2n$ 位寄存器，存放 被乘数、乘数+乘积
- 进行 $n$ 轮加法、移位运算，计数器 $C_n = n$ ，部分积-乘积寄存器 初值为 0

1. 首先将乘数寄存器的最低位放入控制逻辑中进行判断
2. `if` 最低位 = 1，则执行 ==加法== 并将结果写入乘积寄存器（注意进位需保存至进位触发器中）
3. `else` 最低位 = 0，则直接进入下一步
4. 将 进位触发器、乘积寄存器、乘数寄存器 视为一个整体，整体逻辑右移一位，抛弃最小位
5. 计数器 $C_n -1$，继续循环。

- 当 $C_n = 0$ 时，结束循环，此时乘积正好全部占满原本的乘数寄存器。提取需阶段，容易导致溢出。
### 1.2 溢出判断
- 乘积寄存器==（高 n 位）==若不全为零，则 `OF == 1` ，发生溢出。
- 若溢出，OF 标志位和 CF 标志位都会 = 1

### 1.3 溢出的处理方式
1. 不处理
2. 溢出自陷指令[trap]      执行[[中断的处理]]处理程序

# 2 带符号数乘法运算：

也叫： 补码一位乘法（Booth 布斯算法），通过相邻位判断执行“加”或“减”操作。

### 2.1 电路实现逻辑

对于 $n$ 位带符号数相乘，需要 1 个 $n$ 位寄存器 和一个 $2n+1$ 位寄存器（考虑符号扩展和进位）
	被乘数寄存器 [X]补、部分积-乘积寄存器-辅助位（初始为 0 ）。

**初始化：**

- 部分积初值为 0
- 计数器 $C_n = n$    
- 乘数寄存器末尾增加一位辅助位 $Y_{n+1} = 0$ 

**控制逻辑：**

观察乘数寄存器的**最低位 $Y_n$** 与 **辅助位 $Y_{n+1}$** 的组合：

1. **if $Y_n Y_{n+1} = 01$**：部分积 + [X]补，结果写入部分积寄存器。
2. **if $Y_n Y_{n+1} = 10$**：部分积 + [-X]补（即减去 X），结果写入部分积寄存器。
3. **if $Y_n Y_{n+1} = 00$ 或 $11$**：直接跳过加减。

**移位与循环：**

- 将 **部分积寄存器、乘数寄存器、辅助位** 视为一个整体，进行补码算术右移一位（符号位填充）
- 计数器 $C_n -1$，继续循环。

- 结束循环时，结果会与寄存器对齐。

### 2.2 溢出判断

- **截断判断**：若将 `2n` 位结果转回 `n` 位，需截断并丢弃**高 n 位**。此时要判断**保留下来的结果符号位**，是否与**丢弃的高 n 位**完全一致。
    
- **标志位状态**：
    - 若这 `n+1` 位完全相同（即高 `n` 位只是低位符号的有效扩展），则判断为**无溢出**，处理器会将 **OF 与 CF 同时清零 (0)**。
    - 若这 `n+1` 位不全相同（即高 `n` 位包含了被截断的有效数据），则判断为**溢出**，处理器会将 **OF 与 CF 同时置 1**。

### 2.3 溢出的处理方式

- 忽略乘法溢出
- 执行“溢出自陷指令”，当`OF == 1` 时会触发“异常处理程序”来处理溢出
