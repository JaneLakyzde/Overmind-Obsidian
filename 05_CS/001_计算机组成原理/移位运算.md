# 移位运算

| **操作类型** | 左移                 | **右移 **                     |
| -------- | ------------------ | --------------------------- |
| **逻辑**   | 丢弃最高位，最低位补 **`0`** | 丢弃最低位，最高位补 **`0`**          |
| **算术 **  | 丢弃最高位，最低位补 **`0`** | 丢弃最低位，最高位补 **符号位** (保持符号不变) |
# 逻辑移位 
- 用于无符号整数
	左移：当高位 1 左移出时发生溢出
	右移：低位移出丢失精度

# 算术移位 
- 用于有符号整数。使用[[机器数|补码]]表示。
	左移时，当符号位改变（ 0 变 1 或 1 变 0）发生溢出
	右移时，最高位要补符号为。会丢失精度

- 左移的操作相同，判断溢出的条件不同
- 右移的操作不同，但实际上都是填补符号位。
