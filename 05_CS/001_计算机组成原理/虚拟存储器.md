## 地址转换
MMU（内存管理单元）是一个硬件组件，直接坐落在 CPU 和物理内存之间，负责处理所有与存储相关的繁杂事务。
地址转换是它最基本的工作。CPU 运行程序时用的是**虚拟地址 (VA)**，而内存条只认**物理地址 (PA)**。MMU 负责把 CPU 给出的那个“虚”的地址，通过查表的方式转换成“实”的地址。

- 它会先看 **TLB** ⚡（快表）里有没有现成的答案。
    
- 如果没有，它会亲自去内存里查**页表** 📋。
## 快表
快表是位于 **CPU 内部**（更具体地说是集成在 MMU 内存管理单元中）的一种高级高速缓存。它使用的是价格昂贵但速度极快的 **SRAM** 存储介质，而主存（内存条）使用的是 **DRAM**。

# 虚拟存储器与 [[Cache]] 的比较
- Cache 主要解决系统速度, 而虚拟存储器是为了解决主存容量
- Cache 全由硬件实现, 对所有程序员都[[透明性|透明]]; 
	而虚拟存储器是 OS 和硬件共同实现的, 对汇编程序员不透明
