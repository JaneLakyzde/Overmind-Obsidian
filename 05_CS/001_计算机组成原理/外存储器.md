# 磁盘
- 写过程是电生磁，改变磁性；读过程是磁生电，检测磁通变化
- 磁盘是==块设备==, 最小传输单位是块(块内含若干扇区), 不能按字节精确取数字
- 磁盘三要素:
	1. 磁盘驱动器
	2. 磁盘控制器
	3. 盘片

- 扇区 硬盘块 是磁盘读/写的最小单位,即磁盘按块存取
	还有 Cache块 和 文件块 
	
- 存取时间 = 平均寻道时间 + 平均寻扇时间 + 传输时间
	
- [[RAID]] 冗余磁盘阵列
	
- 温盘即“温彻斯特磁盘”，核心特征正是“可移动磁头、固定盘片、全密封结构”。
	
    正是因为密封（盘片和磁头被封装在洁净腔内），消除了外界尘埃污染，才使得它对使用环境要求不高，成为后来占绝对主导地位的硬磁盘存储器。

# 固态硬盘

- EEPROM --> FLASH Memory --> SSD
- 数据是以页为单位读/写,以[块]为单位擦除的
- 磨损均衡:
	动态磨损均衡: 写入新数据时,自动选择新闪存块
	静态磨损均衡: 将读多写少的内容自动移动至老闪存块
