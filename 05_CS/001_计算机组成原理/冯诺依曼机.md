# 五大要点：

1、工作方式：存储程序，程序控制

2、五大部件：运算器、[[主存储器]]、控制器、输入、输出

3、指令和数据同等地位存放在存储器内, 通过[[指令周期]]的不同阶段来区分是指令还是数据

4、指令和数据都用二进制表示

5、指令 = 操作吗 + 地址码

# 工作原理

- **取指令**：根据 **PC（程序计数器）** 中的地址从存储器 ( MAR - RAM - MDR ) 取出指令送入 **IR（指令寄存器）**。
    
- **分析指令**：控制单元对 IR 中的操作码进行译码，确定操作性质及操作数地址。
    
- **执行指令**：根据指令要求，完成计算并将结果存入通用寄存器或累加器（ACC）。接着取出操作数或完成数据传送。（访存写回操作）
    
- **更新 PC**：为下一条指令做准备（通常是 $PC + 1$，遇到转移指令则修改为目标地址）。


**指令 vs 数据**

- 从时间上区分：取指周期取出的通常是指令，执行周期取出的通常是操作数。
	
- 从空间上区分：指令流向控制器（IR），数据流向运算器（ACC/ALU）。

# 现代化改进
- 以存储器为中心极大地提高了 CPU 的利用率。
- 将指令和数据物理上分开存储，拥有独立的总线，常见于现代高性能 CPU 的 **L1 Cache**（一级缓存）设计。

# [[弗林分类法]]：

 ① 控制流驱动 (Control Flow Driven)，冯诺依曼机，SISD

1. **存储程序原理**：冯·诺依曼机的核心是“存储程序控制”，即指令序列预先存放在内存。
    
2. **指令驱动本质**：冯·诺依曼架构明确规定计算机必须按照**指令的顺序**自动执行。PC（程序计数器）的存在就是为了维持这个“控制流”。
    
3. **单步特性**：经典的冯·诺依曼机属于 **SISD（单指令流单数据流）**，是典型的按序执行模型，完全符合控制流驱动的定义。
    

|**概念**|**维度**|**冯·诺依曼机属性**|**考研常考点**|
|---|---|---|---|
|**控制流驱动**|**驱动方式**|**是（核心属性）**|PC 的自动加 1 与跳转。|
|**微程序控制**|**实现技术**|**可选（后期改进）**|控制存储器（CM）与微指令。|
|**多指令多数据**|**并行等级**|**否（经典冯氏为单流）**|多核处理器、共享存储模型。|
|**数据流驱动**|**驱动方式**|**否（与其对立）**|非冯·诺依曼架构的代表。|

- **陷阱 1**：不要因为现代 CPU 内部有微程序，就认为微程序是冯·诺依曼机的基本思想。基本思想是**存储程序**，而微程序只是实现控制器的一种**手段**（另一种是硬布线）。
    
- **陷阱 2**：数据流驱动不设 PC。如果题目问“哪种架构没有程序计数器”，那指的就是**数据流机**。
