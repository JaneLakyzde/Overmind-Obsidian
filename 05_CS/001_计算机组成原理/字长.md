# 机器字长

- 机器字长 = 通用寄存器位数 = ALU 宽度, 代表 CPU 一次自然处理数据的位数
	CPU 字长现代通常为 32/64 位
	
- 字长不决定数据类型的具体范围，int 需要查看题目的具体内容。（寄存器位数）

---

# 存储字长

MDR 的位数 = 主存数据线位数 ，通常等于存储字的大小（存储单元大小），由 [[主存储器|RAM]] 决定
注意⚠️：不同于 MAR 的位数 = 寻址空间 = 地址总线宽度 = PC

-  这个CPU的地址位数现代通常为 48/52 位，即 CPU 中MAR的位数
	48 对应 256TB，52 对应 4096 TB = 4 PB

---

# 指令字长

指的是一条机器指令二进制代码总长度 早期ARM固定32位、x86可变字节（1 - 15字节）

- 数据总线的位数 通常与CPU一致 
- 也有例外 Intel 8088 （ CPU 16位，数据总线 8 位，称为准 16 位）

---

指令字长、存储字长、指令字长三者无固定相等关系，但不是互不相关
