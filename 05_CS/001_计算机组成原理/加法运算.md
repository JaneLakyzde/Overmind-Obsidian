# 逻辑思路
计算机内部，不论有无符号，都是使用补码进行存储和计算的。加法器不需要区分数据类型，主需要按位加法，并将CF、OF存入状态寄存器中即可。数据的具体含义/符号交给编译器和指令解释。

# 加法器的构造
关键在于标志位：
1. OF 溢出标志：判断有符号数是否溢出，由 符号位进位 和 最高数位 异或得到
	$OF = C_n \oplus C_{n-1}$
	此即第三种判断溢出的方式 [[溢出判断|进位判断法]] 
	
2. CF 进借位标志：判断无符号数是否溢出，由 最高位 和 减法信号位 异或得到1
	 $CF = Sub \oplus C_{out}$
	 具体电路实现时，如果加上逆元，最高位没有进位，
	 无符号数的 进/借标识位 实际上就是 最高位/符号位
	 
3. ZF 零标志：等于1时表示结果为0，有无符号都有意义。
	
4. SF 符号标志：表示结果的符号，有符号时有意义
