# 一、应用层

## 基于UDP
UDP的复用分用
### [[DNS]]
`Domain Name System，域名系统`
  - **应用**：将域名解析为IP地址（正向解析）或反之（反向解析），是互联网的“电话簿”。
  - **端口号**：UDP **53**（常用查询），TCP **53**（区域传送或响应超过512字节时使用）

### [[DHCP]]
`Dynamic Host Configuration Protocol，动态主机配置协议`
  - **应用**：给主机自动分配IP地址、子网掩码、默认网关、DNS服务器等配置参数，实现即插即用。
  - **端口号**：UDP **67**（服务器端），UDP **68**（客户端）

### [[RIP]]
`Routing Information Protocol，路由信息协议`
  - **应用**：一种内部网关协议（IGP），基于距离向量算法，以跳数为度量，适用于小型网络的路由信息交换。
  - **端口号**：UDP **520**

## 基于TCP
### [[BGP]]
`Border Gateway Protocol，边界网关协议`
  - **应用**：在不同自治系统（AS）之间交换路由信息，是互联网核心路由协议，负责域间选路。
  - **端口号**：TCP **179**

### [[HTTP]]
`HyperText Transfer Protocol，超文本传输协议`
  - **应用**：Web服务器与客户端（浏览器）之间传输超文本（网页），是万维网的基础。
  - **端口号**：TCP **80**（HTTP），TCP **443**（HTTPS，HTTP over TLS/SSL）

### [[FTP]]
`File Transfer Protocol，文件传输协议`
  - **应用**：在网络上进行可靠的文件上传与下载，支持用户认证与目录操作。
  - **端口号**：TCP **21**（控制连接，传命令），TCP **20**（数据连接主动模式，服务器端），被动模式数据连接端口由服务器协商后指定。

### [[电子邮件|SMTP]]
`Simple Mail Transfer Protocol，简单邮件传输协议`
  - **应用**：从邮件客户端向服务器发送邮件，或服务器之间中继转发邮件，属于“推送”协议。
  - **端口号**：TCP **25**（默认），TCP **587**（提交，通常需认证），TCP **465**（SMTPS，过时但仍用）

### [[电子邮件|POP3]]
`Post Office Protocol version 3，邮局协议版本3`
  - **应用**：从邮件服务器将邮件下载到本地客户端，下载后默认删除服务器副本，适合单设备管理。
  - **端口号**：TCP **110**（默认），TCP **995**（POP3 over SSL）

# 二、网络层

- **ICMP（Internet Control Message Protocol，互联网控制报文协议）**
  - **应用**：用于传递错误报告（如目的不可达、超时）和网络诊断信息（如ping用的回显请求/应答、traceroute依赖的超时报文）。
  - **端口号**：无端口概念，封装在IP数据报中，IP协议号 **1**。

- **OSPF（Open Shortest Path First，开放最短路径优先）**
  - **应用**：内部网关协议，基于链路状态算法，支持区域划分，适用于大型企业网络，收敛速度快。
  - **端口号**：无传输层端口，直接封装在IP包中，IP协议号 **89**。

- **IGMP（Internet Group Management Protocol，互联网组管理协议）**
  - **应用**：在主机与直连路由器之间管理多播组成员关系，主机通过它通知路由器加入或离开某个多播组。
  - **端口号**：无端口，封装在IP中，IP协议号 **2**。

# 三、数据链路层

- **PPP（Point-to-Point Protocol，点对点协议）**
  - **应用**：在两节点间通过串行链路建立直接的数据链路，曾广泛用于拨号上网，也用于广域网和PPPoE。
  - **补充**：零比特填充法对应同步链路 / 字节填充法对应异步链路

- **802.3 局域网（IEEE 802.3，以太网）**
  - **应用**：定义有线局域网物理层与MAC子层规范，是应用最广泛的局域网技术。
  - **端口号**：无（数据链路层帧，使用MAC地址寻址）
  - **补充**：早期使用CSMA/CD半双工（现已多全双工交换式以太网）；帧格式包含目标MAC、源MAC、类型/长度字段；速率从10Mbps发展到400Gbps。

- **802.11 无线局域网（IEEE 802.11，Wi-Fi）**
  - **应用**：定义无线局域网物理层与MAC子层，实现无线接入，支持移动设备互联。
  - **端口号**：无（数据链路层帧，使用MAC地址）
  - **补充**：MAC采用CSMA/CA避免冲突，支持DCF和PCF，提供RTS/CTS机制；802.11b/a/g/n/ac/ax等标准在频段、速率、调制上不断演进。
