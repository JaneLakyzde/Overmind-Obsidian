# 路由器
`router` 也叫网关 `Gateway` 
### 路由选择部分
路由选择处理机:
根据其所选择的[[路由选择]]协议, 周期性的更新路由表
路由表只包含目的网络到下一跳的映射
路由表需要对网络拓扑变化的计算最优化
除了处理自己收到的路由信息, 也会发送自己的路由信息
### 分组转发部分

转发表1结构应当使查找过程最优化
1. 交换结构
2. 输入端口(+输出 缓冲区)
3. 输出端口(+输出缓冲区)

	一个数据包进入路由器各个层的具体流程
	1. 物理层: 将信号转换成比特流
	2. 数据链路层: 从比特流中识别出帧并去掉帧头帧尾
	3. 网络层: 
		普通待转发数据分组根据转发表转发
		路由报文交送路由选择处理机
	4. 网络层: 更新首部中某些字段的值
	5. 数据链路层: 封装成帧
	6. 物理层: 将帧转化为电信号
# 知识点
- 碰撞域 Collision Domain vs 广播域 Broadcast Domain
	碰撞域: 在同一范围内，如果两个设备同时发送数据，就可能发生冲突的区域
	广播域: 一个广播帧能够到达的所有设备范围
