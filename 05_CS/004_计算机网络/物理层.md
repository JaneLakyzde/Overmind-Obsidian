# 计算机网络 - 物理层 (Physical Layer) 学习总结

> 物理层是OSI参考模型的第一层，它定义了网络通信最基础的部分。它的核心任务是在**物理信道**上传输原始的比特流（0和1）。需要明确的是，物理层关注的是**信道**，而不仅仅是物理**介质**。信道是信号传输的路径，包含了介质、编码、电压标准等一系列规则。

---

## 1. 传输介质 (Transmission Media)

传输介质是承载数据信号的物理实体。

- **双绞线 (Twisted Pair)**
  - **非屏蔽双绞线 (UTP - Unshielded Twisted Pair)**: 最常用，如超五类，使用 **RJ45** 水晶头。
  - **屏蔽双绞线 (STP - Shielded Twisted Pair)**: 内部有金属屏蔽层，抗干扰能力更强。
  - **RJ11 连接器**: 通常用于电话线，比 RJ45 窄。

- **同轴电缆 (Coaxial Cable)**
  - 由中心铜导体、绝缘层、网状屏蔽层和外层护套构成，抗干扰性和带宽高于双绞线。常用于有线电视。

- **光纤 (Fiber Optic Cable)**
  - 利用光的全反射原理传输光信号，具有带宽高、距离远、抗电磁干扰能力极强的优点。
  - **单模光纤 (Single-mode)**: 纤芯细，只传输一种模式的光，衰减小，适合长距离传输。
  - **多模光纤 (Multi-mode)**: 纤芯粗，可传输多种模式的光，衰减大，适合短距离传输（如楼宇内部）。

## 2. 以太网传输命名标准

以太网的命名遵循一定格式，例如 `1000BASE-T`，可以拆解为以下几个部分：

| 部分       | 含义                                                 | 示例 (`1000BASE-T`)                       |
| :------- | :------------------------------------------------- | :-------------------------------------- |
| **传输速率** | 数据的传输速率，单位是 **Mbps** (兆比特每秒)。                      | `1000` -> 1000 Mbps (即 1 Gbps)          |
| **调制方式** | 信号的传输方式。                                           | `BASE` -> **基带 (Baseband)** 信号，信道一对一专用。 |
|          | `BROAD` -> **宽带 (Broadband)** 信号，可将信道划分为多个子信道，一对多。 |                                         |
| **传输媒介** | 指示所使用的物理介质。                                        | `-T` -> 双绞线 (Twisted Pair)              |
|          | `-F` 或 `-FX` -> 光纤 (Fiber)                         |                                         |
| **编码体系** | 数据比特流到信号的编码方案。                                     | `-X` -> **8B/10B** 编码 (用于千兆以太网)         |
|          | `(空)` -> 曼彻斯特编码 (用于早期以太网)                          |                                         |
|          | `-TX` -> 包含多种编码方案，如 4B/5B (用于快速以太网)                |                                         |
|          | `-R` -> 64B/66B 编码 (用于万兆以太网)                       |                                         |

## 3. 数据通信基础理论

### 3.1. 基本概念

- **码元 (Symbol)**: 在数字通信中，一个固定时长的信号波形（例如某个电压电平）是承载信息的基本单位。一个码元可以表示一个或多个比特。
- **波特率 (Baud Rate)**: 也称码元速率，表示**每秒钟传输多少个码元**。单位是**波特 (Baud)**。
- **比特率 (Bit Rate)**: 表示**每秒钟传输多少个比特**。单位是**比特每秒 (b/s 或 bps)**。
- **关系**: `比特率 = 波特率 * log₂(N)`，其中 `N` 是一个码元所能表示的不同状态（离散值）的数量。例如，如果一个码元有4种电平状态（00, 01, 10, 11），那么N=4，每个码元可以携带 `log₂(4) = 2` 个比特。

### 3.2. 两个关键定理

#### 奈奎斯特定理 (Nyquist's Theorem) - 无噪声信道
- **定义**: 在理想的、无噪声的信道中，为避免码间串扰，码元速率的极限值 `B` 为信道带宽 `H` 的两倍。
- **码元速率极限**: $B = 2H$ (Baud)
- **信道容量极限 (C)**: $C = 2H \log_2(N)$ (b/s)
  - `H`: 信道带宽，单位是赫兹 (Hz)。
  - `N`: 一个码元可以取的离散值的个数。

#### 香农定理 (Shannon's Theorem) - 有噪声信道
- **定义**: 在存在高斯白噪声的信道中，无论采用何种编码技术，信息的最大传输速率（信道容量）有一个无法超越的上限。
- **信道容量极限 (C)**: $C = H \log_2(1 + S/N)$ (b/s)
  - `H`: 信道带宽，单位是赫兹 (Hz)。
  - `S/N`: **信噪比 (Signal-to-Noise Ratio)**，即信号的平均功率与噪声的平均功率之比。
- **分贝 (dB) 与信噪比换算**: $信噪比(dB) = 10 \log_{10}(S/N)$

## 4. 编码与调制

### 4.1. 数字信号编码 (Line Coding)
将数字数据（比特流）转换为数字信号（电压跳变）的过程。

- **不归零编码 (NRZ)**: 用两种不同的电压（如+5V和-5V）分别表示1和0。无法区分长串的0或1，难以同步。
- **反向不归零编码 (NRZI)**: **信号翻转表示0，保持不变表示1**。解决了长串1的同步问题，但长串0的问题仍在。
- **归零编码 (RZ)**: 每个码元中间都会**返回到零电平**。自带同步信号，但编码效率低，因为一半时间电平为零。
- **曼彻斯特编码 (Manchester)**: 每个码元中间都有一次电平跳变。**从低到高跳变表示0，从高到低跳变表示1**。自带同步，是以太网早期标准。
- **差分曼彻斯特编码 (Differential Manchester)**: 每个码元中间跳变用于同步。码元开始处的**边界是否有跳变**用来表示数据：**有翻转表示0，无翻转表示1**。

### 4.2. 数字调制 (Digital Modulation)
将**数字信号**转换为**模拟信号**，以便在模拟信道（如无线电）上传输。
- **调幅 (ASK)**: 用载波的**振幅**变化来表示0和1。
- **调频 (FSK)**: 用载波的**频率**变化来表示0和1。
- **调相 (PSK)**: 用载波的**相位**变化来表示0和1。
- **正交振幅调制 (QAM)**: 结合了调幅(ASK)和调相(PSK)，在同一频率下通过改变振幅和相位的组合来表示更多的比特，传输效率更高。

## 5. 数据交换方式 (Data Switching)

- **电路交换 (Circuit Switching)**
  - **过程**: 1. 建立连接 -> 2. 传输数据 -> 3. 断开连接。
  - **特点**: 在通信期间**独占物理线路**，时延稳定，可靠性高。
  - **例子**: 传统的电话网络。

- **报文交换 (Message Switching)**
  - **特点**: 以完整的**报文 (Message)**为单位进行存储转发，无需预先建立连接。
  - **缺点**: 报文大小不一，导致网络节点需要大量缓存，且时延不确定。

- **分组交换 (Packet Switching)**
  - **特点**: 将大的报文**分割成大小固定或上限固定的小数据包 (Packet)**，每个包独立选择路径进行存储转发。是现代互联网的核心交换方式。
  - **优点**: 线路利用率高，更加灵活和高效。

## 6. 信道复用技术 (Channel Multiplexing)
允许多路用户共享同一个信道。

- **频分复用 (FDM - Frequency Division Multiplexing)**
  - **原理**: 按**频率**划分信道，每个用户分配一个独立的频段。
  - **例子**: 收音机、电视台，不同频道占用不同频率。

- **时分复用 (TDM - Time Division Multiplexing)**
  - **原理**: 按**时间**划分信道，将时间划分为一个个**时间片 (Time Slot)**，轮流分配给不同用户。
  - **例子**: 早期的数字电话系统、对讲机。

- **波分复用 (WDM - Wavelength Division Multiplexing)**
  - **原理**: 光的频分复用，在一根光纤中同时传输多种**不同波长**的光信号。
  - **例子**: 现代骨干网光纤通信。

- **码分复用 (CDM - Code Division Multiplexing)**
  - **原理**: 为每个用户分配一个唯一的、相互**正交 (Orthogonal)** 的**码片序列 (Chip Sequence)**。所有用户可以在同一时间和频率上传输信号，通过码片来区分。
  - **例子**: 3G移动通信（CDMA技术）、GPS。
  - **码片特性**:
    - 一个比特被扩展为多个码片（如64或128）。
    - 任意码片序列 `S` 与自身归一化内积为 **1**。
    - `S` 与其反码 `-S` 归一化内积为 **-1**。
    - 任意两个**不同**的正交码片序列 `S` 和 `T`，归一化内积为 **0**。

## 7. 物理层接口的四个特性
物理层接口标准（如RS-232）通常定义以下四个方面的特性：

1.  **机械特性 (Mechanical)**: 定义接口的物理尺寸、引脚数量和排列方式等。 (例如：RJ45接口是8个引脚)
2.  **电气特性 (Electrical)**: 定义信号的电压电平、传输速率和距离限制等。 (例如：高电平为+5V，低电平为-5V)
3.  **功能特性 (Functional)**: 定义各条引脚线（信号线）的功能。 (例如：某引脚是数据发送，某引脚是数据接收)
4.  **规程特性 (Procedural)**: 定义事件的发生顺序，即信号和控制的交互流程。 (例如：数据传输的握手协议)
