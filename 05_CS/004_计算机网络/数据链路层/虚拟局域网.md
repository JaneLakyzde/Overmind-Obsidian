# 虚拟局域网的实现机制

VLAN 是一种将局域网内的设备划分成与物理位置无关的逻辑组的技术, 这些逻辑组具有某些共同的需求

交换机需要的功能:
## 1. 需要能处理 IEEE 802.1Q帧
对以太网 MAC 帧 扩展 (最大长度 1522字节) 插入了 4 字节的 VLAN 标记
VLAN 标记的最后 12 比特 称为VLAN标识符 VID, 唯一标志了以太网帧属于哪一个VLAN
VID 的有效取值范围 ( 1 ~ 4094 )  
802.1Q 帧是由交换机来处理的, 打标签和去标签都是交换机进行的 

## 2. 交换机端口支持不同的端口
#### 1. Access
一般用于连接用户计算机, 只属于一个VLAN, PVID值 与端口所属 VLAN 的 ID 相同
若收到的帧中的VID与端口的PVID相等, 则去标签并转发该帧, 否则不转发
#### 2. Trunk
#### 3. Hybrid ( 思科没有 )
交换机各端口的缺省VLAN ID, 可以称为本征VLAN 或 PVID
