- BGP 全称 `Border Gateway Protocol`（边界网关协议），当前版本为 BGP-4
- 属于 `Exterior Gateway Protocol`（外部网关协议）
- 不关注最佳路径, 只求得一个可行路径即可, 构造不存在回路的自治系统连通图
- 邻居数量少, 路由表巨大, BGP会话长期保持, 因此使用 [[TCP]] 

---

# 发言人与对等关系
- **BGP 发言人**：运行 BGP 协议的路由器，常被称为 BGP 边界路由器。
- 两个 BGP 发言人之间通过 [[TCP]] 交互，目的端口号为 179
  原因：BGP 需要可靠的传输承载大量路由信息，直接利用 TCP 的重传、排序和确认机制。
- **建立 BGP 会话**：  
  在 TCP 连接之上，交互 **OPEN** 报文交换参数，建立 BGP 对等会话。
- **邻站 / 对等站 (`Peer`)**：  
  成功建立 BGP 会话的两台路由器互为对等体。  
  - **`EBGP` (`External BGP`)**：位于不同 AS 之间的对等体。  
  - **`IBGP` (`Internal BGP`)**：位于同一 AS 内部的对等体。
- 建立对等关系后，通过 **UPDATE** 报文交换路由信息。

## 交换网络可达性信息，形成无环的 AS 级路径图
- **网络可达性信息 (`Network Layer Reachability Information`, NLRI)**：  
  本质上就是“到达哪些网络前缀可以怎么走”。BGP 通过 UPDATE 报文携带 NLRI 及路径属性。
- **构造树形结构？**  
  原提纲说“构造树形结构，不存在回路的自治系统连通图”，更准确的表述是：  
  BGP 在 AS 级别上运行**路径向量**算法，通过 **AS_PATH** 属性避免环路，最终形成一张**无环的自治系统连通图**。这不是严格的树，而是一个无环有向图，因为一个 AS 可以从多个邻居收到去往同一目的地的多条路径。

---

## 路径向量
`Path Vector`
- BGP 是路径向量协议，区别于距离向量（RIP）和链路状态（OSPF）。
- 每条路由会携带一个 `AS_PATH` 属性，记录该路由信息已依次经过的 AS 号列表。
- 防环规则
  当 BGP 发言人收到一条路由时，若 `AS_PATH` 列表中已包含自己的 AS 号，则丢弃该路由。从而保证整个 AS 级路径绝对无环。
- 选路依据
  除了 `AS_PATH` 长度，BGP 还综合考虑多种路径属性（见下文），执行固定的选路规则。

## 四种报文类型
BGP 报文头部固定 19 字节，以下报文作为 TCP 的数据部分传输。

| 报文类型           | 全称              | 作用                                                          |
| -------------- | --------------- | ----------------------------------------------------------- |
| `OPEN`         | Open 报文         | 建立 BGP 会话。协商版本、AS 号、Hold Time、BGP ID 等参数。是 TCP 连接后的第一条报文。   |
| `UPDATE`       | Update 报文       | 核心报文。用于通告新路由或撤销失效路由。<br>包含路径属性和 NLRI。                       |
| `KEEPALIVE`    | Keepalive 报文    | 仅含 19 字节 BGP 头部。用于维持会话活性，周期性发送（默认每 **60 秒**），重置 Hold Timer。 |
| `NOTIFICATION` | Notification 报文 | 差错通知。携带错误码和子码，发送后立即关闭 BGP 连接。                               |

**补充计时器**：  
- **Hold Time**：在 OPEN 报文中协商，默认 180 秒。若在此时间内未收到对端 KEEPALIVE 或 UPDATE，会话断开。
