**NAT（Network Address Translation，网络地址转换）** 是一种在 IP 数据报经过路由器时，
**修改其源 IP 地址和/或目的 IP 地址**的技术。
通常还伴随修改端口号，这时叫 **NAPT**。
核心作用：
> **让使用私有地址的内部网络主机能够访问公网，同时缓解 IPv4 地址枯竭，并隐藏内部网络结构。**

---

## 1. 为什么需要 NAT？

IPv4 地址只有 32 位，公网地址不够用。  
私有地址可以在不同内部网络重复使用，但不能出现在公网。

私有地址范围：

| 范围 | 前缀 |
|---|---|
| 10.0.0.0 ~ 10.255.255.255 | 10.0.0.0/8 |
| 172.16.0.0 ~ 172.31.255.255 | 172.16.0.0/12 |
| 192.168.0.0 ~ 192.168.255.255 | 192.168.0.0/16 |

内部主机用私有地址，出口路由器做 NAT，把私有地址转换成公网地址。

---

## 2. NAT 的基本原理

NAT 通常运行在**私有网络与公网边界路由器**上。
当内部主机发数据到公网：

1. 数据包源 IP 是私有地址；
2. NAT 路由器把源 IP 改成自己的公网 IP；
3. 如果使用 NAPT，还要把源端口改成一个新端口；
4. 路由器记录映射关系；
5. 公网回包到达时，根据映射表反向转换，送回内部主机。

---

## 3. NAT 的主要类型

| 类型 | 特点 | 说明 |
|---|---|---|
| 静态 NAT | 一对一，固定映射 | 内部一个私有 IP 永久映射到一个公网 IP |
| 动态 NAT | 一对一，从地址池分配 | 内部主机临时占用一个公网 IP |
| NAPT / PAT | 多对一，用端口区分 | 多个内部主机共享一个公网 IP，最常用 |

**NAPT（Network Address Port Translation）** 也叫 **PAT（Port Address Translation）**，是 NAT 最常见的形式。

它不只改 IP，还改端口，例如：
```
内部：192.168.1.2:1234
NAT 公网：202.1.1.1
转换后：202.1.1.1:5001
```

映射表：
```
192.168.1.2:1234  <->  202.1.1.1:5001
```

公网回包：
```
8.8.8.8:80 -> 202.1.1.1:5001
```

NAT 查表后改成：
```
8.8.8.8:80 -> 192.168.1.2:1234
```

这样，多个内部主机可以共用一个公网 IP，靠不同端口区分。

---
## 4. NAT 的优缺点

### 优点

- 节省公网 IPv4 地址；
- 隐藏内部网络结构，提高一定安全性；
- 内部网络编址灵活，可用私有地址；
- 部署简单，广泛用于家庭、企业、校园网。

### 缺点

- 破坏端到端通信透明性；
- 外部主机不能直接主动访问内部主机，除非配置端口映射或静态 NAT；
- 某些应用层协议需要 ALG 支持，如 FTP、SIP；
- 对 IPsec 等加密协议可能不友好；
- 增加转换开销和延迟；
- 修改 IP/TCP/UDP 首部，需要重新计算校验和。

## NAT 的过程
### 出站
```text
内部主机 192.168.1.2:1234
        |
        | 源：192.168.1.2:1234 -> 8.8.8.8:80
        v
NAT 路由器
        |
        | 改源 IP/端口，记录映射
        | 源：202.1.1.1:5001 -> 8.8.8.8:80
        v
公网服务器 8.8.8.8:80
```
### 入站
```text
公网服务器 8.8.8.8:80
        |
        | 源：8.8.8.8:80 -> 202.1.1.1:5001
        v
NAT 路由器
        |
        | 查映射，改目的 IP/端口
        | 源：8.8.8.8:80 -> 192.168.1.2:1234
        v
内部主机 192.168.1.2:1234
```

## 6. 408 考研常考点

1. NAT 作用：私有地址与公网地址转换，缓解 IPv4 地址不足, 私有IP地址不能直接用于互联网
2. NAT 路由器通常位于内部网络与 Internet 边界
3. NAPT 用端口号区分多个内部主机，实现多对一。
4. 转换过程：改源 IP/端口，记录映射，回包反向转换。
5. 私有地址范围：10/8、172.16/12、192.168/16。
6. 外部不能直接访问内部，需静态 NAT 或端口映射。
7. NAT 修改 IP 首部，需重算校验和。
8. NAT 对上层协议有影响，某些协议需 ALG。

---

## 7. 一句话总结

**NAT 是在私有网络与公网边界处，通过修改 IP 数据报的源/目的 IP 地址和端口，实现私有地址与公网地址转换的技术；它节省公网 IPv4 地址、隐藏内部网络，最常见的形式是 NAPT，即多个内部主机共享一个公网 IP，用端口号区分。**
