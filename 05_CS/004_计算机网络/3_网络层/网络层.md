## 异构网络

异构网络是指由不同类型的网络互联而成的网络系统。通常情况下，这些网络在物理层或数据链路层所采用的技术不同，例如以太网、无线局域网、移动通信网等，但它们可以通过统一的网络层协议，如 IP 协议，实现互联互通。路由器在不同链路层网络之间转发 IP 数据报时，会根据目的 IP 地址进行路由选择，而不要求各个底层网络使用相同的数据链路层协议。若网络层协议也不同，则通常需要网关或协议转换机制才能实现通信。

- 路由器连接多个局域网时，各局域网的物理层和数据链路层协议可以不同，例如一个局域网使用以太网，另一个局域网使用无线局域网。路由器在转发时会去掉原链路层帧头，取出网络层数据报，再根据输出接口重新封装成相应链路层帧。

- 普通路由器实现互联时，网络层通常需要使用相同的协议，例如都使用 IP 协议，路由器根据目的 IP 地址进行转发。如果网络层协议不同，则通常需要网关或协议转换机制。

- 网络层以上的协议不是各局域网都必须相同，而是通信双方的端系统需要使用相同或兼容的传输层和应用层协议。中间的路由器一般只处理网络层，不关心传输层和应用层内容。
