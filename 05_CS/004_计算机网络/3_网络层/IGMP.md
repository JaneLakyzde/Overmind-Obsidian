**IGMP（Internet Group Management Protocol，网际组管理协议）** 
是 **[[IPv4]] 中用于组播组成员管理**的协议, 协议号为 2

它的核心作用是：

> **让主机告诉本地组播路由器：我要加入/离开哪个组播组；让路由器知道哪些组播组在哪些接口上还有成员。**

注意：IGMP 只负责**主机 ↔ 直连组播路由器**之间的组成员管理，**不负责在路由器之间传播组播路由**。
路由器之间用什么协议传播组播路由，是 PIM、DVMRP、MOSPF 等组播路由协议的事。

---
# 1. 工作层次与封装

- IGMP 报文封装在 **IP 数据报**中；
- IP 协议号：**2**；
- TTL 通常为 **1**，因为只在本地网络内使用；
- 组播地址：IGMP 查询发往 `224.0.0.1`（所有主机组）。

---

# 2. 主要功能

1. **加入组播组**  
   主机想接收某个组播组数据时，发送成员关系报告，声明加入。

2. **维护组成员关系**  
   组播路由器周期性地发送查询，主机回复报告，路由器据此维护组员列表。

3. **离开组播组**  
   主机要离开时发送离开组消息，路由器再发特定组查询，确认是否还有成员。

---

# 3. IGMP 版本

| 版本     | 特点                             |
| ------ | ------------------------------ |
| IGMPv1 | 只有查询和报告，没有离开消息，路由器靠超时判断成员离开    |
| IGMPv2 | 增加离开组消息、特定组查询，减少离开延迟           |
| IGMPv3 | 支持源特定组播 SSM，主机可指定只接收某些源发往该组的数据 |

目前常用的是 IGMPv2 和 IGMPv3。

---

# 4. 典型报文类型

- **成员关系查询**  
  - 一般查询：询问所有组是否有成员；
  - 特定组查询：询问某个组是否还有成员。
- **成员关系报告**  
  主机回复，表示自己要加入或仍在某个组。
- **离开组**  
  主机告诉路由器自己要离开某个组。

---

# 5. 简单工作过程

1. 组播路由器周期性向 `224.0.0.1` 发送一般查询；
2. 主机收到后，如果对某些组感兴趣，延迟随机时间后发送报告；
3. 路由器收到报告，知道对应接口下有该组成员；
4. 主机加入时也可主动发送报告；
5. 主机离开时发送离开组消息；
6. 路由器收到离开后，发送特定组查询，确认是否还有成员；
7. 如果没人响应，路由器就停止向该接口转发该组数据。

---

# 6. IGMP 与组播路由协议的区别

| 对比项    | IGMP         | 组播路由协议          |
| ------ | ------------ | --------------- |
| 作用     | 管理本地组成员      | 在路由器之间建立组播转发路径  |
| 通信双方   | 主机 ↔ 直连组播路由器 | 路由器 ↔ 路由器       |
| 范围     | 本地网络         | 整个组播网络          |
| 典型协议   | IGMPv1/v2/v3 | PIM、DVMRP、MOSPF |
| 是否传播路由 | 不传播          | 传播组播路由          |

一句话：

> **IGMP 让路由器知道“谁要收”；组播路由协议让路由器知道“怎么把数据送过去”。**

---

# 7. 408 考研可能考点

- IGMP 是 **IPv4 组播组成员管理协议**；
- 封装在 **IP** 中，协议号 **2**；
- 工作在 **主机和直连组播路由器**之间；
- 不是组播路由协议；
- IGMPv2 增加离开组消息；
- IGMPv3 支持源特定组播；
- 查询目的地址常为 `224.0.0.1`；
- TTL 通常为 1。
