# 差错报告报文
用于向源主机报告传输错误，常见类型：
3. 终点不可达
	路由器或主机无法交付数据报
	
4. 源点抑制
	拥塞时通知源点降速（已废弃
	
5. 改变路由
	路由优化, 通知主机下次走更好的路由
	
11. 时间超过
	TTL 减为 0 或分片重组超时
	
12. 参数问题
	IP 首部字段有误
	[[差错控制|首部校验和]]出错字节丢弃不发送

**不发送 ICMP 差错报告的情况**：
- 对 ICMP 差错报文不会再生成 ICMP 差错报文
- 对非第一个分片的数据报不发送
- 对多播地址、回环地址、默认地址的数据报不发送
- 首部校验和出错接收方会直接丢弃该数据报不发送
# 询问报文

- 回送请求和回答报文
	向特定目的主机发出询问, 收到报文的主机必须回送回答报文
	用来测试目的站是否可达并了解其有关状态
	例如: [[ping]]
	
- 时间戳请求和回答报文
	请某个主机回答当前的日期和时间, 精确到秒
	用来进行时钟同步和测量时间
	例如: traceroute 跟踪路由
