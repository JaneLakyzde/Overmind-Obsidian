# 差错报告报文

- 终点不可达
- 源点抑制
	拥塞
- 时间超过
	TTL 超时
- 参数问题
	格式问题
	[[差错控制|首部校验和]]出错字节丢弃不发送!!
- 改变路由
	路由优化


- 对 ICMP 差错报文不会再生成 ICMP 差错报文
- 对 后续数据报片 不发送 ICMP 差错报文
- 对 多播地址、回环地址、默认地址的数据报, 不发送 ICMP 差错报文
# 询问报文

- 回送请求和回答报文
- 时间戳请求和回答报文

# 应用

- 分组网间探测 [[ping]] 
	回送请求问答报文
- 跟踪分组路由 Traceroute
	回送请求问答报文 + 时间超过报文
