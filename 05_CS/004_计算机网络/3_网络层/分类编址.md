# 1. 分类编址
`1981`

| 类别     | 首位标识   | 默认子网掩码          | **可用网络号数量** | **最大主机数(-2)**  | **可用网络号范围**                         |
| :----- | :----- | :-------------- | :---------- | :------------- | :---------------------------------- |
| **A类** | `0` 开头 | `255.0.0.0`     | **126** 个   | **16,777,214** | **1.0.0.0** ~ **126.0.0.0** <br>    |
| **B类** | `10`   | `255.255.0.0`   | **2^14** 个  | **65,534**     | **128.0.0.0** ~ **191.255.0.0**     |
| **C类** | `110`  | `255.255.255.0` | **2^21**个   | **254**        | **192.0.0.0** ~ **223.255.255.0**   |
| **D类** | `1110` | **无** (多播地址)    | **不支持**     | **不支持**        | **224.0.0.0** ~ **239.255.255.255** |
| **E类** | `1111` | **无** (保留地址)    | **不支持**     | **不支持**        | **240.0.0.0** ~ **255.255.255.255** |
- A类 网络号全 0 用来表示默认网络(本网络/默认网关)
	0.0.0.0 只能作为源地址使用, 表示本网络上的本主机, 如 [[DHCP]] 报文
	
- A类 网络号`127`即`0111 1111`来表示本地软件环回测试本主机
	可以作为源地址和目的地址, 用于本地环回测试
	
- 主机号全0表示该IP地址是本主机所连接到的单个网络地址
	
- 主机号全1表示该网络上的所有主机 (广播地址)
	255.255.255.255 表示本网络上进行转发

# 2. 子网划分
`1985`
从主机位借用几个比特位来划分成子网
网络号 + 子网号 + 主机号
子网中最少也要留两位主机号
### 子网掩码
划分子网的工具, 连续的比特1对应网络号和子网号, 连续的比特0对应主机号 
默认的子网地址就是对应网络号全划为1
### 定长子网划分

### 变长子网划分
全称：Variable Length Subnet Mask，可变长子网掩码。
特点：**不同子网使用不同长度的掩码**，按实际需求分配大小。

类比“[[哈夫曼编码]]”

- 哈夫曼编码：频率高的字符用短码，频率低的用长码；
    
- VLSM：需求大的子网用短前缀、大地址块；需求小的子网用长前缀、小地址块；
    
- 二者都要求前缀不重叠，类似前缀码。
    

VLSM 划分步骤：

1. 按需求从大到小排序；
    
2. 先给大需求分配大地址块；
    
3. 再给小需求分配小地址块；
    
4. 保证各子网地址不重叠。
    

例子：有 `192.168.1.0/24`，需求：

|部门|需要主机数|需要主机位|前缀|分配子网|
|---|---|---|---|---|
|A|100|7 位，`2^7-2=126`|/25|192.168.1.0/25|
|B|50|6 位，`2^6-2=62`|/26|192.168.1.128/26|
|C|20|5 位，`2^5-2=30`|/27|192.168.1.192/27|
|D|2|2 位，`2^2-2=2`|/30|192.168.1.224/30|

# 3. 无分类编址 CIDR
`1993`
`Classless Inter-Domain Routing` 无类别域间网络
## 1. 基本概念

CIDR：Classless Inter-Domain Routing，无类别域间路由。

思想：

```text
网络前缀 + 主机号
```

表示法：

```
text

192.168.1.0/24
```

其中 `/24` 表示前 24 位是网络前缀，后 8 位是主机号。

CIDR 不再区分 A/B/C 类，前缀长度可以是任意值，如 `/13`、`/22`、`/27`。

---

## 2. CIDR 地址块

一个 CIDR 地址块包含：

- 起始地址；
    
- 前缀长度 `/n`；
    
- 地址数：`2^(32-n)`；
    
- 可用主机数：通常 `2^(32-n) - 2`，但 CIDR 中网络地址和广播地址概念仍存在。
    

例如：

```text
192.168.1.0/24
地址数：2^8 = 256
可用主机：254
```

---
## 3. 路由聚合

也叫超网划分。
做法：**找多条路由的共同前缀，合并成一条更短前缀的路由。**
好处：减小路由表长度，提高转发效率。

## 4. 最长前缀匹配

当目的 IP 有多条路由匹配时，选择**前缀最长、最具体**的那条。

# 定长 vs 变长 vs CIDR

|对比项|定长子网划分|变长子网划分 VLSM|CIDR|
|---|---|---|---|
|掩码长度|所有子网相同|不同子网可不同|任意前缀长度|
|地址利用率|较低|较高|高|
|灵活性|差|好|很好|
|主要用途|传统子网划分|按需分配子网|路由聚合、无类编址|
|类比|等长编码|哈夫曼编码|前缀路由|
