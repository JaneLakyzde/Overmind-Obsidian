## OSPF 协议与 Dijkstra 最短路径优先

OSPF 是一种基于**链路状态**的内部网关协议
它使用 **Dijkstra（迪杰斯特拉）[[最短路径优先]] (`Shortest Path First`, SPF) 算法** 来计算路由
- 需要使用组播地址发现邻居和实现泛红LSA, TCP不支持
- 邻居众多, 使用 TCP 建立连接开销大
- OSPF 的 LSA 自己有可靠性实现, 于是直接封装在 [[IPv4|IP]] 中

---

## 链路状态

- **链路状态 = 相邻路由器 + 相应链路的“代价”**
  - 代价可以是：费用、距离、时延、**带宽**（原笔误“贷款”应为带宽）等。
- 路由器通过交换**链路状态通告**，让全网了解自己周围的拓扑信息，最终每个路由器都能得到一张完全相同的网络拓扑图。

---

## 邻居关系的建立与维护

通过交互 **Hello 分组**来发现、建立并维持邻居关系。

- **Hello 分组的封装与发送**
  - 封装在 IP 数据报中，包含 OSPF 首部 + OSPF 分组载荷。
  - 发往组播地址 **224.0.0.5**（所有 OSPF 路由器均侦听此地址）。
- **Hello 定时器**
  - 默认每 **10 秒** 发送一次 Hello 报文。
  - 若 **40 秒**内未收到邻居的 Hello 报文，则判定该邻居路由器不可达，邻居关系中断

---

## 链路状态通告 
(`Link State Advertisement`, LSA)

**LSA** 是 OSPF 传递链路状态信息的基本单元，内容包括：
- 直连网络的链路状态信息；
- 邻居路由器的链路状态信息。

**洪泛法传递**：
- LSA 被封装在 **链路状态更新分组 (`Link State Update`, LSU)** 中，采用**可靠的洪泛法**发送至区域内的所有路由器，以保证数据库同步。

---

## 链路状态数据库 
(`Link State Database`, LSDB)

- 每个运行 OSPF 的路由器都维护着一个完全相同的 **LSDB**。
- 路由器基于 LSDB，利用 **Dijkstra SPF 算法** 计算出以自己为根的**最短路径树**，进而构建出各自的路由表。
- SPF 计算保证无环，且支持等价负载分担。

---

## OSPF 的五种分组

| 分组类型  | 英文全称                     | 中文释义     | 主要作用                       |
| ----- | ------------------------ | -------- | -------------------------- |
| Hello | （无标准缩写的全称，即 `Hello`）     | 问候分组     | 建立、维护邻居关系，选举 DR/BDR        |
| DD    | `Database Description`   | 数据库描述分组  | 对 LSDB 进行简要描述，用于主从路由器间同步目录 |
| LSR   | `Link State Request`     | 链路状态请求分组 | 向邻居请求缺少的 LSA 详细信息          |
| LSU   | `Link State Update`      | 链路状态更新分组 | 携带完整的 LSA，用于洪泛链路状态信息       |
| LSAck | `Link State Acknowledge` | 链路状态确认分组 | 对收到的 LSU 进行可靠确认，保证洪泛可靠性    |

## DR/BDR
指定路由器 `Designated Router` 与 备用指定路由器 `Backup Designated Router`

- **目的**：多路访问网络（如以太网）中，避免所有路由器之间形成全互连邻居关系，从而减少 LSA 洪泛开销。
- **工作机制**：
  - 所有非 DR/BDR 的路由器 **仅与 DR 和 BDR 建立邻接关系**，邻居间的链路状态信息也只需和 DR/BDR 交换。
  - BDR 作为 DR 的热备份，一旦 DR 失效立即接管工作，保证网络稳定。
- 选举基于接口优先级和 Router ID，Hello 分组中携带相应字段。

## 区域划分

OSPF 支持将**自治系统 (`Autonomous System`, AS)** 划分为多个更小的**区域 (`Area`)**，以限制洪泛范围，降低路由开销。

- **主干区域 (`Backbone Area`)**  
  - 区域号为 0（Area 0），负责在不同区域间转发路由信息。
- **其他常规区域**
  - 洪泛法被限定在**单个区域内**，区域内部的拓扑变化不会影响到其他区域，显著减少通信量和 SPF 重计算的频率。
- **关键路由器角色**
  - **区域边界路由器 (`Area Border Router`, ABR)**  
    连接一个或多个区域到主干区域的路由器，通常也称其为**主干路由器**（原笔误“猪肝路由器”）。ABR 负责区域间路由的汇总与传递。
  - **自治系统边界路由器 (`Autonomous System Boundary Router`, ASBR)**  
    负责将 OSPF 网络与外部路由域（如其他 AS 的路由协议）连接，引入外部路由信息。
