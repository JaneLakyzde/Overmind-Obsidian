# 核心特征
- **距离向量** `Distance Vector`, D-V
	每个路由器只维护到所有目的网络的**距离**和**方向**
	并与邻居周期性地交换整个路由表。
- **度量值**  
	以 跳数 `Hop Count`作为唯一的路由优劣标准。  
	- 直接相连的网络跳数为 0（通告时加 1 变为 1）
	- 最大有效跳数为 15  (16 代表网络不可达)
- **等价负载均衡** `Equal-Cost Load Balancing`
	RIP 支持将多条跳数相等的路径同时加入路由表，
	最多默认 **4 条**（可配置到 6 条），实现流量分担。  
- **倾向最少跳数路径**  
	总是优先选择跳数最少的路线，不考虑带宽、延迟等其他因素

| 问题         | 答案                                                                |
| ---------- | ----------------------------------------------------------------- |
| **和谁交换**   | 与**相邻路由器**（处于同一物理网络且运行 RIP ）交换                                    |
| **交换什么信息** | 交换自己当前**完整的路由表**，<br>包含（目的网络，跳数，下一跳）。                             |
| **何时交换**   | ① **周期性更新**：默认每 30 秒向邻居发送一次路由表。<br>② **触发更新**：拓扑变化时立即发送变更信息，不等周期。 |

# 工作过程

### 1. 直连网络初始化
- 路由器启动时，路由表中只包含直连网络，跳数为 0，下一跳为本地接口。
- 向外通告这些网络时，跳数**加 1** 再发送。

### 2. 处理相邻更新报文
- 收到邻居发来的RIP 更新报文后，路由器先对报文进行改造
	1. 将下一跳的接口全部改为邻居地址
	2. 每条路由的跳数++
	3. 然后按照以下五条规则处理：

| 规则             | 条件                 | 操作                  |
| -------------- | ------------------ | ------------------- |
| 相同下一跳<br>直接更新  | 更新来自当前表中的下一跳       | 无论跳数变大变小<br>信任原路径来源 |
| 新目的网络<br>添加    | 路由表中没有该目的网络        | 直接添加<br>下一跳为更新来源    |
| 不同下一跳<br>新路由更优 | 新路由跳数**小于**现有路由的跳数 | 更新路由<br>替换下一跳和度量值   |
| 不同下一跳<br>新路由等价 | 新路由跳数**等于**现有路由    | 添加为等价路径<br>形成负载均衡   |
| 不同下一跳<br>新路由更差 | 新路由跳数**大于**现有路由    | 忽略该更新<br>不改变路由表     |

### 3. 收敛与更新
- 全网路由器反复交换，最终所有路由器对每个网络都获得一致的最优路由，即收敛

# 坏消息传的慢

- 坏消息传的慢
	当某网络突然不可达时，该“坏消息”无法立刻传遍全网，
	导致路由表中产生无效路由并形成[路由环路]和[无穷计数]问题

- 相互欺骗：
	路由器 A 认为通过 B 能到达失效网络，A 通告给 B；
	B 也认为通过 A 可达，互相继续通告，
	跳数不断累加直到 16 才能收敛

| 解决机制  | 解释                                                                          |
| ----- | --------------------------------------------------------------------------- |
| 限制跳数  | 将 16 跳定义为不可达，<br>强制终结无穷计数过程。                                                |
| 触发更新  | 路由发生改变时，立即发送更新，<br>不必等待周期计时器，大大加快坏消息扩散速度。                                   |
| 水平分割  | **避免反方向传送**：<br>从一个接口学到的路由信息，不再从该接口发送回去，<br>从根本上切断双方互相欺骗的路径。                |
| 毒性逆转  | **水平分割的增强版：**<br>从一个接口学到的路由，仍会从该接口发出，<br>但将其跳数设为 16（不可达），<br>明确告诉对方这条路由已失效。 |
| 抑制定时器 | 当某条路由变为不可达后，启动一个抑制计时器，<br>在此期间忽略一切比原路由更差的更新，<br>防止错误信息回传。                   |

# RIP 的版本与报文封装

- **RIPv1**  
  - 有类路由协议，路由更新中不带子网掩码。  
  - 使用广播地址 `255.255.255.255` 发送更新。
- **RIPv2**  
  - 无类路由协议，更新中携带子网掩码，支持 VLSM 和 CIDR
  - 使用组播地址 `224.0.0.9`，支持明文/密文认证。
- **封装方式**  
  RIP 报文封装在 **[[UDP]]** 中，端口号 **520**。
