# 数据包
- 传输差错: 误码、丢失、重复、失序
- 流水线[[时延计算]]
	传输时延(底边) + 传播时延(斜边投影)

# 虚电路

建立请求分组通常需要携带目的地址
数据分组只需要带虚电路标识，但不需要每个分组都带完整目的地址

- `Permanent Virtual Circuit` 永久虚电路
	固定的逻辑连接, 不需要建立连接和释放
	长期存在
	
- `Switched Virtual Circuit` 临时虚电路
	有建立连接和释放的开销

电路交换是真正独占资源；虚电路只是逻辑路径，不独占整条链路
