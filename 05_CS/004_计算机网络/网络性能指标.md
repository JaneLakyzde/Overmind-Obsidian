# 1. 速率

# 2. 带宽
频率带宽[[信道极限速率]]与速率带宽
频率带宽越宽, 传输数据的能力越强, 速率带宽越高
$$最高数据传输速率 = min\{主机接口速率,信道带宽, 网络设备的接口速率\}$$

# 3. 吞吐量

吞吐量受带宽限制
一般情况下只考虑一个方向
