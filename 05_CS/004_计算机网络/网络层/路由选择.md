## 内部路由协议
设法使分组在一个自治系统内尽可能有效的从源网络传输到目的网络
无需考虑自治系统外部其他方面的策略
### [[RIP]]
`Routing Information Protocol`，路由信息协议
是一种基于距离向量的内部网关协议，使用跳数作为唯一度量，通过周期性广播路由表进行更新，最大有效跳数为 15，适用于小型网络。
**只需要周期性交换少量路由信息，不要求严格可靠，使用 UDP 开销小。**
### [[OSPF]]
`Open Shortest Path First`，开放最短路径优先
是一种基于链路状态的内部网关协议，通过洪泛 LSA 构建全网一致的 LSDB，并独立运行 Dijkstra 最短路径优先算法计算出无环的最优路由，同时支持区域划分以适应大规模网络。
**属于网络层协议，需要直接利用 IP 多播并自行实现邻居发现、LSA 洪泛、确认和重传等机制，因此不经过 TCP/UDP。**
### IS-IS
中间系统到中间系统，与OSPF同属链路状态，但基于OSI模型设计，扩展性强，常用于运营商骨干网。

### EIGRP
增强型内部网关路由协议（思科私有），结合距离向量与链路状态优点，使用DUAL算法快速收敛并支持非等价负载均衡。

## 外部路由协议
在不同自治系统内, 度量代价的标准不同, 因此跨自治系统的代价不具备参考价值
### [[BGP]]
`Border Gateway Protocol`，边界网关协议
是一种基于路径向量的外部网关协议，运行在不同自治系统之间，通过携带丰富的路径属性来实现灵活的路由策略控制，是互联网的核心路由协议。
**交换的是整个互联网 AS 间的路由信息，必须保证可靠、有序、不丢失，因此建立 TCP 连接，由 TCP 提供可靠传输。**

| 对比项目           | RIP                          | OSPF                     | BGP                                   |
| -------------- | ---------------------------- | ------------------------ | ------------------------------------- |
| 全称             | Routing Information Protocol | Open Shortest Path First | Border Gateway Protocol               |
| 类型             | 内部网关协议（IGP）                  | 内部网关协议（IGP）              | 外部网关协议（EGP）                           |
| 应用范围           | 一个 AS 内                      | 一个 AS 内                  | 不同 AS 之间                              |
| 工作层次           | 应用层                          | 网络层                      | 应用层                                   |
| 封装方式           | UDP                          | IP                       | TCP                                   |
| IP 协议号         | ——                           | 89                       | ——                                    |
| 端口号            | UDP 520                      | 无端口                      | TCP 179                               |
| 数据包封装          | IP → UDP → RIP               | IP → OSPF                | IP → TCP → BGP                        |
| 路由算法           | 距离向量（Distance Vector）        | 链路状态（Link State）         | 路径向量（Path Vector）                     |
| 度量(metric)     | 跳数(Hop Count)                | Cost（通常与带宽有关）            | Path Attributes（AS_PATH、LOCAL_PREF 等） |
| 最大跳数           | 15（16表示不可达）                  | 无固定限制                    | 无固定限制                                 |
| 收敛速度           | 慢                            | 快                        | 较慢（为了稳定）                              |
| 是否易产生环路        | 是                            | 基本不会                     | 基本不会                                  |
| 防环机制           | 水平分割、毒性逆转、触发更新等              | SPF 算法 + LSDB            | AS_PATH 属性                            |
| 是否支持 CIDR/VLSM | RIP v1 不支持；RIP v2 支持         | 支持                       | 支持                                    |
| 是否支持认证         | RIP v2 支持                    | 支持                       | 支持                                    |
| 更新方式           | 周期广播（约30 s）                  | 事件触发，仅变化时更新              | 增量更新                                  |
| 更新内容           | 整张路由表                        | 链路状态信息（LSA）              | 路由可达性及路径属性                            |
| 是否建立邻居         | 简单                           | 是（Hello 建邻）              | 是（TCP 建连接）                            |
| 是否维护拓扑数据库      | 否                            | 是（LSDB）                  | 否（维护 BGP 路由表）                         |
| 是否计算最短路径树      | 否                            | 是（SPF）                   | 否                                     |
| 是否依赖传输层        | 是（UDP）                       | 否                        | 是（TCP）                                |
| 是否依赖 TCP 可靠传输  | 否                            | 否（自己实现）                  | 是                                     |
| 是否自己实现可靠机制     | 否                            | 是（LSA确认、重传等）             | 否（依赖TCP）                              |
| 是否支持区域划分       | 否                            | 支持（Area）                 | 不支持（按AS划分）                            |
| 网络规模           | 小型网络                         | 中大型企业网络                  | 全球互联网                                 |
| 典型应用           | 小型局域网                        | 企业、校园网                   | ISP、互联网骨干                             |
