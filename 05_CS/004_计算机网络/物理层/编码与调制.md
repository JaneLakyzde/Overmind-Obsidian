- 基带调制 = 编码 = 数字信号
- 带通调制 = 调制 = 模拟信号
- 信息速率 = 数据传输速率 = 比特率 $R_b$ 
- 码元传输速率 = 符号速率 = 调制速率 = 波特率 $R_B$
	$R_b = R_B * log_2V = 波特率 * 码元携带比特数$
- 信道的频率带宽: 信道能通过的最高频率与最低频率之差
	频率带宽主要受[[传输介质]]影响
# 编码

## NRZ
- 不用归零, 编码效率最高
- 存在同步问题, 双方需要带有时钟线
## RZ
- 自同步机制
- 码元中间跳变归零提供时间基准
## NRZI
- ==跳变表示 0, 不变表示 1==
- 长时间不变会有同步问题, 引入...
- USB 2.0
## 曼彻斯特编码
- 自同步机制
- 标准以太网
	联想: 10BASE-T、10BASE 5、10BASE 2、51.2µs 争用期(CSMA/CD)

## 差分曼彻斯特编码
- 码元边界时刻 ==跳变表示 0, 不变表示 1==
- 中间时刻的电平跳变表示时钟信号, 边界时刻的电平跳变表示数据
- 更强的抗干扰能力
- 宽带高速网

# 信道的极限容量
- 在信道的频率带宽 $W$ 一定的情况下, 为了提高信道的极限信息传输速率, 就必须使每个码元携带更多个比特, 并且努力提高信道中的信噪比

## 奈奎斯特定理
- 适用 ==理想== 低通信道和 ==无噪声== 信道
- 理想极限数据传输速率: $= 2W\log_2V$ 单位为 $bit/s$
- $V$ 表示每个码元的离散电平数量, $log_2V$ 表示码元携带的比特数

## 香农定理
- 频率带宽受限且有高斯 ==白噪声干扰== 信道的 ==极限信息传输速率== 
- 极限数据传输速率: $=W\log_2(1+S/N)$  单位为 $bit/s$
- 信噪比分贝形式: $=10log_{10}(S/N)$ , $30dB$ 代表 $S/N = 1000$ 
- 低于香农公式, 即可实现无差错的信号传输

## 对比与综合应用


| 项目   | 奈奎斯特定理                | 香农定理                   |
| ---- | --------------------- | ---------------------- |
| 适用信道 | 无噪声                   | 有噪声                    |
| 限制对象 | 码元速率上限                | 信息速率上限                 |
| 突破方式 | 增加进制数 $V$             | 提高信噪比或带宽               |
| 公式   | $C = 2W \log_2 V$     | $C = W \log_2(1+S/N)$  |
| 极限含义 | 若超过 $2W$ Baud，必出现码间串扰 | 超过 $C$ bps 则不可能实现无差错传输 |

| 名称         | 公式                                      |
| ---------- | --------------------------------------- |
| 比特率与波特率    | $R_b = R_B \log_2 V$                    |
| 奈奎斯特无噪声容量  | $C = 2W \log_2 V$                       |
| 奈奎斯特最大码元速率 | $R_{B,\max} = 2W$                       |
| 香农有噪信道容量   | $C = W \log_2(1 + S/N)$                 |
| 信噪比分贝换算    | $(S/N)_{\text{dB}} = 10 \log_{10}(S/N)$ |
| 极限信噪比需求    | $S/N = 2^{C/W} - 1$                     |
