# OSI参考模型
- TCP/IP参考模型在网络层仅有无连接不可靠的数据报通信
	而在传输层支持无连接和面向连接的通信
- OSI 在网络层支持无连接和面向连接的通信
	但在传输层支持面向连接的通信
原理参考模型
PDU: 协议数据单元
SAP: 服务访问点
## 7. 应用层
通过进程交互来==实现特定网络应用==
**PDU**: 应用层报文
## 6. 表示层
实现数据的表示和格式转换、压缩

## 5. 会话层
实现基于进程通信的会话管理、同步点、检验点

## 4. 传输层
实现进程之间基于网络的==端到端==通信与流量控制
**PDU**: TCP报文段 (TCP段) 或 UDP 用户数据报
**服务访问点**: 段头或报头的“端口号”字段
## 3. 网络层
实现数据包在==多个网络之间==传输或路由以及整个网络的流量控制
**PDU**: IP数据报 (IP分组)
**服务访问点**: IP 分组的“协议”字段
## 2. 数据链路层
实现数据包在==一个网络或一段链路上传输==, 以及相邻节点之间的流量控制
**PDU**: 帧
**服务访问点**: 帧的“类型”字段
## 1. 物理层
实现怎么用信号来==传输和表示比特 `0和1`==
**PDU**: 比特流

# 协议与三要素
语法: 定义通信双方所交换信息的格式
语义: 定义通信双方所要完成的操作
同步: 定义通信双方的时序关系
