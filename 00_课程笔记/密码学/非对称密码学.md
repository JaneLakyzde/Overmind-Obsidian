# Rabin 加密算法（教学笔记）

## 一、算法概述

**Rabin 加密算法（Rabin Cryptosystem）** 是一种经典的公钥加密算法，由 Michael O. Rabin 于 1979 年提出。

- 属于：公钥密码体制
    
- 数学基础：大整数分解 + 二次剩余
    
- 理论特点：
    
    - 破解 Rabin 加密 **等价于** 分解大整数
        
    - 具有严格的安全性归约证明
        

> 📌 教学定位：  
> Rabin 算法常用于**密码学理论教学**，而非工程实践。

---

## 二、数学基础（前置知识）

### 1. 模运算

- 同余关系：  
    [  
    a \equiv b \pmod{n}  
    ]
    
- 模平方运算：  
    [  
    m^2 \bmod n  
    ]
    

---

### 2. 大素数

- 选择两个大素数：  
    [  
    p,\ q  
    ]
    

---

### 3. 二次剩余

- 若存在 ( x ) 使得：  
    [  
    $x^2 \equiv c \pmod{n}$  
    ]  
    则称 ( c ) 为模 ( n ) 下的二次剩余。
    

---

### 4. 中国剩余定理（CRT）

> **核心解密工具**

- 用于将：
    
    - 模 ( p ) 的解
        
    - 模 ( q ) 的解
        
- 合并为模 ( n = pq ) 下的解
    

---

## 三、算法核心思想

> **加密 = 平方取模（非常简单）**  
> **解密 = 求模平方根（非常困难，除非知道素因子）**

---

## 四、密钥生成（Key Generation）

### 1. 选取素数

选择两个大素数，满足：

```text
p ≡ 3 (mod 4)
q ≡ 3 (mod 4)
```

> 📌 教学说明：  
> 该条件可以简化模平方根的计算公式。

---

### 2. 计算模数

[  
n = p \times q  
]

---

### 3. 密钥组成

- **公钥**：
    
    ```text
    n
    ```
    
- **私钥**：
    
    ```text
    (p, q)
    ```
    

> ⚠️ 与 RSA 的区别：  
> Rabin 公钥中 **只有一个参数 n**。

---

## 五、加密过程（Encryption）

### 1. 明文表示

将明文编码为整数：

```text
m ∈ {0, 1, ..., n−1}
```

---

### 2. 加密公式

[  
\boxed{c = m^2 \bmod n}  
]

---

### 3. 特点总结

- 计算极快
    
- 实现简单
    
- 非单射映射（一个密文对应多个明文）
    

---

## 六、解密过程（Decryption）⭐重点

### 1. 解密目标

已知：  
[  
c = m^2 \bmod n  
]

目标：

```text
求 m
```

➡️ 等价于：  
**求模 n 下的平方根**

---

### 2. 解密步骤

#### 步骤一：分别在模 p、模 q 下求平方根

当：

```text
p ≡ q ≡ 3 (mod 4)
```

平方根计算公式为：

[  
m_p = c^{\frac{p+1}{4}} \bmod p  
]  
[  
m_q = c^{\frac{q+1}{4}} \bmod q  
]

得到：

```text
± m_p (mod p)
± m_q (mod q)
```

---

#### 步骤二：使用中国剩余定理合并

将以下四种组合合并：

```text
(+m_p, +m_q)
(+m_p, −m_q)
(−m_p, +m_q)
(−m_p, −m_q)
```

➡️ 得到 **4 个模 n 下的解**

---

### 3. 解密歧义性（核心问题）

- 解密结果：
    
    ```text
    4 个候选明文
    ```
    
- 原始明文只是其中之一
    
- 实际系统必须引入：
    
    - 明文冗余
        
    - 格式校验
        
    - 哈希验证  
        来消除歧义
        

---

## 七、教学示例（小数值演示）

> ⚠️ 仅用于教学说明，不具备安全性

### 1. 密钥生成

```text
p = 7
q = 11
n = 77
```

---

### 2. 明文

```text
m = 20
```

---

### 3. 加密

[  
c = 20^2 \bmod 77 = 400 \bmod 77 = 15  
]

---

### 4. 解密

求：  
[  
x^2 \equiv 15 \pmod{77}  
]

解为：

```text
{20, 57, 34, 43}
```

✔ 原始明文为：20

---

## 八、安全性分析

### 1. 理论安全性

- 破解 Rabin 加密  
    ⇔  
    分解大整数 ( n )
    

> 📌 Rabin 是少数具有**严格数学安全性证明**的公钥算法。

---

### 2. 与 RSA 对比

|项目|Rabin|RSA|
|---|---|---|
|加密速度|极快|较慢|
|解密复杂度|高|中等|
|解的唯一性|❌（4 解）|✅|
|理论安全证明|有|无严格等价|
|实际应用|少|广泛|

---

## 九、教学常见问题

### Q1：为什么会有 4 个解？

- 合数模平方根的数学性质
    

### Q2：为什么要求 p ≡ q ≡ 3 (mod 4)？

- 简化平方根计算公式
    

### Q3：为什么 Rabin 没有广泛使用？

- 解密存在歧义，工程复杂度高
    

### Q4：Rabin 是否比 RSA 更安全？

- 理论上：是
    
- 工程上：不一定
    

---

## 十、总结

> **Rabin 加密算法通过“平方取模”实现极简加密，其安全性与大整数分解严格等价，但解密产生多解，必须依赖额外机制才能实用。**

# ElGamal 加密算法（简要说明）

## 一、算法概述

**ElGamal 加密算法**是一种基于**离散对数困难性**的公钥加密算法，由 **Taher ElGamal** 于 1985 年提出。

- 算法类型：公钥加密算法
    
- 数学基础：离散对数问题（DLP）
    
- 工作群：有限域乘法群或椭圆曲线群
    
- 重要特性：**概率加密（非确定性）**
    

---

## 二、核心思想

> **通过随机数引入不确定性，使相同明文每次加密得到不同密文。**

安全性来源于：

```text
在给定 g^x 的情况下，求 x 是计算上不可行的
```

---

## 三、密钥生成（Key Generation）

1. 选择一个大素数 ( p )
    
2. 选择模 ( p ) 下的生成元 ( g )
    
3. 随机选择私钥：  
    [  
    x \in {1, \dots, p-2}  
    ]
    
4. 计算公钥：  
    [  
    y = g^x \bmod p  
    ]
    

- **公钥**：
    
    ```text
    (p, g, y)
    ```
    
- **私钥**：
    
    ```text
    x
    ```
    

---

## 四、加密过程（Encryption）

1. 将明文编码为：
    
    ```text
    m ∈ {1, …, p−1}
    ```
    
2. 随机选择一次性随机数：  
    [  
    k \in {1, \dots, p-2}  
    ]
    
3. 计算密文对：  
    [  
    c_1 = g^k \bmod p  
    ]  
    [  
    c_2 = m \cdot y^k \bmod p  
    ]
    

- **密文形式**：
    
    ```text
    (c1, c2)
    ```
    

---

## 五、解密过程（Decryption）

1. 计算：  
    [  
    s = c_1^x \bmod p  
    ]
    
2. 还原明文：  
    [  
    m = c_2 \cdot s^{-1} \bmod p  
    ]
    

> 其中 ( s^{-1} ) 为模逆元。

---

## 六、算法特点总结

- ✔ 概率加密（同一明文，多种密文）
    
- ✔ 抗重放与模式分析
    
- ❌ 密文长度是明文的 **2 倍**
    
- ❌ 计算量较大（指数运算）
    

---

## 七、与 RSA / Rabin 的直观对比

- **RSA / Rabin**：确定性加密（原始形式）
    
- **ElGamal**：随机化加密
    
- **安全假设不同**：
    
    - RSA / Rabin → 大整数分解
        
    - ElGamal → 离散对数
        

---

## 八、一句话总结

> **ElGamal 通过引入随机数实现安全的概率加密，其安全性基于离散对数问题，但以更大的密文长度和计算开销为代价。**
