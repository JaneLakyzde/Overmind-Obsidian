非对称式加密算法，安全性基于大整数质因数分解的困难性：
- 将两个大素数相乘很容易
- 但是对乘积进行质因数分解在计算上非常困难
# 数学基础

1. **密钥生成**：
    
    - 选择两个大素数p和q
    - 计算n = p × q（模数）
    - 计算φ(n) = (p-1)(q-1)（欧拉函数）
    - 选择加密指数e，满足1 < e < φ(n)且 $gcd(e, φ(n)) = 1$通常为65537
    - 计算解密指数d，满足 $d×e ≡ 1 (mod φ(n))$ 即为私钥
    
2. **加密过程**：密文c = m^e mod n
    
    - 其中m是明文消息
3. **解密过程**：明文m = c^d mod n
    
    - 利用[[欧拉定理]]和模幂运算
