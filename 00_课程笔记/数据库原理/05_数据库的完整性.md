## 实体完整性

- 确保每个表中的主键唯一且非空，唯一标识实体。
	- 主键值必须唯一且非空（NOT NULL）
	-  主键可以是单列或多列组合（复合主键）

实现方式：通过 PRIMARY KEY 约束定义。

```sql
--列级主键
CREATE TABLE Student (
    sno CHAR(9) PRIMARY KEY,
    sname CHAR(20) NOT NULL
);
--表级复合主键
CREATE TABLE SC (
    sno CHAR(9),
    cno CHAR(4),
    PRIMARY KEY (sno, cno)
);
```

---

## 参照完整性

- 维护表间外键关系，确保外键值有效或为 NULL。
- 外键值必须存在于被引用表的主键中，或为 NULL

实现方式：通过 FOREIGN KEY 约束定义。

```sql
CREATE TABLE SC (
    sno CHAR(9),
    cno CHAR(4),
	PRIMARY KEY (sno, cno), 
	-- 添加这一行主键，确保一个学生只能选一门课一次
    FOREIGN KEY (sno) REFERENCES Student(sno),
    FOREIGN KEY (cno) REFERENCES Course(cno)
);
```

## 用户定义完整性

- 根据业务规则自定义约束，如非空、唯一、检查条件。
	列值非空（NOT NULL）、唯一（UNIQUE）
	列值满足特定条件（CHECK 约束）
	元组级约束（跨列条件限制）

实现方式：通过 NOT NULL、UNIQUE、CHECK 等约束定义。

```sql
CREATE TABLE stu (
    sno CHAR(9) PRIMARY KEY,
    sex CHAR(1) NOT NULL,
    age INT CHECK (age > 0)
);
```

## 断言
`ASSERTION`
>定义更具一般性的约束，确保数据始终满足条件。一般跨行跨表的聚合约束靠断言实现在数据库每次更新后, 都会自动判断断言是否为真;若为假, 则拒绝此次操作

断言中的两种核心约束类型:
- 数量约束: 子查询返回单个值，直接用 `<=`, `>=`, `=` 等比较
- 存在约束: 使用 `EXISTS` 或 `NOT EXISTS`，常配合 `ALL`、`SOME`/`ANY`

```sql
CREATE ASSERTION <断言名> <check子句>
-- CHECK 子句的约束条件与 WHERE 子句的条件表达式类似

-- 确保所有员工工资总和不超过100万元
CREATE ASSERTION total_salary_check
CHECK (
    (SELECT SUM(salary) FROM employees) <= 1000000
);

-- 每位教师开设的课程不能超过10门
CREATE ASSERTION teacher_course_limit
CHECK(
	NOT EXISTS(
		SELECT teacher_id
		FROM course
		GROUP BY teacher_id
		HAVING COUNT(*) > 10
	)
)

-- 不允许男同学选修WU老师的课程
CREATE ASSERTION no_male_student_wu_course
CHECK(
	NOT EXISTS(
		SELECT *
		FROM sc
		JOIN student ON sc.sid = student.sid
		JOIN course ON sc.cid = course.cid
        JOIN teacher ON course.teacher_id = teacher.tid
        WHERE student.gender = '男' AND teacher.tname = 'WU'
	)
)
--删除断言： 
DROP ASSERTION 断言名;
```

>绝大多数关系数据库没有完整实现断言，因为它对性能影响大且实现复杂。实际开发中常用触发器或应用层逻辑来模拟。

## 触发器

- 触发器也叫做 事件 → 条件 → 动作 规则。
	当对表进行增、删、改操作时，检查触发器中的条件：
	- 若条件成立，则执行触发动作
	- 否则不执行

```sql
DELIMITER //   -- 修改 MySQL 结束符为 //

CREATE TRIGGER <触发器名>
{BEFORE|AFTER} <触发事件> ON <表名>
FOR EACH {ROW|STATEMENT}  -- 设定频率 
-- ROW：行级触发器
-- STATEMENT：语句级触发器
BEGIN
    <触发动作体>   -- 仅当触发条件为真时才执行
END;

DELIMITER ;   -- 改回默认结束符
```

示例：记录成绩更新操作
```sql
DELIMITER //

CREATE TRIGGER SC_T
AFTER UPDATE ON SC
FOR EACH ROW
BEGIN
    IF New.Grade >= 10 THEN
        INSERT INTO SC_U(Sno, Cno, Oldgrade, Newgrade)
        VALUES(OLD.Sno, OLD.Cno, OLD.Grade, NEW.Grade);
    END IF;
END;

DELIMITER ;
```
