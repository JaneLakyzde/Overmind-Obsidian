# 群
一个集合和一个二元运算，满足一下四个性质：
- 封闭性
- 结合律
- 存在单位元
- 每个元素存在逆元
	
	如果还满足交换律，则称为阿贝尔群、交换群

群的阶数：群中元素的个数
元素的阶数：使元素通过幂运算得到单位元的最小次方、不存在则为无限大

> 减法、除法、幂运算就不满足结合律，即元素的层级、权重不同
# 环
首先需要第一个运算满足以上五个性质，构成交换群
在交换群的基础上引入第二个二元运算，其中第二个二元运算只需要满足：
- 封闭性
- 结合律
- ==分配律==

# 域
在环的基础上，需要第一个二元运算满足所有五个性质，第二个二元运算满足所有六个性质
- 封闭性
- 结合律
- 单位元
- 逆元
- 交换律
- 分配律（第二运算）
- 即 两个**阿贝尔群**的结合
