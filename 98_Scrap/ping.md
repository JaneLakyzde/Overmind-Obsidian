`ping` 是网络诊断中最常用的工具，几乎存在于所有安装了 TCP/IP 协议栈的操作系统中（Windows, macOS, Linux, Android, iOS 等）。

---

## 1. 基本定义与全称

- **全称：** **Packet Internet Groper**（数据包互联网探测器）。
    
- **工作原理：** 它利用 **ICMP** (Internet Control Message Protocol，互联网控制报文协议) 向目标主机发送一个 `ECHO_REQUEST`（回显请求）数据包，并等待目标返回 `ECHO_REPLY`（回显应答）。
    
- **核心作用：** 1. 检测目标主机是否**在线（可达）**。
    
    2. 测量数据包往返的**延迟（Latency/RTT）**。
    
    3. 统计网络传输中的**丢包率（Packet Loss）**。
    

---

## 2. 参数全称与功能速查

不同系统的 `ping` 参数略有差异，以下是通用性最强的参数对照：

| **参数** | **全称 (Meaning)**      | **功能说明**                                                  |
| ------ | --------------------- | --------------------------------------------------------- |
| **-c** | **Count**             | **指定次数**。发送特定数量的数据包后停止（Linux/macOS 默认无限发，Windows 默认 4 次）。 |
| **-t** | **Timeout             | **持续追踪** (Windows)无限期发送数据包，直到手动按 `Ctrl+C` 停止。             |
| **-i** | **Interval**          | **间隔时间**。设置两次数据包发送之间的时间间隔（默认 1 秒）。                        |
| **-s** | **Size**              | **数据包大小**。指定发送缓冲区的大小（默认通常为 56 或 64 字节）。                   |
| **-f** | **Flood**             | **极限测试**。以极快速度发送数据包（通常需要 root 权限），用于压力测试。                 |
| **-a** | **Audible / Address** | **音频提示**。当收到回复时发出“滴”的一声；或尝试解析主机名。                         |
| **-n** | **Numeric**           | **数字模式**。只显示 IP 地址，不进行 DNS 反向解析，速度更快。                     |
| **-W** | **Wait**              | **等待时间**。设置等待每次回复的超时时间。                                   |

## 3. 常用用法示例

### 基础连通性测试


```
ping google.com
```

_这是最简单的用法，用于判断你的电脑能否访问外网以及 DNS 解析是否正常。_

### 检查链路稳定性 (发 100 次包)


```
# Linux/macOS
ping -c 100 192.168.1.1
# Windows
ping -n 100 192.168.1.1
```

_通过查看最后的 `packet loss`（丢包率）来判断网络环境是否抖动。_

### 探测最大传输单元 (MTU)


```
# Windows 示例：-f (不允许分段) -l (长度)
ping -f -l 1472 8.8.8.8
```

_这常用于调试网络配置，找出路由器支持的最大不分段数据包大小。_

### 快速扫描局域网存活主机 (简易版)

在 Linux 下可以配合 `grep` 只显示通顺的机器：


```
for ip in $(seq 1 254); do ping -c 1 -W 1 192.168.1.$ip | grep "from"; done
```

## 4. 结果解读

当你运行 `ping` 后，通常会看到类似以下的数据：

`64 bytes from 142.250.190.46: icmp_seq=1 ttl=117 time=35.2 ms`

- **icmp_seq**: 序列号，如果跳号了说明有丢包。
    
- **ttl (Time to Live)**: 数据包生存时间。每经过一个路由器该值减 1，可以粗略判断经过了多少跳，或者通过初始值判断目标系统（如 64 通常是 Linux，128 通常是 Windows）。
    
- **time**: 往返时间。数值越小网络越快。
    

---

> **温馨提示：** 现代很多服务器（如阿里云、部分公司防火墙）为了防范攻击，会禁掉 ICMP 协议。此时 `ping` 会显示请求超时，但这**并不代表**服务器不在线，这种情况下你需要使用我们之前聊过的 `nc` (Netcat) 来探测特定端口（如 80 或 443）。
