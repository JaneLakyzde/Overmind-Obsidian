**ASCII** 全称 **American Standard Code for Information Interchange**，中文叫“美国信息交换标准代码”。

简单说：**它是一套把字符（字母、数字、符号、控制符）映射成数字的编码标准**，让计算机能用二进制存储和传输文本。

### 核心特点
- 使用 **7 位二进制**，一共 **128 个字符**（0~127）。
- 包括：
  - 可打印字符：英文字母、数字、标点、空格等（32~126）。
  - 控制字符：换行、回车、制表、响铃等（0~31 和 127）。
- 常见例子：
  - `A` = 65
  - `a` = 97
  - `0` = 48
  - 空格 = 32
  - 换行 `\n` = 10
  - 回车 `\r` = 13

### 扩展 ASCII
后来用 **8 位** 扩展到 **256 个字符**（128~255），加入了一些欧洲语言符号、制表符等，但不同地区实现不完全一致。

### 与现代编码的关系
- **Unicode / UTF-8** 是现代主流编码，能表示中文、emoji 等。
- **UTF-8 向后兼容 ASCII**：ASCII 字符在 UTF-8 里编码相同。

### 和你之前问的 FTP 有关
FTP 传输模式里有 **ASCII 模式**和**二进制模式**：
- ASCII 模式：会转换换行符，适合纯文本。
- 二进制模式：原样传输，适合图片、压缩包、程序等。

**一句话：ASCII 是计算机早期最基础的字符编码标准，用 0~127 表示英文字符和控制符，现代 UTF-8 兼容它。**
