由理查德·斯托曼（Richard Stallman）在 1983 年发起的一个自由软件集体协作计划，目标是创建一套完全自由、向上兼容 Unix 的操作系统。
我们日常使用的 Linux 操作系统，严格来说应该被称为 **GNU/Linux**。因为 Linux 本身只是一个“内核”（负责管理硬件、进程等底层工作），而真正构成完整操作系统、提供日常所需基础命令和工具的，正是 GNU 计划开发的大量组件（如 Bash、核心工具链、系统库等）。

[[GCC]]: 最初的全称是 **GNU C Compiler**（GNU C 语言编译器）。随着后来它扩展支持了 C++、Fortran、Java、Go 等多种编程语言，现在的全称演变为 **GNU Compiler Collection**（GNU 编译器套件）。
