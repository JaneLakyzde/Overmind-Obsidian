# 概念与定义
- 基尼系数:
	经济学中用来衡量一个国家或地区收入分配是否平等的指标
	也可以表示资源在种群个体之间分配的集中程度
- 范围通常在 0 到 1 之间, 0 表示绝对平等, 1 表示绝对不平等

**资源基尼系数就是用来量化“进化竞争激烈程度”或者“资源垄断程度”的指标。** 
	数值越高，竞争越残酷，资源越向头部集中。

# 平均差法
基尼系数的核心思想是 “两两比较”
数学定义为：
$$
G = \frac{\sum_{i=1}^{n} \sum_{j=1}^{n} |x_i - x_j|}{2n^2 \bar{x}}
$$
- $x_i, x_j$ 任意两个个体的资源数量
- **$n$**：种群总个体数。
- **$\bar{x}$**：所有个体资源的平均值。
- 通俗理解：把所有个体两两配对，计算他们资源差值的绝对值之和，再除以“理论上最大可能的总差值”。
这个公式最直观，但计算复杂度高（需要双重循环），在种群规模较大时效率较低。

# 排序累加法
在 Python / R 等数据处理中，为了提升计算效率，通常先将所有个体的资源积分从小到大排序，然后使用以下简化公式：
假设有 $n$ 个个体，每个个体的资源为 $x_1, x_2, ..., x_n$（已按数值从小到大排序），则基尼系数 $G$ 为：
$$
G = \frac{\sum_{i=1}^{n} (2i - n - 1) \cdot x_i}{n \sum_{i=1}^{n} x_i}
$$
其中 $i$ 是个体在排序列表中的排名（从 1 开始，1 代表资源最少）
