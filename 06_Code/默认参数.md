# C++默认参数的求值规则

在C++中，`void display(int a, int b = getDefault())` 这种语法定义了一个带有默认参数的函数。关于默认参数的规则有以下几点：

## 关键规则

1. **求值时机**：默认参数在**每次函数调用时**求值，而不是在函数声明/定义时一次求值
2. **按需求值**：只有当调用函数时没有提供对应参数，才会计算默认参数的值
3. **作用域**：默认参数的表达式在调用点的上下文中求值，使用调用时的变量状态

## 本例分析

```cpp
void display(int a, int b = getDefault())
```

在这个例子中：

- 每次调用`display`且不提供第二个参数时，都会执行`getDefault()`函数
- `getDefault()`会修改全局变量`counter`并返回其10倍值
- 当显式提供第二个参数(如`display(3, 100)`)时，不会调用`getDefault()`

## 执行过程

1. `display(1)` → 调用`getDefault()`，counter=1，b=10
2. `display(2)` → 再次调用`getDefault()`，counter=2，b=20
3. `display(3, 100)` → 不调用`getDefault()`，使用提供的值100
4. `display(4)` → 再次调用`getDefault()`，counter=3，b=30

## 常见误解

很多人错误地认为默认参数只在程序启动时计算一次，或者在函数定义时计算。实际上，C++标准明确规定默认参数在每次需要时都会重新计算。

这个特性使得默认参数可以基于当前程序状态动态变化，但同时也可能导致意外的副作用，需要谨慎使用。
