在 C++ 中，**左值（lvalue）** 与 **右值（rvalue）** 的区别，是理解引用、移动语义、重载决议等核心机制的基础。下面从**本质、语义、使用场景**三个层面系统说明。

---

## 一、本质区别（核心判定标准）

**是否具有可识别的、持久的内存位置**

|分类|是否有确定内存地址|生命周期|能否取地址|
|---|---|---|---|
|左值（lvalue）|有|持久（超出当前表达式）|可以（通常）|
|右值（rvalue）|没有或临时|临时（表达式结束即销毁）|不可以（通常）|

**一句话总结：**

> **左值代表“对象本身”，右值代表“对象的值（结果）”。**

---

## 二、左值（lvalue）

### 1. 定义

左值是**可以出现在赋值号左边的表达式**（历史定义），更准确地说：

> 左值是一个**有名字、可定位、有持久存储位置的对象**。

### 2. 常见左值示例

```cpp
int a = 10;
a = 20;        // a 是左值

int* p = &a;   // a 可以取地址
```

```cpp
int arr[3];
arr[0] = 5;    // arr[0] 是左值
```

```cpp
struct S { int x; };
S s;
s.x = 3;       // s.x 是左值
```

### 3. 左值引用

```cpp
int a = 10;
int& r = a;    // 合法：左值引用只能绑定左值
```

❌ 非法：

```cpp
int& r = 10;   // 错误：右值不能绑定到非常量左值引用
```

---

## 三、右值（rvalue）

### 1. 定义

右值是**临时的、匿名的、即将被销毁的值**，通常是表达式计算的结果。

### 2. 常见右值示例

```cpp
10           // 字面量
a + b        // 表达式结果
f()          // 返回非引用的函数返回值
```

```cpp
int x = 10 + 20;   // 10+20 是右值
```

### 3. 右值的特性

```cpp
int* p = &(a + b); // 错误：不能对右值取地址
```

```cpp
(a + b) = 5;       // 错误：右值不能作为赋值左边
```

---

## 四、const 左值引用的特殊情况（重点）

**const 左值引用可以绑定右值**

```cpp
const int& r = 10;    // 合法
```

原因：

- 编译器会为右值创建一个**临时对象**
    
- 该临时对象的生命周期被**延长到引用的生命周期**
    

但要注意：

```cpp
int& r = 10;          // 仍然非法
```

---

## 五、C++11 引入的右值引用（进阶）

### 1. 右值引用 `&&`

```cpp
int&& r = 10;    // 合法
```

右值引用专门用来**绑定右值**，主要用于：

- 移动语义（move）
    
- 完美转发（forward）
    

### 2. 区分三种情况

```cpp
int a = 10;

int&  l1 = a;    // 左值引用 ← 左值
int&& r1 = 10;   // 右值引用 ← 右值

int&& r2 = a;    // 错误：a 是左值
```

但：

```cpp
int&& r = std::move(a); // 合法，a 被“转换”为右值
```

---

## 六、左值 / 右值在函数调用中的体现

```cpp
void f(int& x);
void g(const int& x);
void h(int&& x);

int a = 10;

f(a);       // OK
f(10);      // 错

g(a);       // OK
g(10);      // OK

h(a);       // 错
h(10);      // OK
```

---

## 七、与考试/面试强相关的总结表

|表达式|是左值还是右值|
|---|---|
|普通变量 `a`|左值|
|数组元素 `arr[i]`|左值|
|解引用 `*p`|左值|
|字面量 `10`|右值|
|表达式 `a+b`|右值|
|返回值 `f()`（非引用）|右值|
|`std::move(a)`|右值|

---

## 八、一句话终极总结（记忆版）

- **左值：有名字、有地址、可长期存在**
    
- **右值：没名字、临时的、用完即弃**
    
- **`int&` 只接左值**
    
- **`const int&` 左右都能接**
    
- **`int&&` 专接右值**
