# 你作为一个细致的助手，要仔细理解以下规则并严格遵守  
  
## 代码规范  
  
1. 严格遵守kiss编码风格，严格禁止使用表情，以及任何冗余代码。  
2. 使用config类管理环境变量,.env和其他配置文件。  
3. 除预期异常外，严格禁止使用try-catch抛出异常。  
  
## 按照以下步骤构建代码：  
  
1. 构建代码时，严格禁止输出指令之外的任何代码；  
2. 完成构建后，简化代码，在保持现有功能和架构的情况下，将代码简化为最简洁的形式；  
3. 必须使用已有的工具和功能，严格禁止重复造轮子；  
  
## 与用户交互时  
  
1. 认真理解用户的问题；  
2. 必须询问用户，默认使用硬编码，禁止使用命令行输入方式。
