定义：匿名函数的一种简洁写法。基本结构：`[捕获列表](参数列表) { 函数体 }` 
注意：C 语言不支持 Lambda 表达式
*捕获（capture）本质上就是让 lambda 函数能访问它定义时所在作用域里的局部变量（以及 `this` 等），从而形成一个闭包。

# 捕获列表

Lambda 可以访问它所在作用域里的变量，但需要通过捕获列表来“捕获”它们。捕获有两种主要方式：[值捕获]和[引用捕获]。

### 1. 值捕获

把外部变量的值复制一份到 Lambda 内部，Lambda 内部对变量的修改不会影响外部。
```cpp
int x = 10;
auto lambda = [x]() { std::cout << x << std::endl; };
lambda();  // 输出 10
```
### 2. 引用捕获

捕获外部变量的引用，Lambda 内部可以直接操作原变量（可修改外部变量）。
```cpp
int x = 10;
auto lambda = [&x]() { x = 20; };
lambda();
std::cout << x << std::endl;  // 输出 20
```
### 隐式捕获

让编译器根据 Lambda 体内的代码自动推导需要捕获哪些变量：

- `[=]`：值捕获所有使用的变量。
    
- `[&]`：引用捕获所有使用的变量。
    

```cpp
int a = 1, b = 2;
auto lambda1 = [=]() { return a + b; };      // 值捕获 a 和 b
auto lambda2 = [&]() { a = 3; b = 4; };      // 引用捕获 a 和 b
```

### 混合捕获

可以同时指定不同的捕获方式：
```cpp
int x = 10, y = 20;
auto lambda = [x, &y]() {
    // x 是值捕获（只读），y 是引用捕获（可修改）
    y = x + y;
};
```

### 空捕获

捕获列表决定 Lambda 内部能否使用**它外面定义的局部变量**（比如函数里的局部变量、函数参数等）。如果捕获列表是空的，就表示：

- **Lambda 内部不能直接使用任何外部局部变量**。
    
- 只能使用：
    
    - 全局变量
        
    - 静态局部变量（`static` 修饰的）
        
    - Lambda 自己的参数
        
    - 编译期常量（如 `constexpr`）

# 参数列表

参数列表也可以为空，调用时不需要传参，也可以直接省略。
