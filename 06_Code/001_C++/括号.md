- **圆括号 `()`**
    
    - 函数参数列表：表示参数的类型和个数（如 `void foo(int a, double b)`）。
    - 函数调用：传递实参（如 `foo(3, 4.5)`）。
    - 表达式分组、强制类型转换等。
        
- **方括号 `[]`**
    
    - 数组声明：表示数组的大小（元素个数），如 `int arr[10]`。
    - 数组下标访问：如 `arr[0]`。
    - lambda 表达式捕获列表：如 `[&](){...}`。
        
- **大括号 `{}`**
    
    - 初始化列表：直接给出元素的具体值，如 `int arr[] = {1,2,3}`。
    - 统一初始化（C++11 起）：`int x{5}`，`vector<int> v{1,2,3}`。
    - 函数体、复合语句、命名空间等代码块。
