[[输入|cin]] 输入数据的时候, 遇到空白字符会停止读取数据, 并将空白字符留在输入流中
流结束标志[[EOF]] 导致整个输入过程结束  (ctrl+Z/D)

# 空白字符/分割符

| `' '`  | 空格    | 32  |
| ------ | ----- | --- |
| `'\t'` | 水平制表符 | 9   |
| `'\n'` | 换行符   | 10  |
| `'\v'` | 垂直制表符 | 11  |
| `'\f'` | 换页符   | 12  |
| `'\r'` | 回车符   | 13  |
[[输入]] 输入数据的时候, 遇到空白字符会停止读取数据,
- 会将空白字符留在输入流中
- 下一次 `cin >>` 会跳过他们

凡是 `isspace()` 判定为 true 的字符，都属于空白符

#  流结束标志 EOF

| 对应符号/信号       | 触发方式                   | ASCII 码（若存在） | 说明                        |
| ------------- | ---------------------- | ------------ | ------------------------- |
| 模拟 EOF（文件结束符） | Windows 控制台：`Ctrl+Z`   | 26（`\032`）   | 输入后按回车，`cin.eof()` 为 true |
| 模拟 EOF        | Linux / macOS：`Ctrl+D` | 4（`\004`）    | 直接触发，无需回车                 |
| 物理 EOF        | 读取文件到达末尾               | 无（系统标志）      | -                         |

- `Ctrl+Z` / `Ctrl+D` 本身不是普通字符，而是操作系统终端驱动的特殊信号
- 一旦 `cin` 遇到 EOF，后续所有读取操作都会失败。
