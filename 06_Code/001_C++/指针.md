# `&` 与 `*` 符号在定义式和表达式中的不同含义

| 上下文       | 符号  | 含义     | 示例代码            | 说明       |
| --------- | --- | ------ | --------------- | -------- |
| **定义/声明** | `&` | 声明引用变量 | `int &ref = x;` | 创建变量别名   |
| **表达式**   | `&` | 取地址运算符 | `int *p = &x;`  | 获取变量地址   |
| **定义/声明** | `*` | 声明指针变量 | `int *ptr;`     | 创建指针变量   |
| **表达式**   | `*` | 解引用运算符 | `int y = *ptr;` | 访问指针指向的值 |

## 一、`&` 符号的双重身份

### 1. 在定义式中：表示"引用"

```cpp
int x = 10;
int &ref = x;  // 这里的 & 表示 "ref 是 x 的引用（别名）"
```

- **含义**：创建一个变量的别名
- **特点**：
    - 必须在声明时初始化
    - 一旦绑定到变量，不能重新绑定到其他变量
    - 操作 `ref` 就是直接操作 `x`
- **类比**：就像给一个人起个小名，叫小名时还是在叫这个人

### 2. 在表达式中：取地址运算符

```cpp
int x = 10;
int *ptr = &x;  // 这里的 & 是取 x 的内存地址
```

- **含义**：获取变量在内存中的地址
- **结果**：返回一个指针
- **类比**：就像获取一个人的家庭住址

## 二、`*` 符号的双重身份

### 1. 在定义式中：表示"指针"

```cpp
int x = 10;
int *ptr;  // 这里的 * 表示 "ptr 是一个指针变量"
ptr = &x;  // 初始化指针
```

- **含义**：声明一个存储内存地址的变量
- **特点**：
    - 可以不立即初始化（但最好初始化）
    - 可以更改指向的地址
- **类比**：就像一个记事本，可以记录不同的家庭住址

### 2. 在表达式中：解引用运算符

```cpp
int x = 10;
int *ptr = &x;
int y = *ptr;  // 这里的 * 是获取 ptr 指向地址的值
```

- **含义**：访问指针所指向内存位置的值
- **也称为**："间接访问"运算符
- **类比**：就像根据记事本上的地址，去那个人家里找东西
## 三、常见错误与注意事项

### 1. 混淆声明和表达式中的符号

```cpp
int x = 10;
int &ref;       // 错误！引用必须在声明时初始化
ref = &x;       // 错误！&x 是地址，不是引用

int *ptr;       // 正确，指针可以稍后初始化
ptr = x;        // 错误！应该用 &x 获取地址
```

### 2. 悬空指针/引用

```cpp
int* getPointer() {
    int x = 10;
    return &x;  // 严重错误！返回局部变量的地址
}               // 函数结束后，x 的内存被释放，指针变为"悬空"
```

### 3. 未初始化指针

```cpp
int *p;
*p = 10;  // 严重错误！p 未初始化，指向未知内存位置
```

### 4. 正确的初始化方式

```cpp
// 引用必须初始化
int x = 10;
int &ref = x;  // 正确

// 指针最好也立即初始化
int *ptr = nullptr;  // C++11中的空指针
int *ptr2 = &x;      // 或直接指向有效变量
```

---

指针实例：
```cpp
#include <iostream>
// 交换两个整数的值，传入两个指针

void swap(int *a, int *b) {
    // 使用临时变量存储其中一个值
    int temp = *a;   // 取出指针 a 所指向的值
    *a = *b;         // 将 b 指向的值赋给 a 指向的位置
    *b = temp;       // 将暂存的值赋给 b 指向的位置
}

int main() {
    int x = 10, y = 20;
    printf("交换前: x = %d, y = %d\n", x, y);

    // 传入 x 和 y 的地址，使得 swap 函数能直接修改它们
    swap(&x, &y);

    printf("交换后: x = %d, y = %d\n", x, y);

    return 0;
}
```

---

引用实例：
引用的实质就是常量指针，在底层确实就是通过指针来实现的，区别仅在于语法层面。逻辑上是等价的。
```cpp
#include <iostream>
using namespace std;

// 引用版本：形参是引用，直接绑定到实参
void swap(int &a, int &b) {   // 这里的 & 表示引用，不是取地址
    int temp = a;   // a 是实参的别名，直接使用
    a = b;
    b = temp;
}

int main() {
    int x = 10, y = 20;
    cout << "交换前: x = " << x << ", y = " << y << endl;
    swap(x, y);     // 直接传变量，函数内部通过引用修改 x,y
    cout << "交换后: x = " << x << ", y = " << y << endl;
    return 0;
}
```
