# 指针的基础概念
指针存储的是内存地址, 等价于无符号整数
引用和指针一体两面, 但是引用更方便, 更安全

## `&` 与 `*` 符号在定义式和表达式中的不同含义

| 上下文       | 符号  | 含义     | 示例代码            | 说明       |
| --------- | --- | ------ | --------------- | -------- |
| **定义/声明** | `&` | 声明引用变量 | `int &ref = x;` | 创建变量别名   |
| **表达式**   | `&` | 取地址运算符 | `int *p = &x;`  | 获取变量地址   |
| **定义/声明** | `*` | 声明指针变量 | `int *ptr;`     | 创建指针变量   |
| **表达式**   | `*` | 解引用运算符 | `int y = *ptr;` | 访问指针指向的值 |

### 一、`&` 符号重载

```cpp
//1. 在定义式中：表示"引用"
int x = 10;
int &ref = x;  // 这里的 & 表示 "ref 是 x 的引用（别名）"
```
- **含义**：创建一个变量的别名
    - 必须在声明时初始化
    - 一旦绑定到变量，不能重新绑定到其他变量
    - 操作 `ref` 就是直接操作 `x`

```cpp
//2. 在表达式中：取地址运算符
int x = 10;
int *ptr = &x;  // 这里的 & 是取 x 的内存地址
```
- **含义**：获取变量在内存中的地址


### 二、`*` 符号重载

```cpp
//1. 在定义式中：表示"指针"
int x = 10;
int *ptr;  // 这里的 * 表示 "ptr 是一个指针变量"
ptr = &x;  // 初始化指针
```
- **含义**：声明一个存储内存地址的变量

```cpp
//2. 在表达式中：解引用运算符
int x = 10;
int *ptr = &x;
int y = *ptr;  // 这里的 * 是获取 ptr 指向地址的值
```
- **含义**：访问指针所指向内存位置的值

# 指针的应用与复合
1. 通过[地址偏移运算]得到对应的地址
2. 使用[下标运算符]可以直接获取到对应地址的值
3. 数组会隐式退化为[第一个元素的指针],丢失长度信息
4. 可以定义[数组指针]保留数组的信息
5. [字符指针]在使用时和字符串类似, 都是以[[空白符与终止符|终止符]]为结束标记
6. [对象指针]在调用对象的内容时, 需要使用箭头来代替点
7. [迭代器]可以像指针一样通过`*`来取值
8. [函数指针]可以指向函数, 可以像函数一样使用
