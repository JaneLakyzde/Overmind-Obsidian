**迭代器（Iterator）** 是 C++ 标准模板库（STL）中的一种抽象概念，它提供了一种统一的方式来访问容器（如 `vector`、`list`、`map`）中的元素，而无需暴露容器的底层实现。迭代器本质上是一个行为类似指针的对象，支持解引用（`*`）和递增（`++`）等操作，可以用来遍历容器中的元素序列。

在 C++ 中，迭代器通过一组类型要求（concepts） 来定义，不同的迭代器类别支持不同的操作集。每个容器都定义了自己的迭代器类型（如 `std::vector<int>::iterator`），并提供了 `begin()` 和 `end()` 成员函数来获取指向首元素和尾后位置的迭代器。
