[[空白符与终止符]]

# `cin >>` 
跳过所有空白符 + 按类型解析 + 在第一个不匹配字符处停止

# `getchar()` 
不跳过空白符 + 读取当前缓冲区的1个字符 + 读取后指针后移1位

# `cin.get(c)` 
不跳过空白符 + 读取当前缓冲区的1个字符 + 读取后指针后移1位 

# `cin.get()` 
不跳过空白符 + 读取当前缓冲区的1个字符（以int返回） + 读取后指针后移1位

# `getline(cin, s)` 
不跳过空白符 + 从当前位置开始读取所有字符 + 遇到分隔符'\n'停止并丢弃 

# `scanf` 
按格式串解析 +（大多数格式）跳过前导空白符 + 按规则读取 + 在不匹配处停止（未匹配字符保留）

# `cin.peek` 
不跳过空白符 + 查看当前字符但不取出 + 指针不移动

`getchar()`是`c`风格, `cin.get(c)`是`cpp`风格,两者无差别
