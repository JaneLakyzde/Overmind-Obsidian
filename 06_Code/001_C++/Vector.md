## 1. 初始化

`vector` 是模板类，初始化时必须指定元素类型 `<T>`。

|方式|代码示例|说明|
|---|---|---|
|**默认构造**|`vector<int> v;`|创建一个空的 int 向量。|
|**指定大小**|`vector<int> v(n);`|创建含有 n 个元素的向量，默认值均为 0。|
|**指定大小与初始值**|`vector<int> v(n, val);`|创建 n 个元素，每个值都是 `val`。|
|**拷贝构造**|`vector<int> v1(v2);`|完全复制 `v2` 的内容。|
|**列表初始化**|`vector<int> v{1, 2, 3};`|C++11 特性，直接定义初始内容。|
|**区间初始化**|`vector<int> v(it1, it2);`|从另一个容器的迭代器区间复制。|

## 2. 基础信息与容量 

- **`size()`**: 返回当前元素个数。
- **`empty()`**: 检查是否为空。
- **`resize(n)`**: 强制改变大小。如果扩大，新元素默认初始化；如果缩小，末尾元素被丢弃。
- **`reserve(n)`**: 预留空间，避免频繁触发内存重分配。
- **`capacity()`**: 返回当前不分配新内存的情况下最多能容纳的元素数。

## 3. 元素访问与修改

- **`operator[]`**: 随机访问，下标从 0 开始。
- **`front()` / `back()`**: 返回首个/最后一个元素的**引用**。
- **`push_back(val)`**: 在末尾添加元素。
- **`pop_back()`**: 删除末尾元素。
- **`assign(n, val)`**: 重新分配内容，旧内容全部清空。

```
vector<int> v = {10, 20, 30};
v.push_back(40);    // {10, 20, 30, 40}
v.back() = 100;     // 修改末尾元素，变为 {10, 20, 30, 100}
```

## 4. 插入与删除

注意：`vector` 在中间插入或删除的效率是 O(n)，因为需要移动后续元素。

- **`insert(it, val)`**: 在迭代器 `it` 指向的位置插入 `val`。
- **`erase(it)`**: 删除迭代器 `it` 指向的元素。
- **`erase(it1, it2)`**: 删除 `[it1, it2)` 区间内的元素。
- **`clear()`**: 清空所有元素。

```
v.erase(v.begin()); // 删除第一个元素
v.insert(v.begin() + 1, 99); // 在下标为1的位置插入99
```

## 5. 算法库联动

`vector` 经常配合 `<algorithm>` 头文件使用，这是它比原生数组强大的地方。

- **`sort(v.begin(), v.end())`**: 快速排序。
- **`reverse(v.begin(), v.end())`**: 翻转向量。
- **`lower_bound()` / `upper_bound()`**: 在**有序**向量中进行二分查找。
- **`unique()`**: 去重（通常配合 `sort` 和 `erase` 使用）。

```
// 经典的去重三连招
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
```
