# 2. 权限管理

| 对象类型  | 对象     | 操作类型                                                          |
| ----- | ------ | ------------------------------------------------------------- |
| 数据库模式 | 模式     | CREATE SCHEMA                                                 |
|       | 基本表    | CREATE TABLE, ALTER TABLE                                     |
|       | 视图     | CREATE VIEW                                                   |
|       | 索引     | CREATE INDEX                                                  |
| 数据    | 基本表和视图 | SELECT, INSERT, UPDATE, DELETE,<br>REFERENCES, ALL PRIVILEGES |
|       | 属性列    | SELECT, INSERT, UPDATE, <br>REFERENCES, ALL PRIVILEGES        |

### 授予权限
```sql
GRANT <权限列表> ON <表名/列名> TO <用户或角色>;

[with grant option]表示管理员把分发权限授予普通用户
然后普通用户获得授权后可以把自己权限授予其他用户。

-- 授予用户对 students 表的 SELECT 和 UPDATE 权限
GRANT SELECT, UPDATE ON students TO user_1;

-- 授予用户对 students 表 id 列的 SELECT 和 UPDATE 权限
GRANT SELECT, UPDATE ON students(id) TO user_1;

-- 授予所有权限（慎用！）
GRANT ALL PRIVILEGES ON students TO user_1;
```

### 撤销权限:
```sql
-- 撤销user1用户对 students 的插入权限
REVOKE INSERT ON students FROM user_1;
区分[cascade] [restrict] [grant option for]的不同作用效果
```

### 角色管理
```sql
-- 创建角色并分配权限
CREATE ROLE student_reader;
GRANT SELECT ON students TO student_reader;

-- 将角色赋予用户lihua
GRANT student_reader TO lihua;

-- 角色权限收回
REVOKE 权限 ON 表名 FROM 角色名
REVOKE SELECT ON student FROM student——reader
```

# 3. 数据加密
目的: 防止敏感数据在存储或传输过程中被窃取.
## 存储加密
存储通常使用[[AES]]
加密后的数据使用 BLOB 类型存储, 因为加密后的数据是二进制
```sql
INSERT INTO students VALUES (23, AES_ENCRYPT('lihua','key123'),33);
```
## 传输加密

- 使用 [[SSL和TLS|SSL和TLS]]协议加密数据库连接

# 4. 视图机制
```sql
-- 创建视图, 仅暴露姓名和年龄
CREATE VIEW StudentView AS SELECT 姓名, 年龄 FROM Studnet;

-- 授予用户访问视图的权限
GRANT SELECT ON StudentView TO user_1
GRANT ALL PRIVILIEGES ON StudentView To user_1;
```
1. 多联表视图不允许更新
2. 使用了分组聚合操作的视图不允许更新
3. 行列子集视图可以更新

# 数据备份与恢复
防止数据丢失。
```sql
# 使用 mysqldump 备份整个数据库
mysqldump -u 用户名 -p 密码 --databases 数据库名 > backupfile.sql

# 如果您只想备份单个表，则请执行以下 mysqldump 命令：
mysqldump -u 用户名 -p 密码 数据库名 表名 > backupfile.sql
```

# 5. 审计与监控
- 日志审计：记录所有 SQL 操作（如用户登录、数据修改）。
```sql
# SQL Server 启用审计
CREATE SERVER AUDIT SecurityAudit TO FILE (FILEPATH='D:\AuditLogs\');

# MySQL
-- 安装审计插件
INSTALL PLUGIN audit_log SONAME 'audit_log.so';

-- 配置审计日志路径
SET GLOBAL audit_log_file = '/var/log/mysql/audit.log'
```
