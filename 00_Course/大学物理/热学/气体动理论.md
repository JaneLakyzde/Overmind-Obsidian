# 1. 状态方程
**理想气体状态方程：**
$$PV = \frac{m}{M}RT$$
$$P = nkT$$

*   **参数与单位：**
    *   压强 $P$：$Pa$
    *   体积 $V$：$m^3$
    *   温度 $T$：$K$
    *   单位体积分子数 $n$：$n = \frac{N}{V}$
*   **常数：**
    *   普适气体常量：$R = 8.31 \, J/(mol \cdot K)$
    *   玻尔兹曼常数：$k = 1.38 \times 10^{-23} \, J/K$

**常识：**
1. 热力学温标 $T$ 与摄氏温标 $t$ 的关系：$T = 273 + t$
2. 标准大气压：$1 \, atm = 101325 \, Pa$
3. 标准状态：$P = 1 \, atm, \, T = 273 \, K$

**常见气体摩尔质量（g/mol）：**
*   氢气 $H_2$：2
*   氦气 $He$：4
*   氖气 $Ne$：20
*   氮气 $N_2$：28（例：$0.028kg$ 氮气 $\frac{m}{M} = \frac{28}{28} = 1 \, mol$）
*   氧气 $O_2$：32（例：$2 \, mol$ 氧气 $m = 2 \times 32 = 64g$）

# 2. 内能
**分子内能 = 分子平动动能 + 分子转动动能**
**能量按自由度均分定理：** $\bar{\varepsilon} = \frac{1}{2}kT$

| 分子类型 | 自由度 $i$ | 平动动能 $\bar{\varepsilon}$ | 转动动能 $\bar{\varepsilon}$ | 总动能（内能） $\bar{\varepsilon}$ |
| :---: | :---: | :---: | :---: | :---: |
| 单原子 ($He$) | $3+0 = 3$ | $\frac{3}{2}kT$ | $0$ | $\frac{3}{2}kT$ |
| 双原子 ($O_2$) | $3+2 = 5$ | $\frac{3}{2}kT$ | $\frac{2}{2}kT$ | $\frac{5}{2}kT$ |
| 多原子 ($H_2O$) | $3+3 = 6$ | $\frac{3}{2}kT$ | $\frac{3}{2}kT$ | $\frac{6}{2}kT$ |

**宏观气体公式：**
*   自由度：单原子 $i=3$，双原子 $i=5$，多原子 $i=6$
*   平动动能：$E = \frac{3}{2} \frac{m}{M} RT$
*   内能：$E = \frac{i}{2} \frac{m}{M} RT$

# 3. 速度分布函数
**麦克斯韦分布函数：**
$$f(v) = 4\pi \left(\frac{m}{2\pi kT}\right)^{\frac{3}{2}} e^{-\frac{mv^2}{2kT}} v^2$$

**归一性：** $\int_{0}^{+\infty} f(v) dv = 1$

**积分物理意义：**
① $\int_{v_1}^{v_2} f(v) dv$：表示 $v_1 \sim v_2$ 间分子数占总分子数百分比。
② $f(v) dv$：表示 $v \sim v+dv$ 间分子数占总分子数百分比。
③ $\int_{v_1}^{v_2} N f(v) dv$：表示 $v_1 \sim v_2$ 间分子数。
④ $f(v)$：表示速率 $v$ 在附近单位速率间隔内的分子数占总分子数的百分比。

# 4. 三种常用速率
*   **平均速率：** $\bar{v} = \sqrt{\frac{8RT}{\pi M}}$
*   **方均根速率：** $\sqrt{\overline{v^2}} = \sqrt{\frac{3RT}{M}}$
*   **最概然速率：** $v_p = \sqrt{\frac{2RT}{M}}$

# 5. 典型例题

**题1（速度分布函数）：**
有 $N$ 个假想气体分子，速率分布如图（当 $v > 2v_0$ 时，分子数为零）。求：
(1) $f(v)$；(2) 求 $a$；(3) 速率在 $1.5v_0 \sim 2v_0$ 的分子数；(4) 平均速率和方均根速率。

**解：**
(1) 由分布图可得：
$$f(v) = \begin{cases} 
\frac{2v}{3v_0^2} & 0 \le v < v_0 \\
\frac{2}{3v_0} & v_0 \le v \le 2v_0 \\
0 & 2v_0 < v 
\end{cases}$$

(2) 由归一化条件 $\int_{0}^{+\infty} f(v) dv = 1$：
$$\int_{0}^{v_0} \frac{a}{Nv_0}v dv + \int_{v_0}^{2v_0} \frac{a}{N} dv = 1 \implies \frac{av_0}{2N} + \frac{av_0}{N} = 1 \implies a = \frac{2N}{3v_0}$$

(3) 速率在 $1.5v_0 \sim 2v_0$ 的分子数占总分子数的比例 $P = \frac{1}{3}$：
$$\Delta N = N \cdot P = \frac{N}{3}$$

(4) 
平均速率：$\bar{v} = \int_{0}^{+\infty} v f(v) dv = \int_{0}^{v_0} v \frac{2v}{3v_0^2} dv + \int_{v_0}^{2v_0} v \frac{2}{3v_0} dv = \frac{11}{9}v_0$
方均根速率：$\sqrt{\overline{v^2}} = \sqrt{\int_{0}^{+\infty} v^2 f(v) dv} = \sqrt{\frac{31}{18}}v_0$

**题2（方均根速率计算）：**
某气体 $T = 273K$，压强 $P = 1.0 \times 10^{-2} atm$，密度 $\rho = 1.24 \times 10^{-2} kg/m^3$，求该气体分子的方均根速率。（注：计算时需将压强单位换算为 $Pa$）

**解：**
由 $PV = \frac{m}{M}RT \implies M = \frac{mRT}{PV} = \frac{\rho RT}{P}$
代入方均根速率公式：
$$\sqrt{\overline{v^2}} = \sqrt{\frac{3RT}{M}} = \sqrt{\frac{3RT}{\frac{\rho RT}{P}}} = \sqrt{\frac{3P}{\rho}}$$
代入数值（$P = 1.0 \times 10^{-2} \times 1.013 \times 10^5 Pa$）：
$$\sqrt{\overline{v^2}} = \sqrt{\frac{3 \times 1.0 \times 10^{-2} \times 1.013 \times 10^5}{1.24 \times 10^{-2}}} = 495 \, m/s$$
