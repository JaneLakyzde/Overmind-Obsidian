
# 1. 求电场强度 ($\vec{E}$)

## 1.1 离散型

- **库仑定律:**$$F = \frac{1}{4\pi\epsilon_0} \frac{q_1 q_2}{r^2}$$
    
    - **方向：** 沿电荷连线。同性相斥，异性相吸。
    - **正反比：** 与电荷量乘积成**正比**，与距离平方成**反比**。
    - **真空介电常量：$\epsilon_0 \approx 8.854 \times 10^{-12} \, \text{C}^2/(\text{N}\cdot\text{m}^2)$ 
        
- **电场强度公式:**$$\vec{E} = \frac{\vec{F}}{q_0} = \frac{1}{4\pi\epsilon_0} \frac{Q}{r^2} \hat{r}$$
    
    - **方向判定：** 正电荷场强背离场源，负电荷场强指向场源。
    - **性质：** $\vec{E}$ 是电场本身的属性，**与场源电荷、位置有关，与试探电荷无关**。

---

## 1.2 连续型

- **直线型例题：**
    
    1. 取线元 $dx$，对应电荷量 $dq = \lambda dx$。
    2. 确定微元场强        $$dE = \frac{1}{4\pi\epsilon_0} \frac{dq}{r^2}$$
    3. 若要求轴线上某点，直接求和：
        $$E = \int \frac{\lambda dx}{4\pi\epsilon_0 x^2}$$
    4. 若要求垂线上某点，需分解为 $dE_x, dE_y$ 后分别积分。
        
- **半圆环型例题：**
    
    1. 建立极坐标，取电荷微元 $dq = \lambda R d\theta$。
    2. 利用对称性：水平分量 $E_x$ 抵消。        
    3. 对垂直分量积分：
        
        $$E_y = \int_{-\pi/2}^{\pi/2} \frac{\lambda R d\theta}{4\pi\epsilon_0 R^2} \cos\theta = \frac{\lambda}{2\pi\epsilon_0 R}$$

---

## 1.3 结论型

#### 基本与几何型

|**模型**|**场景/位置**|**场强公式 E**|
|---|---|---|
|**点电荷**|距离 $r$ 处|$$E = \frac{Q}{4\pi\epsilon_0 r^2}$$|
|**无限长导线**|垂直距离 $r$ 处|$$E = \frac{\lambda}{2\pi\epsilon_0 r}$$|
|**半圆环**|圆心处|$$E = \frac{\lambda}{2\pi\epsilon_0 R}$$|
|**均匀带电圆环**|轴线上距离 $x$ 处|$$E = \frac{Qx}{4\pi\epsilon_0 (x^2 + R^2)^{3/2}}$$|
|**均匀带电圆面**|轴线上距离 $x$ 处|$$E = \frac{\sigma}{2\epsilon_0} \left( 1 - \frac{x}{\sqrt{x^2+R^2}} \right)$$|

---
#### 高斯定理推导型 ($\oint \vec{E} \cdot d\vec{A} = \frac{\sum q_{in}}{\epsilon_0}$)

| **模型**     | **区域**          | **场强公式 E**                                                         |
| ---------- | --------------- | ------------------------------------------------------------------ |
| **无限大平板**  | 板外（匀强）          | $$E = \frac{\sigma}{2\epsilon_0}$$                                 |
| **无限长圆柱**  | $r > R$         | $$E = \frac{\lambda}{2\pi\epsilon_0 r}$$                           |
|            | $r < R$ (均匀分布)  | $$E = \frac{\rho r}{2\epsilon_0}$$                                 |
| **均匀带电球体** | $r > R$ (等效点电荷) | $$E = \frac{Q}{4\pi\epsilon_0 r^2}$$                               |
|            | $r < R$         | $$E = \frac{Qr}{4\pi\epsilon_0 R^3} = \frac{\rho r}{3\epsilon_0}$$ |
| **均匀带电球壳** | $r > R$         | $$E = \frac{Q}{4\pi\epsilon_0 r^2}$$                               |
|            | $r < R$         | $$E = 0$$                                                          |
