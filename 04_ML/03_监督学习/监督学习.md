# 1. 定义

监督学习是一种利用**已标注数据集**训练模型的机器学习范式。模型通过学习输入特征与输出标签之间的映射关系，从而能够对新的、未见过的数据进行预测。其核心目标是让模型**泛化**到与训练数据同分布的未知样本上。

- **标注数据**：每个样本都包含输入特征和对应的正确答案（即真实标签 / Ground Truth）。
- **学习过程**：算法不断调整模型参数，最小化预测输出与真实标签之间的差异。

# 2. 核心要素

- **输入空间** $\mathcal{X}$：特征向量所在的空间。
- **输出空间** $\mathcal{Y}$：标签或数值的集合。
- **训练集** $D = \{(x_i, y_i)\}_{i=1}^N$，其中 $y_i$ 是真实标签。
- **损失函数 (Loss Function)**：衡量单次预测误差的函数。
- **代价函数 (Cost Function)**：整个训练集上的平均损失。
- **优化算法**：如梯度下降，通过最小化代价函数调整模型参数。

> **补充说明**：损失函数的选择由任务决定。分类常用交叉熵损失，回归常用均方误差 (MSE)。优化时通过反向传播计算梯度，再沿负梯度方向更新权重。

# 3. 主要任务类型

#### 3.1 分类 (Classification)
预测离散标签，输出属于某个类别的概率或直接归类。
- **二分类**：如垃圾邮件检测（是/否）。
- **多分类**：如图像识别（猫、狗、鸟）。
- **多标签分类**：一个样本可同时属于多个类别。
#### 3.2 回归 (Regression)
预测连续数值，输出为一个实数。
- 示例：房价预测、股价预测、温度预测。

# 4. 常见监督学习算法一览

- **线性模型**：
  - [[线性回归]]（最小二乘法）
  - [[逻辑回归]]（实际上为分类）
  - 带正则化的回归：[[岭回归]] (L2)、[[套索回归]] (L1)、弹性网络
- **非线性模型**：
  - 多项式回归（特征升维后仍使用线性方法拟合）

  - [[神经网络]]（深度前馈网络、CNN、RNN 等）

# 5. 训练与评估流程

1. **数据划分**：通常分为训练集、验证集、测试集。
2. **模型训练**：在训练集上优化参数。
3. **验证与调参**：利用验证集选取超参数，防止过拟合。
4. **测试**：在测试集上评估最终泛化能力。
5. **交叉验证 (Cross-Validation)**：常用 K 折交叉验证以充分利用数据，尤其适合小数据集。

# 6. 关键挑战与应对

- **过拟合 (Overfitting)**：模型在训练集上表现极好，但在新数据上误差大。
  - 应对：正则化、增大训练数据、早停、Dropout（神经网络）、集成方法。
- **欠拟合 (Underfitting)**：模型连训练集上的规律都没学好。
  - 应对：增加模型复杂度、添加更多特征、减少正则化。
- **数据偏差**：训练标签存在人为偏差或不平衡，导致模型学到不公平或错误的关联。
  - 应对：数据重采样、类别权重调整、偏差审计。
- **标注成本高昂**：需要大量人工标注，尤其是专业领域。
  - 可考虑半监督学习、自监督学习或主动学习来缓解。

### 7. 与其他学习范式的对比
| 范式 | 数据特点 | 反馈信号 | 典型应用 |
|------|----------|----------|----------|
| 监督学习 | 全部有标签 | 真实标签 | 垃圾邮件检测、图像分类 |
| 无监督学习 | 全部无标签 | 数据内在结构 | 聚类、降维、异常检测 |
| 半监督学习 | 少量有标签 + 大量无标签 | 标签 + 结构 | 标注稀缺场景 |
| 自监督学习 | 大量无标签，自动生成伪标签 | 伪标签 | 预训练语言模型、视觉表征 |
| 强化学习 | 智能体与环境交互 | 奖励信号 | 游戏AI、机器人控制 |

### 8. 现实应用
- **图像与物体识别**：人脸识别、医疗影像诊断。
- **自然语言处理**：情感分析、意图识别、文本分类。
- **金融风控**：信用评分、欺诈检测。
- **推荐系统**：基于用户行为的协同过滤通常可用监督学习实现。
- **预测性维护**：基于传感器数据预测设备故障。

> 监督学习是工业界应用最广泛、理论最成熟的机器学习范式。其成功依赖于高质量标注数据的规模与代表性。
