# 1. 核心定义

随机森林是一种基于**集成学习 (Ensemble Learning)** 中 **[[Bagging]] (装袋法)** 思想的算法。它通过构建大量互不相关的**决策树**，并对它们的输出进行汇总（分类问题用多数投票，回归问题用平均），来得到一个更稳定、更准确的单一结果。该算法由 Leo Breiman 和 Adele Cutler 提出。

> **补充 - Bagging 的本质**：Bagging 的核心思想是 **Bootstrap Aggregating**。它的威力在于能有效降低模型的**方差 (Variance)**。因为每棵树都是在不同的数据子集和特征子集上训练的，它们犯错误的“模式”各不相同，取平均或投票恰好能抵消掉这些不相关的随机误差。

# 前置概念：[[决策树]]
随机森林由决策树构成。决策树通过一系列**决策节点**（如“这个像素值大于 100 吗？”），将数据按分支划分，最终在**叶节点**上给出结论。
- **分裂目标**：找到最优切分特征及切分点，使子节点的不纯度最低。
- **常用评估指标**：
  - **分类**：熵、基尼系数
  - **回归**：均方误差 (MSE)。
- **核心缺陷**：单棵决策树极易**过拟合**，且对数据微小变化敏感，属于**高方差**模型。

# 随机森林的两重随机性
这是它区别于单一决策树的关键，也是其降低方差的根本原因：

1.  **样本随机性 (Bagging)**：每棵树使用的训练集，是从原始数据中有放回地抽取的 **Bootstrap 样本**。每次约有 1/3 的样本未被抽中，这些被称为**袋外数据 (Out-of-Bag, OOB)**，它们可作为无偏的验证集来评估模型性能。
2.  **特征随机性 (Feature Randomness)**：每个决策节点在选择最优分裂特征时，不是从全部 $M$ 个特征中选，而是从一个随机抽取的、包含约 $\sqrt{M}$ (分类) 或 $M/3$ (回归) 个特征的子集中选。

> 如果只有样本随机性，那么每棵树中的强特征总会被优先选中，导致各棵树长得非常相似根据统计原理，平均一堆高度相关的模型，并不能显著降低方差。**特征随机性**强制各棵树在不同的特征组合上探索，降低了树与树的相关性，从而让集成后的方差降低效果达到最优。

# 核心超参数
- **`n_estimators` (树的数量)**：树木越多，效果越稳定，但边际收益递减。
- **`max_features` (节点分裂时的最大特征数)**：控制随机性强度和单棵树的强度。推荐默认值。
- **`max_depth` / `min_samples_split`**：控制单棵树的生长复杂度，防止单棵树木过拟合。

# 优势与挑战
- **优势**
  - **抗过拟合能力强**：在大数据量和多特征时，方差远低于决策树。
  - **用途灵活**：原生支持分类与回归，可处理特征缺失，能给出 [[特征重要性]] 评估。
  - **评估便捷**：利用 **OOB 误差** 不需要额外划分验证集。
- **挑战**
  - **计算密集**：树多、特征多时，训练时间长，内存消耗大。
  - **可解释性差**：模型成了“黑箱”，远不如单棵决策树直观。
  - **对高维稀疏数据不擅处理**：如超高维文本数据，特征随机可能总选到噪声。

# 特征重要性

随机森林提供了一套自然的特征选择机制。常用的衡量方法是：
- **基于杂质的平均减少 (MDI)**：统计特征在所有树中用于分裂时，带来的不纯度减少总量（加权平均）。计算快，但偏好高基数特征。

- **基于排列的重要性 (MDA)**：在 OOB 数据上随机打乱某特征的值，观察模型误差增加的幅度。误差增加越多，该特征越重要。此方法更可靠，但计算慢。
