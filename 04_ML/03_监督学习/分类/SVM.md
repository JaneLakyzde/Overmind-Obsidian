# 支持向量机（SVM）— 核心知识点总结

## 1. 算法概览

- **全称**：Support Vector Machine，支持向量机
- **类型**：监督学习算法，主要用于分类，也可扩展用于回归（SVR）
- **提出者**：Vladimir N. Vapnik 及其同事，1995 年
- **核心思想**：在 N 维空间中找到一个最优超平面，使两个类别之间的**间隔（margin）最大化**，从而获得最好的泛化能力。


## 2. 核心概念图解
![[3-1_svm_optimal-hyperplane_max-margin_support-vectors-2-1-16x9.png]]

| 术语       | 含义                               |
| -------- | -------------------------------- |
| **超平面**  | 分割数据的决策边界；二维中是线，三维中是面，更高维是超平面    |
| **支持向量** | 距离超平面最近的那些数据点，它们直接决定了超平面的位置和方向   |
| **间隔**   | 超平面到最近支持向量之间的距离；SVM 的目标就是最大化这个间隔 |

## 3. 关键公式

### 3.1 超平面方程

决策边界（超平面）的数学表达式为：

$$\mathbf{w} \cdot \mathbf{x} + b = 0$$

其中：
- $w$ 是权重向量（决定超平面的方向）
- $x$ 是输入向量
- $b$ 是偏置项（决定超平面与原点距离）

分类决策规则：若 $\mathbf{w} \cdot \mathbf{x} + b > 0$ 预测为正类，否则为负类。

### 3.2 硬间隔 SVM（Hard Margin）

要求所有样本完全正确分类，且位于间隔区外：

$$y_j (\mathbf{w} \cdot \mathbf{x}_j + b) \geq 1, \quad \forall j$$

最大化的间隔为：

$$\text{max } \gamma = \frac{1}{\|\mathbf{w}\|}$$

等价于最小化 $\frac{1}{2}\|\mathbf{w}\|^2$，在约束条件下求解。这只适用于线性完全可分的数据。

### 3.3 软间隔 SVM（Soft Margin）

引入**松弛变量** $\xi_j \geq 0$，允许个别样本误分类或落入间隔内：

$$y_j (\mathbf{w} \cdot \mathbf{x}_j + b) \geq 1 - \xi_j, \quad \forall j$$

优化目标变为两项之和（间隔最大化 + 误差最小化）：

$$\min_{\mathbf{w}, b, \xi} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{j=1}^{n} \xi_j$$

**C** 是正则化超参数：
- **C 较大** → 间隔窄，对误分类惩罚重 → 更严格（可能过拟合）
- **C 较小** → 间隔宽，容许更多误分类 → 更平滑（可能欠拟合）

## 4. 线性 SVM 与非线性 SVM

### 4.1 线性 SVM
- 适用于**线性可分**的数据。
- 可直接用超平面划分，无需对数据进行空间变换。

### 4.2 非线性 SVM 与核技巧
- 现实数据往往**线性不可分**。
- 解决方法：通过**核函数**将数据映射到高维空间，使其在高维中线性可分。
- **核技巧**：直接计算高维空间中向量的点积，而不必显式地进行高维映射，降低计算负担。

**常用核函数：**

| 核类型          | 表达式                                                                                 | 说明                                  |
| ------------ | ----------------------------------------------------------------------------------- | ----------------------------------- |
| 线性核          | $K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i \cdot \mathbf{x}_j$                   | 相当于不做映射，用于线性可分场景                    |
| 多项式核         | $K(\mathbf{x}_i, \mathbf{x}_j) = (\mathbf{x}_i \cdot \mathbf{x}_j + c)^d$           | 有度数 $d$ 可调，适用于有一定多项式关系的数据           |
| RBF（径向基/高斯）核 | $K(\mathbf{x}_i, \mathbf{x}_j) = e^{-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2}$     | 最常用，可处理复杂非线性关系；$\gamma$ 控制单个样本的影响范围 |
| Sigmoid 核    | $K(\mathbf{x}_i, \mathbf{x}_j) = \tanh(\alpha \mathbf{x}_i \cdot \mathbf{x}_j + c)$ | 模仿神经网络激活函数                          |

## 5. 支持向量回归（SVR）

- **SVR** 是 SVM 在回归问题上的扩展，预测**连续值**。
- 同样寻找一个“管道状”超平面，使大部分数据点落在管道内，间隔最大化。
- 与线性回归的区别：SVR 不需要事先假设自变量与因变量的明确关系，自动确定映射关系。常用于时间序列预测等任务。

## 6. SVM 的主要特点

### 优点
- 在高维数据上表现优秀（如文本、图像）
- 泛化能力强，对过拟合有较好控制（尤其通过最大化间隔）
- 通过核技巧可处理复杂的非线性问题
- 相对可解释（支持向量提供清晰的决策依据）

### 缺点
- 计算成本高，在大规模数据集上训练慢、内存消耗大
- 需要仔细调整超参数（C、核函数类型、γ 等）
- 对缺失数据敏感
- 结果不如神经网络灵活可扩展（在极大规模数据集上）

## 7. SVM 与其他算法简要比对

| 对比算法  | SVM 的优势             | SVM 的不足     |
| ----- | ------------------- | ----------- |
| 朴素贝叶斯 | 非线性场景表现更好           | 计算成本更高，需调参  |
| 逻辑回归  | 处理高维、非结构化数据更好，不易过拟合 | 计算成本更高      |
| 决策树   | 高维数据更好，不易过拟合        | 训练较慢，可解释性略逊 |
| 神经网络  | 不易过拟合，可解释性更好        | 灵活性、扩展性不足   |

## 8. 模型构建与调优流程

1. **数据拆分**：划分为训练集和测试集，完成探索性数据分析。
2. **模型训练**：导入 SVM 模块（如 sklearn.svm），拟合训练数据。
3. **性能评估**：使用准确率、精确率、召回率、F1 分数等指标对比测试集。
4. **超参数调优**：通过**网格搜索 + 交叉验证**寻找最优组合（核函数、C、γ 等）。
