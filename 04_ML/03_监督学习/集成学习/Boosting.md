Boosting 是一类**顺序式**集成方法，旨在将多个弱学习器组合成一个强学习器，**核心目标是系统地降低偏差**。
# 1. 核心思想

-   **串行学习，聚焦错误**：模型按序生成，每个新模型都专注于纠正前一个模型所犯的错误。这就像一位学生反复钻研错题集，一步步补齐短板。
-   **与 Bagging 的本质区别**：Boosting 通过不断“查漏补缺”**降低偏差**，而 Bagging 通过并行独立训练和平均来**降低方差**。两者分别应对欠拟合和过拟合。

# 2. 三种主流 Boosting 算法

-   **AdaBoost - 自适应提升**
    -   **机制**：每轮训练后，**提高被误分样本的权重**，强制下一个学习器重点关注这些“难题”。
    -   **特点**：最初代的 Boosting 算法，相当于调整考卷中错题的分数占比。
	
-   **Gradient Boosting - 梯度提升**
    -   **机制**：不调整样本权重，而是让每个新模型直接去**拟合前一个模型的残差**，逐步缩小误差缺口。
    -   **特点**：引入了梯度下降的思想，适用性更广，是当前主流框架。
	
-   **XGBoost / LightGBM**
    -   **机制**：梯度提升的工业级优化实现，通过并行计算、正则化等手段**大幅提升训练速度并抑制过拟合**。
    -   **注意**：它们并非 sklearn 内置，而是独立的第三方库。
	

# 3. 优点与挑战
| 优点 | 挑战 |
| :--- | :--- |
| **减偏差能力强**：能有效把简单的弱模型提升为复杂的强模型。 | **易过拟合**：顺序聚焦错误样本，模型可能过度学习数据中的噪声，导致泛化能力下降。 |
| **实施方便**：`sklearn.ensemble` 提供了 `AdaBoost`、`GradientBoosting` 等，参数调优直接。 | **计算成本高**：顺序训练本身难以并行，训练速度通常慢于 Bagging。 |
| **自适应性**：天然擅长处理不平衡分布或难样本。 | **对异常值敏感**：由于错误会被重点关注，离群点可能被过分放大。 |
