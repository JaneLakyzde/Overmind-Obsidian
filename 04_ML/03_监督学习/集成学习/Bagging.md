Bagging 是一种**并行式**集成学习方法，全称为 Bootstrap Aggregating（引导聚合）。其核心目标是**系统地降低模型的方差**，防止过拟合。

# 1. 核心思想

- **独立并行，平均消噪**：通过在原始数据集上反复“有放回抽样”创造出多个不同的训练子集，并在每个子集上独立训练同类模型，最后将它们的预测结果平均或投票。这个过程相当于收集一群专家的独立判断，能有效消除个别专家因“看到的数据面过窄”而产生的极偏结论。
    
- **本质目标**：主要针对**高方差、低偏差**的模型（如完全生长的决策树）。这些模型在稍有变化的数据上输出差异巨大（方差高），Bagging 通过“取平均”把波动压下去。
    
# 2. 三步工作原理

1. **Bootstrap（引导采样）**：从原始数据集中**有放回地**随机抽取 n 个样本，生成一个 Bootstrap 子集。这意味着大约 63% 的样本会被抽中，剩下的 37% 自然成为**袋外样本**，可用来验证模型而不需额外划分数据。
    
2. **并行训练**：重复步骤1多次，生成多个不同的 Bootstrap 子集，并在每个子集上独立训练一个基础学习器。
    
3. **聚合**：
    
    - **回归**：对各个模型的输出取平均值。
        
    - **分类**：进行多数投票（硬投票）或概率平均（软投票）。
        

# 3. Bagging 与 Boosting 的核心差异速览

|特征|Bagging|Boosting|
|---|---|---|
|**训练方式**|各学习器**独立并行**训练|学习器**依序依赖**训练|
|**主要降低**|**方差**（解决过拟合）|**偏差**（解决欠拟合）|
|**采样方式**|有放回 Bootstrap 抽样|通常依据上一轮错误调整样本权重，不一定是简单重采样|
|**代表算法**|随机森林|AdaBoost, GBDT, XGBoost|

# 4. 延伸：[[随机森林]]

随机森林是 Bagging 的经典扩展。它做了两层随机化进一步降低方差：

- **样本随机**：对数据有放回抽样（Bagging 的思想）。
    
- **特征随机**：每个节点分裂时，仅从特征的随机子集中寻找最优切分点。这使得每棵树长得更“去相关”，平均后方差更低。
    

# 5. 优势与挑战

|优势|挑战|
|---|---|
|**降方差效果显著**：能极大抑制复杂模型（如深度树）的过拟合。|**可解释性差**：从单一明确规则变成众多模型“投票”，业务解读模糊。|
|**实现简单**：`sklearn.ensemble.BaggingClassifier/Regressor`开箱即用。|**计算成本高**：需要训练大量基础学习器，训练和预测都可能较慢。|
|**有天然验证集**：袋外误差可近似交叉验证，无需再切数据。|**对稳定模型提升有限**：线性回归等低方差模型再用 Bagging，效果微弱。|
