## 1. 核心定义
- **自回归模型**：一种用于时间序列分析和预测的[[机器学习]]技术，使用时间序列自身先前时间步的一个或多个值（滞后值）作为预测变量，建立回归模型来预测当前或未来值。

> 如果我用气温去预测冰淇淋销量，那是**多元回归**或**交叉回归**。但如果我用昨天气温预测今天气温，那就是**自回归**。

### 2. 基本原理
- **自相关性**：数据跨时间步长与其自身的相关性。值与其滞后值之间的相关性越强，预测效果越好。
- **适用与不适用场景**：
  - 纯线性过程：完美自相关，可准确预测。
  - 完全随机过程（白噪声）：无自相关，无法通过过去值预测。
- **时间序列**：同一变量随时间均匀间隔测量的一系列值（如每小时、每月）。

### 3. 模型表示与阶数
- **AR(1) 一阶自回归**：以过去 $p$ 个数据点的线性组合表示的未来数据点
	  $$ x_t = \delta + \phi_1 x_{t-1} + \alpha_t $$

| 符号         | 含义                                 |
| ---------- | ---------------------------------- |
| $x_t$​     | 当前时刻 tt 的观测值                       |
| $x_{t−1}$​ | 一阶滞后值，即前一个时间步的观测值                  |
| $ϕ_1$​     | 该滞后项的系数，表示 xt−1xt−1​ 对 xtxt​ 的影响程度 |
| $α_t$​     | 白噪声误差项，代表纯随机波动，无法由历史数据预测           |
| $δ$        | 常数项（截距），与过程均值 μμ 及自回归系数有关          |
| $μ$        | 整个时间序列过程的均值（长期平均水平）                |
- **AR(2) 二阶自回归**：包含两个滞后项。$$ x_t = \delta + \phi_1 x_{t-1} + \phi_2 x_{t-2} + \alpha_t $$
- **AR(p)**：一般形式为: 
$$ x_t = \delta + \phi_1 x_{t-1} + \dots + \phi_p x_{t-p} + \alpha_t$$
- **预测下一步**：例如 AR(2) 预测 
$$ x_{t+1} = \delta + \phi_1 x_t + \phi_2 x_{t-1} + \alpha_{t+1} $$
### 4. 系数估算与阶数选择
- **估算方法**：常用最大似然估计（MLE）或最小二乘法（OLS），也可使用 Yule-Walker 或 Burg 方法。
- **模型选择标准**：可根据 Akaike 信息准则（AIC）或贝叶斯信息准则（BIC）选择模型。
- **阶数确定**：通过**自相关函数（ACF）图**，观察不同滞后下的自相关系数。显著峰值提示潜在时间结构，平稳序列自相关随滞后增加而衰减，否则可能存在非平稳因素。

### 5. 主要变体
- **向量自回归模型 (VAR)**：适用于多变量时间序列。每个变量是其自身过去值和其他变量过去值的线性函数。
- **ARMA / ARIMA**：用于处理具有强烈趋势的数据。ARIMA 结合了自回归和移动平均，并有 VARIMA、SARIMA（季节性）等扩展。
- **自回归条件异方差 (ARCH / GARCH)**：对时间序列中随时间变化的方差（波动率）进行建模和预测，常用于金融领域的波动率预测。

### 6. 其他领域应用
- **深度自回归模型（如 GPT）**：用神经网络，把“过去所有 token”压缩成一个上下文，然后输出下一个 token 的概率。
- **空间数据**：将位置视为序列，用其他相关位置的读数作为滞后值，对目标位置进行回归预测（如利用周边监测站数据和距离因素预测空气质量）。
