# 一、核心概念

- **向量嵌入**：将任意数据（文字、图像、音频等）转换为机器学习模型可处理的数字数组
	- 让非数学数据在数学运算中保留其原始语义，使得 相似的数据 → 相近的向量
	- 不同模态的数据可以映射到同一个嵌入空间，实现跨模态理解（如文搜图)

# 二、张量
机器学习中用“张量”统称多维数组，嵌入通常是其中的**向量**。

| 类型 | 阶数 | 示例 | 说明 |
|------|------|------|------|
| 标量 | 0 阶 | `33` | 单个数值，如温度 |
| 向量 | 1 阶 | `[25, 30, 33]` | 一维数组，同类型数据 |
| 元组 | 1 阶 | `("Jane", 31, 65)` | 可含不同类型，不常用作嵌入 |
| 矩阵 | 2 阶 | `3×30` 表格 | 二维数组，如整月天气记录 |
| N 维张量 | ≥3 阶 | 彩色图像 `(高×宽×3)` | 计算机视觉常用 |

> **向量 vs 嵌入**：嵌入是“捕捉特征的数字表示”，理论上不一定是向量；但在现代 ML 中，嵌入几乎都是向量，向量也通常作为嵌入使用，两词常可互换。

# 三、向量嵌入的工作原理

### 3.1 数据如何表示为向量
- 每个维度对应数据的一个特征（如像素灰度、词义维度）。
- 高维数据往往包含噪声，需要降维以提取关键信息、加速计算并防止过拟合。
- 常用降维方法：[[自编码器]]、卷积、[[PCA|PCA]]、t-SNE 等。
- 在深度学习中，特征通常不是人工设计的，而是由模型在训练中隐式习得。

### 3.2 如何比较嵌入相似度
嵌入的意义在于：相似的数据点，其向量在空间中距离更近。常用度量如下：

| 度量    | 公式/描述                                                            | 特点                 | 取值范围                    |
| ----- | ---------------------------------------------------------------- | ------------------ | ----------------------- |
| 欧氏距离  | $\sqrt{\sum (a_i - b_i)^2}$                                      | 对向量大小敏感，适合量化       | [0, ∞) ，0 相同            |
| 余弦相似度 | $\frac{\mathbf{A}\cdot\mathbf{B}}{\|\mathbf{A}\|\|\mathbf{B}\|}$ | 归一化夹角，忽略向量长度 (NLP) | [-1, 1]，1 相同，0 正交，-1 相反 |
| 点积    | $\sum a_i b_i$                                                   | 非归一化，综合反映方向和大小     | (-∞, ∞)                 |

### 3.3 嵌入模型从哪来
- **预训练模型**：在大规模通用数据上训练好，可直接使用。
  - 文本：Word2Vec、GloVe、BERT、SBERT 等。
  - 图像：ImageNet 预训练 CNN（去掉分类层）、CLIP。
- **微调/自定义模型**：针对专业领域（法、医）补充训练，使嵌入更贴合专有词汇和场景。
- **端到端学习**：嵌入层作为整个神经网络的一部分共同训练（如 CNN 编码器）。

# 四、图像嵌入
### 4.1 图像数字化
- 灰度图：2D 矩阵，像素值 0~1。
- RGB 图：3D 张量 `(高 × 宽 × 3)`，每个通道 0~255。
- 可展平为向量（如 `28×28` 图 → 784 维向量）。

### 4.2 特征提取（CNN）
卷积核（可学习参数）滑过图像 → 生成特征图 → 池化降维 → 展平为向量嵌入。

### 4.3 典型应用
- **图像搜索**：比较查询图与库图的嵌入相似度。
- **多模态搜索（文搜图）**：用 CLIP 联合训练图文编码器，使文本嵌入和图像嵌入在共享空间中对齐。
- **图像生成**：
  - VAE：编码为均值/方差向量 → 采样 → 解码生成变体。
  - 扩散模型（DALL·E、Stable Diffusion）：用 CLIP 将文本提示转为嵌入，引导反向扩散过程生成图像。

# 五、文本嵌入（NLP）

文字没有像像素那样天然的数值表示，需捕捉语义、上下文、词序等抽象特征。
NLP 的嵌入模型需要在海量训练数据上进行[[SSL]], 以充分捕捉语言的潜在含义

### 文本嵌入模型

- **掩码语言模型**（BERT）：随机遮挡部分词，让模型根据上下文预测，逼迫嵌入学习深层语义。
- **预测上下文**（Word2Vec）：用中心词预测周围词，或反之，习得词共现关系。

	- Word2Vec / GloVe：经典词嵌入，能表达语义运算（如 king - man + woman ≈ queen）。
	- BERT：双向 Transformer 编码器，适用词/句级任务。
	- SBERT / 句子转换器：针对句子嵌入优化，可直接生成相似度高的句向量。
	- DistilBERT：轻量化 BERT，速度提升 60%，保留 95% 以上性能。
	- RoBERTa：优化训练策略的 BERT 变体，性能更强。

### 文本嵌入类型
- **词嵌入**：捕捉单词语义和上下文关系，可进行类比推理。
- **句子嵌入**：表示整句含义，用于搜索、情感分析、机器翻译。
- **文档嵌入**：对整个文档建模，用于分类、索引、检索。

### 其他数据类型嵌入
- **音频嵌入**：基于波形/频谱图，常使用 CNN、RNN 或 Transformer，用于语音识别、音乐检索。
- **产品嵌入**：用于电商推荐系统，通常由无监督学习生成。
- **图嵌入**：表示节点与边的关系，应用于社交网络、生物网络分析。

# 六、向量数据库与检索应用

向量数据库: 专为高维向量优化的存储检索系统，支持高效的[[KNN|最近邻]]搜索。

- **语义搜索**：
	理解查询意图，而非简单关键字匹配（“水果”能返回“苹果”）。
- **检索增强生成 [[RAG]]**：
	检索：将用户问题转为向量，从外部知识库中搜索最相关的文档片段。
	生成：将检索到的信息作为上下文，提供给大语言模型生成更准确、更新的回答。
