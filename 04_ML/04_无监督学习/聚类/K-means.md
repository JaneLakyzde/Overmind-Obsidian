## 一、 什么是 K-均值聚类？

K-均值聚类（K-Means Clustering） 是一种基于质心的[[无监督学习]]算法。

- 无监督学习：意味着训练数据是未标记的，算法需要自己去寻找数据内部的潜在结构。
    
- 排他性/硬聚类：K-Means 属于“硬聚类”方法，即一个数据点只能完全属于一个簇，不能脚踩两只船。
	
- 簇 `Cluster`：由相似的数据点聚集而成的组。
- 质心 `Centroid`：簇的中心点。通常是该簇内所有数据点坐标的平均值（均值）。
    

---

## 二、 K-Means 是如何工作的？

K-Means 的本质是一个**迭代优化**的过程，其目标是让同一个簇内的数据点离质心最近。它主要包含以下四个步骤：


### 1. 初始化 K 值与质心

首先，我们需要手动指定要分成的聚类数量 $K$。然后，算法会在数据空间中随机选择 $K$ 个点作为初始质心。

### 2. 距离分配（E 步 - 期望步骤）

计算每个数据点到这 $K$ 个质心的距离（通常使用[[欧几里得距离]]），并将每个数据点分配给距离它最近的那个质心所在的簇。

### 3. 移动质心（M 步 - 最大化步骤）

当所有数据点分配完毕后，重新计算每个簇内所有点的平均值，将该平均值作为新的簇中心（更新质心位置）。

### 4. 判定收敛

重复步骤 2 和 3，直到满足以下任一条件：

- 质心的位置不再发生明显变化（已达到收敛点）。
- 达到了预设的最大迭代次数。

## 三、 如何评估和优化聚类效果？

好的聚类应该满足：同一个簇里的点越近越好，不同簇之间越远越好。

### 1. 评估指标

- ==惯性==：
	也叫误差平方和 sse `Sum of Squared Errors`
	衡量簇内紧密度的指标。它是每个点到其所属质心距离的平方和。
	SSE 越小，说明簇内数据越紧凑，聚类效果越好。
    
- ==Dunn 指数==：衡量簇间疏离度的指标。代表“最小簇间距离”与“最大簇内距离”的比值。Dunn 指数越高，说明各簇之间区分度越高。
    

### 2. 性能优化技巧

由于初始质心是随机选取的，K-Means 容易陷入局部最优。为了解决这个问题，通常使用以下优化方法：

- **K-Means++ 算法（优化质心初始化）**：
    
    不再完全随机选点。先随机选第一个质心，然后让后续的质心**倾向于选择彼此距离较远的数据点**。这极大地提高了算法的稳定性和收敛速度（Python 的 `scikit-learn` 库默认开启此优化）。
    
- **肘部法 (Elbow Method)（寻找最佳 K 值）**：
    
    不知道该分几类时，可以尝试不同的 $K$ 值，并绘制“$K$ 值 - 误差平方和(SSE)”的折线图。随着 $K$ 的增加，SSE 会下降。当曲线下降速度突然变缓、形成一个像**手肘**一样的拐点时，该拐点对应的 $K$ 通常就是最佳的集群数量。
    
- **轮廓分析 (Silhouette Analysis)**：
    
    另一种评估聚类质量、帮助确定最佳 $K$ 值的常用方法。

## 四、 优缺点剖析

| **优点 (Advantages)**                      | **缺点 (Disadvantages)**                           |
| ---------------------------------------- | ------------------------------------------------ |
| **简单易懂**：逻辑清晰，非常适合作为入门聚类算法。              | **需要预设 K 值**：算法无法自动学习出应该分多少类，必须人工指定。             |
| **计算速度快**：相比于复杂的层次聚类，K-Means 计算简单，运行效率高。 | **对初始值敏感**：不同的初始质心可能会导致完全不同的聚类结果。                |
| **可扩展性强**：能够非常轻松地应对和处理大规模的数据集。           | **对异常值敏感**：由于是计算均值，极端的离群点/异常值会严重拉偏质心的位置。         |
|                                          | **无法处理复杂形状**：适合圆形或球形分布的数据，对不规则、环形或密度差异极大的数据效果较差。 |

## 五、Python 实战代码速查 (Scikit-Learn)

作为新手，在 Python 中使用 `scikit-learn` 极其简单，核心代码如下：

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 1. 特征缩放（K-Means 基于距离，强烈建议先做标准化）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 2. 定义模型（设置聚类数为 3，默认使用 k-means++ 初始化）
kmeans = KMeans(n_clusters=3, init='k-means++', random_state=42)

# 3. 训练模型并预测
labels = kmeans.fit_predict(X_scaled)

# 4. 获取质心位置与惯性(SSE)
centroids = kmeans.cluster_centers_
inertia = kmeans.inertia_
```
