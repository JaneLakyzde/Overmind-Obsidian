# 1. 为什么需要位置编码？

词序对语义至关重要。比如：

- “Allen 遛狗”  
- “狗遛 Allen”

两句话词完全相同，但意思完全相反。  
RNN / LSTM 按顺序读入词元，天然携带位置信息；而 **Transformer** 并行处理整个序列，自注意力机制本身 不感知词的先后顺序。  
因此我们需要一种显式的位置编码，把“第几个词”的信息注入到输入中，让模型同时知道 “词是什么”和“词在哪里”。

# 2. 正弦位置编码（Sinusoidal Positional Encoding）

Vaswani 等人在《Attention is All You Need》中提出：用 **正弦（sin）和余弦（cos）函数** 为每个位置生成一个固定且唯一的向量，然后直接加到词嵌入上。

### 2.1 为什么用正弦 / 余弦？

正弦波有几个很好的性质：

- **周期性**：适合表示重复模式；  
- **平滑连续**：输入微小变化 → 输出微小变化，可在可微分空间里表示位置；  
- **多尺度**：对不同维度使用不同频率，能刻画不同粒度的位置关系。

### 2.2 公式

对位置 $pos$（第一个词为 0）和维度索引 $i$：

$$
\begin{aligned}
PE_{(pos,\, 2i)}   &= \sin\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right) \\
PE_{(pos,\, 2i+1)} &= \cos\left(\frac{pos}{10000^{2i / d_{\text{model}}}}\right)
\end{aligned}
$$

- $pos$：词在序列中的位置（0, 1, 2, …）  
- $i$：维度的“对”索引（每一对包含一个 sin 和一个 cos）  
- $d_{\text{model}}$：词嵌入的总维度（例如 512）  
- 10000 是论文中设定常数（可调），控制频率变化的范围。

**直观理解**：  
- 偶数维度用 **sin**，奇数维度用 **cos**；  
- 同一个位置的 sin 和 cos 构成一对，共同编码该位置的信息；  
- 不同维度的波长不同，低维变化快（高频），高维变化慢（低频），组合起来就像给每个位置画了一条独特的“波指纹”。

# 3. Python 实现与简单示例

下面实现一个生成位置编码矩阵的函数，并在短句子上演示。

```python
import numpy as np

def get_position_encoding(seq_len, d_model, n=10000):
    P = np.zeros((seq_len, d_model))
    for pos in range(seq_len):
        for i in range(d_model // 2):
            denominator = np.power(n, 2 * i / d_model)
            P[pos, 2*i]   = np.sin(pos / denominator)   # 偶数维
            P[pos, 2*i+1] = np.cos(pos / denominator)   # 奇数维
    return P
```

用句子 “Allen walks dog” 演示（3 个词，为方便观察只取 `d_model=4`）：

```python
P = get_position_encoding(seq_len=3, d_model=4, n=10000)
print(P)
```

输出（已四舍五入，精确值见注释）：

```
[[ 0.          1.          0.          1.        ]
 [ 0.84147098  0.54030231  0.00999983  0.99995   ]
 [ 0.90929743 -0.41614684  0.01999867  0.99980001]]
```

对照表格：

| 词       | 位置 pos | dim0 sin(…) | dim1 cos(…) | dim2 sin(…) | dim3 cos(…) |
|----------|----------|--------------|--------------|--------------|--------------|
| "Allen"  | 0        | 0.0000       | 1.0000       | 0.0000       | 1.0000       |
| "walks"  | 1        | 0.8415       | 0.5403       | 0.0100       | 0.99995      |
| "dog"    | 2        | 0.9093       | -0.4161      | 0.0200       | 0.99980      |

可以看到：每个词都获得了一组独一无二的数值，这些数值由位置和维度共同决定。  
模型会将这些位置编码向量 **直接加** 到对应的词嵌入上，得到带有位置信息的输入表示。

# 4. 可视化：更直观地感受位置编码

用更长的序列和更大的维度绘制热图，观察不同位置的“编码指纹”。

```python
import matplotlib.pyplot as plt

seq_len, d_model = 100, 512
P = get_position_encoding(seq_len, d_model)

plt.figure(figsize=(10, 6))
plt.matshow(P, cmap='viridis', aspect='auto')
plt.title("Sinusoidal Positional Encoding Heatmap")
plt.xlabel("Embedding Dimension")
plt.ylabel("Token Position")
plt.colorbar()
plt.tight_layout()
plt.show()
```

热图中：  
- 横轴是嵌入维度，纵轴是词位置；  
- 颜色深浅反映正/负值的变化；  
- 低维度处颜色变化快（高频），高维度处变化慢（低频），整体形成一种结构化模式，让模型能够区分绝对位置与相对位置。

# 5. 小结

- **为什么用**：Transformer 并行处理，需要显式注入位置信息。  
- **怎么做**：对每个位置的每个维度，用不同频率的 sin / cos 生成固定编码，加到词嵌入上。  
- **优点**：  
  - 完全确定、不增加可训练参数；  
  - 支持任意长度序列的外推；  
  - 能让模型学到相对位置关系（因为波形的平移性质）。  
- **位置编码在训练中保持静态**，不影响并行计算效率。
