# 1. 图是什么？

想象一个**社交网络**：你有朋友，朋友又有朋友，你们之间的连线没有固定的长度和方向，有的朋友只单向关注（比如微博），有的互相关注（微信好友）。这就是图。

- **节点**：图中的一个个实体，比如“你”“我”“张三”。  
- **边**：节点之间的关系，比如“是朋友”“关注”“转发”。  
- **有向图**：关系有方向，比如“欠我钱”——A欠B，不代表B欠A。  
- **无向图**：关系对称，比如“是同学”——你是我同学，我也是你同学。

数学上，图 G = (节点集合 Vertices，边集合 Edge)。为了存储和计算，我们常用邻接矩阵，就像一张表格：行和列都是节点，如果节点 i 和节点 j 之间有边，就在 (i, j) 位置写个 1（或权重）。
![[5f5efa01697803d689cc77fb11432e0c.jpg]]
排列不变性 (Permutation Invariance);
	函数 $f$ 是排列不变的，当且仅当对节点集合施加任意排列（permutation）后，函数的输出完全不变。
排列等变性 (Permutation Equivariance)
	函数 $f$ 是排列等变的，当且仅当输入的节点顺序重排时，输出的节点顺序会以完全相同的方式重排，但每个节点对应的特征值不变。

# 2. 图神经网络

[[CNN]] 擅长处理像素网格——每个像素只和周围几个像素相连，结构规整。  
[[RNN]] 擅长处理序列——每个元素只和前一个、后一个有联系。  
但现实世界中，很多东西是**图**：分子结构里原子之间连接数不定，社交网络里朋友数量千差万别，知识图谱里实体关系错综复杂。传统网络在这些数据面前就像用直尺量卷尺——使不上劲。

GNN 就是为了处理这种不规则连接而生的。它能让模型理解“谁是邻居”，并据此更新每个节点的理解。

# 3. 消息传递

GNN 的设计哲学是图进图出：输入一张图，不断更新图中每个节点的嵌入（就是表示该节点的数字向量），但不改变图的连接结构。最终，这些更新后的嵌入可以用于各种任务。

现代 GNN 的核心思想是**邻域聚合**：每个节点通过聚合邻居信息迭代更新自身表示。Gilmer 等人(2017)将其形式化为**消息传递 (Message Passing)** 框架：

在第 $k$ 层，对于每个节点 $v$：

1. **消息计算**：每个邻居 $(u \in \mathcal{N}(v))$ 生成消息 
 $$\mathbf{m}_{u \to v}^{(k)} = M^{(k)}\bigl( \mathbf{h}_v^{(k-1)}, \mathbf{h}_u^{(k-1)}, \mathbf{e}_{uv} \bigr)$$
    
2. **消息聚合**：节点 $v$ 汇总所有邻居消息（通常用求和、均值或最大化） 
$$\mathbf{m}_v^{(k)} = \text{AGG}^{(k)}\bigl( { \mathbf{m}_{u \to v}^{(k)} : u \in \mathcal{N}(v) } \bigr)$$
    
3. **节点更新**：结合自身表示与聚合消息得到新表示 
$$\mathbf{h}_v^{(k)} = U^{(k)}\bigl( \mathbf{h}_v^{(k-1)}, \mathbf{m}_v^{(k)} \bigr)$$
    

其中 $(M, \text{AGG}, U)$ 均为可学习函数（通常为线性变换加激活）。经过 $K$ 层后，每个节点能感知 $K$ 跳邻域的上下文。

# 4. 图分析类型

GNN 能干的活，按目标层级可以分成三类：

- **图级任务**：问整张图的性质。  
  比如，给定一个分子的图（原子为节点，键为边），预测它能不能治病。或者看一个社交网络图，判断它是不是一个“大学班级”图。这相当于给整张图进行分类

- **节点级任务**：问每个节点的特征。  
  比如在社交网络中，根据一个人的朋友都爱打高尔夫，预测这个人是否也爱打高尔夫。或者论文引用网络中，预测某篇论文属于哪个学科。

- **边级任务**（链接预测）：问两个节点之间会不会有关系。  
  比如推荐系统里“猜你还认识谁”，就是预测两个用户之间是否应该有一条“好友”边。场景理解中，识别出图片里的物体后，预测物体之间的关系（人-骑-自行车）。

这三类任务覆盖了绝大部分图数据的应用。

# 5. 变体和扩展


#### 1. 图卷积网络 (GCN) 

Kipf & Welling (2017) 提出最经典的谱域一阶近似模型。消息聚合形式极简： 
$$\mathbf{h}_v^{(k)} = \sigma \left( W^{(k)} \sum_{u \in \mathcal{N}(v) \cup {v}} \frac{\mathbf{h}_u^{(k-1)}}{\sqrt{\hat{d}_v \hat{d}_u}} \right) $$

- 特点：固定对称归一化，共享权重 (W)，无需边特征。
    
- 优势：简单、可叠加多层，适合转导(transductive)节点分类。
    
- 局限：必须使用全图邻接矩阵，难以扩展到大规模图；邻居权重固定，无法自适应。
    

#### 2. GraphSAGE

Hamilton 等人(2017) 针对大规模图提出**采样+归纳**学习：

- **邻居采样**：每节点随机采样固定数量的邻居，解耦计算图与原图大小。
    
- 聚合器可选择：均值池化、LSTM、最大池化等。
    
- 泛化能力：模型学的是“聚合函数”，可应用于从未见过的新节点/新图。
    

#### 3. 图注意力网络 (GAT) 

Veličković 等人(2018) 将注意力机制引入邻居聚合： $$ \alpha_{uv} = \frac{\exp(\text{LeakyReLU}(\mathbf{a}^T [W\mathbf{h}_u \parallel W\mathbf{h}_v]))}{\sum_{w \in \mathcal{N}(v)} \exp(\text{LeakyReLU}(\mathbf{a}^T [W\mathbf{h}_v \parallel W\mathbf{h}_w]))} ] [ \mathbf{h}_v' = \sigma \left( \sum_{u \in \mathcal{N}(v)} \alpha_{uv} W \mathbf{h}_u \right) $$

- 邻居权重由节点特征计算得出，不同邻居重要性不同。
    
- 支持多头注意力增强稳定性。
    

#### 4. 图同构网络 (GIN) 

Xu 等人(2019) 证明GNN的表达能力上限由**Weisfeiler-Lehman (WL) 图同构测试**界定。通过设计内射(injective)聚合和更新函数，GIN能达到WL测试的能力： $$\mathbf{h}_v^{(k)} = \text{MLP}^{(k)} \left( (1+\epsilon^{(k)}) \mathbf{h}_v^{(k-1)} + \sum_{u \in \mathcal{N}(v)} \mathbf{h}_u^{(k-1)} \right) $$引入可学习参数 $\epsilon$，并使用多层感知机 (MLP) 代替线性变换，理论上最强。

# 6. GNN 的挑战

|挑战|描述|典型解法|
|---|---|---|
|**过平滑**|层数加深后所有节点表示趋于一致，失去区分度|残差连接、DropEdge、归一化技巧、限制层数|
|**可扩展性**|全批次计算需要整个图的邻接矩阵，内存爆炸|邻域采样 (GraphSAGE)、聚类 (Cluster-GCN)、子图训练|
|**异质图**|多种节点/边类型，关系语义不同|R-GCN, HGT (异质Transformer)|
|**动态图**|图结构和特征随时间变化|结合RNN/时序机制, TGN, DySAT|
|**深层次语义**|部分信息需要长程传播，普通GNN难以捕捉|图Transformer、混合架构、利用原图几何信息|
