# 1. 定义

伽马函数（Gamma Function）是阶乘在实数与复数域上的延拓，其标准定义为：
$$\Gamma(x) = \int_{0}^{+\infty} t^{x-1} e^{-t} \, dt \quad (x > 0)$$
# 2. 初值与递推

1. $\Gamma(1) = \int_{0}^{+\infty} e^{-t} \, dt = 1$ 
2. $\Gamma\left(\frac{1}{2}\right) = \sqrt{\pi}$ (通过 二重积分 + 极坐标 换元得证)
3. $\Gamma(x+1) = x \cdot \Gamma(x)$ (通过分部积分得证)
# 3. 解题方法

- 通过简单的换元, 将陌生的积分转化为伽马函数的定义, 再利用初值和递推直接秒杀

# 4. 高斯积分
- 高斯积分本质上就是伽马函数在 x = 1/2 时的特例
	可用于证明正态分布的概率密度归一化条件
	高斯积分通常是整个数轴上的; 柏松积分特指正半轴上的
