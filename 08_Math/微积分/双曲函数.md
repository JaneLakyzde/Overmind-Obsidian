## 一、核心内容：双曲正弦与双曲余弦（考研重点）

### 1. 定义
$$\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}$$

### 2. 基本性质
- **奇偶性**：$\sinh x$ 是奇函数，$\cosh x$ 是偶函数。
- **值域**：$\sinh x \in \mathbb{R}$；$\cosh x \in [1, +\infty)$，最小值为 $\cosh 0 = 1$。
- **平方恒等式**（最重要）：  
  $$\cosh^2 x - \sinh^2 x = 1$$

### 3. 导数与积分
- 导数公式（与三角函数对比仅差符号）：
  $$(\sinh x)' = \cosh x, \quad (\cosh x)' = \sinh x$$
- 不定积分：
  $$\int \sinh x \,dx = \cosh x + C, \quad \int \cosh x \,dx = \sinh x + C$$

### 4. 反双曲正弦与反双曲余弦
这也是考试中容易出现的“看起来复杂”的对数形式。

- **反双曲正弦**：
  $$\operatorname{arsinh} x = \ln\!\bigl(x + \sqrt{x^2+1}\bigr), \quad x \in \mathbb{R}$$
  导数：$(\operatorname{arsinh} x)' = \dfrac{1}{\sqrt{x^2+1}}$

- **反双曲余弦**（主值，通常取 $y \ge 0$）：
  $$\operatorname{arcosh} x = \ln\!\bigl(x + \sqrt{x^2-1}\bigr), \quad x \ge 1$$
  导数：$(\operatorname{arcosh} x)' = \dfrac{1}{\sqrt{x^2-1}} \quad (x > 1)$

### 5. 常见应用
- **悬链线**：$y = a\cosh\!\bigl(\dfrac{x}{a}\bigr)$
- **积分工具**：遇到 $\sqrt{x^2 + a^2}$ 时常可借助双曲代换，或直接写出：
  $$\int \frac{dx}{\sqrt{x^2+a^2}} = \operatorname{arsinh}\!\bigl(\frac{x}{a}\bigr) + C = \ln\bigl(x+\sqrt{x^2+a^2}\bigr)+C$$
- **微分方程**：$y'' - a^2 y = 0$ 的通解可写成 $y = C_1 \sinh(ax) + C_2 \cosh(ax)$，这与 $y = C_1 e^{ax} + C_2 e^{-ax}$ 等价。

## 二、补充：其他双曲函数

以下四个函数均由 $\sinh x$ 与 $\cosh x$ 派生，考研中一般不做重点要求，但了解其结构与导数有助于迁移。

### 1. 定义与导数
| 函数 | 定义 | 导数 |
|------|------|------|
| $\tanh x$ | $\dfrac{\sinh x}{\cosh x} = \dfrac{e^x - e^{-x}}{e^x + e^{-x}}$ | $\operatorname{sech}^2 x$ |
| $\coth x$ | $\dfrac{\cosh x}{\sinh x} = \dfrac{e^x + e^{-x}}{e^x - e^{-x}}\ (x \neq 0)$ | $-\operatorname{csch}^2 x$ |
| $\operatorname{sech} x$ | $\dfrac{1}{\cosh x}$ | $-\operatorname{sech} x \tanh x$ |
| $\operatorname{csch} x$ | $\dfrac{1}{\sinh x}\ (x \neq 0)$ | $-\operatorname{csch} x \coth x$ |

### 2. 补充恒等式（与三角函数对照记忆）
- $1 - \tanh^2 x = \operatorname{sech}^2 x$
- $\coth^2 x - 1 = \operatorname{csch}^2 x$

### 3. 反函数（对数形式）
- $\operatorname{artanh} x = \dfrac{1}{2}\ln\dfrac{1+x}{1-x}, \quad |x|<1$
- $\operatorname{arcoth} x = \dfrac{1}{2}\ln\dfrac{x+1}{x-1}, \quad |x|>1$
- $\operatorname{arsech} x = \ln\!\bigl(\dfrac{1+\sqrt{1-x^2}}{x}\bigr), \quad 0<x\le 1$
- $\operatorname{arcsch} x = \ln\!\bigl(\dfrac{1+\sqrt{1+x^2}}{|x|}\bigr), \quad x \neq 0$

### 4. 记忆技巧：Osborn 法则
把三角函数恒等式中的**隐含 $\sin^2$ 的项改符号**，就能得到双曲版本。  
例如：  
- $\cos^2 x + \sin^2 x = 1 \;\rightarrow\; \cosh^2 x - \sinh^2 x = 1$  
- $\cos 2x = 1 - 2\sin^2 x \;\rightarrow\; \cosh 2x = 1 + 2\sinh^2 x$

---

**总结**：抓牢双曲正弦、余弦的定义、导数、平方恒等式以及反函数对数形式，就覆盖了考研双曲函数的核心考点，其余双曲函数作为同类结构稍加延伸即可。
