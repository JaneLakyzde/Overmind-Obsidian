# 1. 基本积分公式

| 类型                   | 首选积分结果                                   | 备用等价形式                                  |
| :------------------- | :--------------------------------------- | :-------------------------------------- |
| $1/\sqrt{a^2 - x^2}$ | **$\arcsin\frac{x}{a}$**                 | （无，直接用这个最快）                             |
| $1/\sqrt{x^2 + a^2}$ | **$\ln(x + \sqrt{x^2+a^2})$**            | 或 $\text{arsinh}\frac{x}{a}$            |
| $1/\sqrt{x^2 - a^2}$ | **$\ln\|x + \sqrt{x^2-a^2}\|$**          | 或 $\text{arcosh}\frac{x}{a}$（取正半轴时）     |
| $1/a^2 + x^2$        | **$\frac{1}{a}\arctan\frac{x}{a}$**      |                                         |
| $1/a^2 - x^2$        | **$\frac{1}{2a}\ln\|\frac{a+x}{a-x}\|$** | 或 $\frac{1}{a}\text{artanh}\frac{x}{a}$ |

$$\int_{a}^{b} f(x) \, dx = \int_{a}^{b} f(a+b-x) \, dx$$
$$\int_{a}^{b} f(x) \, dx = \frac{1}{2} \int_{a}^{b} \big[ f(x) + f(a+b-x) \big] \, dx$$
形如 $xf(sinx)$ 求积分, 常用积分再现公式, 其中, 点火公式是积分再现公式的一个应用
