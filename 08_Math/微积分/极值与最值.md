# 一元函数

## 驻点
- 导数为零的点 $f'(x_0) = 0$
	不一定产生极值
## 极值
- 导数为零/不可导 + 两侧一阶导变号
	必要条件: [[费马引理]]
	[[一元微分应用|一阶导数穿根法/二阶导数判据]]
## 最值
- 闭区间上的端点 + 所有临界点 + 不可导点
## 拐点
- 二阶导数为零/不存在 + 两侧二阶导变号
## 不可导点
- 左导数 != 右导数
- 导数无穷大
	是极值点和拐点的候选人

# 多元函数的极值与最值

- 多元函数极值要求在点的邻域内有定义, 因此边界点不能算是无条件极值/最值点
- 对可微函数求无条件极值, 通常求其偏导数为零的驻点进行**筛选**, 并通过二阶偏导**判断**
	对不可微函数求无条件极值, 通常通过定义法进行直接判断
- 对可微函数求条件极值, 通常使用拉格朗日数乘法构造方程, 求偏导为零方程

## 无条件极值

- **驻点** ：对于可微函数 $z = f(x, y)$，若 $P_0(x_0, y_0)$ 为极值点
	则 $f_x(x_0, y_0) = 0$ 且 $f_y(x_0, y_0) = 0$ 
	反之不成立（驻点是鞍点）
	
- **不可偏导点** ：偏导数不存在但函数连续的点
	如圆锥体 $z = \sqrt{x^2 + y^2}$ 在 $(0,0)$ 处
	需单独拎出，用极值定义法判定

- **极值判定（充分条件 - Hessian 判据）** ：
	首先, 先筛选出所有的驻点
	设 $A = f_{xx}(x_0, y_0)$，$B = f_{xy}(x_0, y_0)$，$C = f_{yy}(x_0, y_0)$，令 $\Delta = AC - B^2$
	若 $\Delta > 0$ 且 $A > 0$：**极小值**；
	若 $\Delta > 0$ 且 $A < 0$：**极大值**；
	若 $\Delta < 0$：**非极值, 为鞍点**；
	若 $\Delta = 0$：**此法失效**，需用定义法或高阶偏导判定
	[[黑塞矩阵]]正定/负定在二元函数情形的特殊结论

## 条件极值

- **一个约束条件** ：求 $z = f(x, y)$ 在 $\varphi(x, y) = 0$ 下的极值。
	构造拉格朗日函数 $L(x, y, \lambda) = f(x, y) + \lambda \varphi(x, y)$。求解方程组 $\begin{cases} L_x = f_x + \lambda \varphi_x = 0 \\ L_y = f_y + \lambda \varphi_y = 0 \\ L_\lambda = \varphi(x, y) = 0 \end{cases}$
	依次对各个参数求偏导, 所得点即为候选极值点
	(实际判定需结合物理意义或边界比较)
	
- **两个约束条件** ：求 $u = f(x, y, z)$ 在 $\varphi_1(x, y, z) = 0$ 和 $\varphi_2(x, y, z) = 0$ 下的极值。
	构造 $L = f + \lambda_1 \varphi_1 + \lambda_2 \varphi_2$，对 $x, y, z, \lambda_1, \lambda_2$ 分别求偏导并令为 $0$
	解方程组得到候选点。
	
- 移项/高斯消元法/构造连等式得到参数
- 设目标函数为 $z=f(x,y)$，约束条件为 $g(x,y)=0$ 
	在条件极值点 $(x0,y0)$ 处，有：$∇f(x0,y0)=λ∇g(x0,y0)$ 
	即条件极值点处, 等位线与约束相切, 说明有相同或相反的梯度/法向量
	
	
## 最值
- **有界闭区域 $D$ 上的最值求法** ：  
  第一步，求 $D$ 内部所有**驻点**及**不可偏导点**，计算函数值；  
  第二步，求 $D$ 边界上的最值（将边界方程代入消元转化为一元函数求最值，或使用拉格朗日乘数法沿边界求解）；  
  第三步，比较上述所有值，**最大者为最大值，最小者为最小值**。
- **开区域或无界区域** ：若区域非闭，需考察边界处或无穷远处的极限趋势。若开区域内存在**唯一极值点**，且根据实际背景该极值必存在，则唯一极小值即为最小值（反之亦然）。

## 边界最值转化
- **代入消元法** ：若边界为直线（如 $x = a$），直接代入 $f(a, y)$ 化为一元函数求最值；若边界为曲线（如 $x^2 + y^2 = 1$），令 $x = \cos t, y = \sin t$，代入 $f$ 化为一元函数 $F(t)$ 求最值。
- **拉格朗日法求边界** ：求 $f(x, y)$ 在边界曲线 $\psi(x, y) = 0$ 上的最值，本质就是**条件极值**问题，直接套用拉格朗日乘数法求解。

## 隐函数极值
- **定义** ：由方程 $F(x, y, z) = 0$ 确定隐函数 $z = f(x, y)$，求其极值。
- **必要条件的特殊形式** ：由隐函数求导公式 $z_x = -F_x / F_z$，$z_y = -F_y / F_z$。令 $z_x = 0, z_y = 0$，等价于令 $F_x = 0, F_y = 0$（需保证 $F_z \neq 0$），联立原方程 $F=0$ 解出驻点。
- **极值判定** ：在驻点处对隐函数求二阶偏导 $z_{xx}, z_{xy}, z_{yy}$（需对 $F_x, F_y$ 继续求偏导并代入 $z_x, z_y$），再使用无条件极值的 Hessian 判据（$AC - B^2$）进行判定。
