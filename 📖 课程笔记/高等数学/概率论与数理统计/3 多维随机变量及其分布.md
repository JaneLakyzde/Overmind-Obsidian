# 概率论学习笔记：二维随机变量 

> [!note] 费曼开篇
> 我们的世界充满了“成对”出现的随机性。比如：投资的“风险与回报”，学生的“身高与体重”，靶点的“横坐标与纵坐标”。
>
> 仅用一个数字描述是不够的。这份笔记将带我们进入“二维”世界。
>
> 我们的路径：
> 1.  **定义**：如何用数学语言描述 $(X, Y)$？ (Sec 1-3)
> 2.  **拆解**：如何从 $(X, Y)$ 中单独看 $X$ 或 $Y$？ (Sec 4)
> 3.  **关联**：当 $X$ 发生时，$Y$ 会怎样？ (Sec 5-6)
> 4.  **组合**：$(X, Y)$ 组合出的新变量（如 $Z=X+Y$）如何分布？ (Sec 7)

## 1. 二维随机变量及其分布函数

### 1.1 什么是二维随机变量？
* **费曼理解**：一个“实验”同时产生了**两个**我们关心的**数字**结果。这个“对” $(X, Y)$ 就是我们的研究对象。
* **数学定义**：设 $X=X(\omega)$ 和 $Y=Y(\omega)$ 是定义在**同一**样本空间 $S$ 上的两个随机变量。由它们组成的向量 $(X, Y)$ 就称为一个**二维随机变量**。（向量）

### 1.2 联合分布函数 $F(x, y)$
* **费曼理解**：这是描述 $(X, Y)$ 的“全息地图”。它回答了最基本的问题：“随机点 $(X, Y)$ 落在一个以 $(x, y)$ 为右上角的、无限大的‘左下’区域的概率是多少？”（几何意义）
* **数学定义**：
    * $$F(x, y) = P(X \le x, Y \le y)$$
* **几何意义**：$F(x, y)$ 是 $(X, Y)$ 落在 $(-\infty, x] \times (-\infty, y]$ 区域的概率。
* **核心性质 (必须理解)**： 
    1.  **规范性**：$0 \le F(x, y) \le 1$。且 $F(-\infty, y) = F(x, -\infty) = 0$, $F(+\infty, +\infty) = 1$。
    2.  **单调**：$F(x, y)$ 关于 $x$ 和 $y$ 均单调不减。
    3.  **右连续**：$F(x, y) = F(x+0, y) = F(x, y+0)$。
    4.  **(重要) 矩形区域概率**：对于 $x_1 < x_2, y_1 < y_2$：
        * $$P(x_1 < X \le x_2, y_1 < Y \le y_2) = F(x_2, y_2) - F(x_2, y_1) - F(x_1, y_2) + F(x_1, y_1)$$
        * *理解*：这是“容斥原理”。用大矩形减去两个小矩形，被减了两次的左下角要加回来。

## 2. 二维离散型RV及其分布

* **费曼理解**：$(X, Y)$ 的所有可能取值是**有限对**或**可列无限对**。比如掷两枚骰子 $(X, Y)$，只有 $6 \times 6 = 36$ 种可能。
* **核心工具：联合分布律 (PMF)**：
    * $P(X = x_i, Y = y_j) = p_{ij}, \quad (i, j = 1, 2, ...)$
* **性质**：
    1.  $p_{ij} \ge 0$ (非负性)
    2.  $\sum_{i=1}^\infty \sum_{j=1}^\infty p_{ij} = 1$ (规范性)
* **表格表示法 (最直观)**：
    * 这是描述离散型 $(X, Y)$ **最常用**的方法。
    * 先求取值，再求概率

| $Y$ \ $X$ | $x_1$ | $x_2$ | ... |
| :--- | :---: | :---: | :---: |
| $y_1$ | $p_{11}$ | $p_{21}$ | ... |
| $y_2$ | $p_{12}$ | $p_{22}$ | ... |
| ... | ... | ... | ... |

* **分布函数计算**：$F(x, y) = \sum_{x_i \le x} \sum_{y_j \le y} p_{ij}$ (把 $(x,y)$ 左下方的所有概率点加起来)

## 3. 二维连续型RV及其分布

* **费曼理解**：$(X, Y)$ 可以在一个平面区域内取**任意**点。我们不能再谈论“某一点”的概率（它总是0），只能谈论“某一小块区域”的概率。
* **核心工具：联合概率密度 (PDF)**：
    * 一个非负函数 $f(x, y)$。
    * *理解*：密度函数 $f(x, y)$ 本身**不是**概率！它是“概率的疏密程度”或“**概率之山**”。山越高的点，附近的概率越大。
* **定义关系**：存在对应密度函数与联合分布函数按照以下关系对应，则可称之为二维连续型R.V.
    * $$F(x, y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(u, v) \,dv \,du$$
* **性质**：
    1.  **非负性**：$f(x, y) \ge 0$ 
    2.  **规范性**：$\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \,dx \,dy = 1$ 
    3. 可逆性：$f(x, y) = \frac{\partial^2 F(x, y)}{\partial x \partial y}$
    4. **区域概率计算**：
    * $(X, Y)$ 落在区域 $D$ 的概率，就是 $f(x, y)$ 在 $D$ 上方的“曲顶柱体”的**体积**。
    * $$P((X, Y) \in D) = \iint_D f(x, y) \,dx \,dy$$
---

### 专题：二维均匀分布 (Uniform Distribution)

二维均匀分布是 [[3. 二维连续型RV及其分布]] 中最直观的例子。

* **费曼理解**：想象你有一块形状为 $D$ 的铁皮（总面积为 $A(D)$），质量为 1kg。如果你**均匀地**把这 1kg 质量铺在铁皮上，那么这块铁皮的“面密度”在 $D$ 内部处处相等，在 $D$ 外部为 0。这个“面密度”就是 $f(x, y)$。
* **记号**：$(X, Y) \sim U(D)$



### 几何概型（你的笔记核心）

> 你的笔记总结得非常到位：“落在子区域的概率等于子区域/总区域”。

这被称为**几何概型**。对于一个 $D$ 的子区域 $D_1$（即 $D_1 \subseteq D$），我们来计算 $P((X, Y) \in D_1)$：

$$
P((X, Y) \in D_1) = \iint_{D_1} f(x, y) \,dx \,dy
$$

因为在 $D_1$ 上，$f(x, y)$ 恒等于 $\frac{1}{A(D)}$：

$$
P((X, Y) \in D_1) = \iint_{D_1} \frac{1}{A(D)} \,dx \,dy = \frac{1}{A(D)} \iint_{D_1} 1 \,dx \,dy
$$

而 $\iint_{D_1} 1 \,dx \,dy$ 正是 $D_1$ 的面积 $A(D_1)$，所以：

$$
P((X, Y) \in D_1) = \frac{A(D_1)}{A(D)}
$$

### 专题：二维正态分布 (Bivariate Normal Distribution)

二维正态分布是概率论中**最重要**的二维连续分布。

* **记号**：$(X, Y) \sim N(\mu_X, \mu_Y, \sigma_X^2, \sigma_Y^2, \rho)$
* **参数**：
    * $\mu_X, \mu_Y$：两个变量的均值（山的峰顶位置）
    * $\sigma_X^2, \sigma_Y^2$：两个变量的方差（沿 $x$ 和 $y$ 方向的“胖瘦”）
    * $\rho$ (rou)：**相关系数**（决定山的“朝向”）

#### 3.4.1 钟形图

它是一个三维的钟形曲面。
> * 山峰的**最高点**在 $(\mu_X, \mu_Y)$ 处。
> * $\sigma_X$ 和 $\sigma_Y$ 决定了山在 $x$ 和 $y$ 方向“延伸”的宽度。
> * $\rho$（rou）决定了这座山的**形状**。

#### 3.4.2 $\rho$  的核心作用：相关关系

$\rho$ 描述了 $X$ 和 $Y$ 之间的**线性相关程度**。

1.  **$\rho = 0$ (不相关)**
    * $f(x, y)$ 的“等高线”是**轴平行**的椭圆（如果 $\sigma_X = \sigma_Y$，则是圆形）。
    * 这座山是“正”的，没有歪斜。
    * **重要特性**：对于正态分布，$\rho = 0$ **等价于** $X$ 和 $Y$ **相互独立**。
        * $f(x, y) = f_X(x) \cdot f_Y(y)$

2.  **$\rho > 0$ (正相关)**
    * $f(x, y)$ 的“等高线”是向**东北/西南**方向倾斜的椭圆。
    * 山脊倾向于沿着 $y=x$ 的方向（经过平移）。
    * **直观理解**：$X$ 取大值时，$Y$ 也倾向于取大值。概率密度向 $(+, +)$ 和 $(-, -)$ 象限（相对均值）集中。

3.  **$\rho < 0$ (负相关)**
    * $f(x, y)$ 的“等高线”是向**西北/东南**方向倾斜的椭圆。
    * 山脊倾向于沿着 $y=-x$ 的方向（经过平移）。
    * **直观理解**：$X$ 取大值时，$Y$ 倾向于取小值。概率密度向 $(+, -)$ 和 $(-, +)$ 象限集中。

4.  **$\rho = \pm 1$ (完全相关)**
    * 这是**退化**情况。
    * 整个“山”**坍缩**成了一条直线，$Y = aX + b$。
    * 此时不再是二维连续型 R.V.，因为所有概率都集中在一条线（面积为0）上。

#### 3.4.3 联合概率密度 (PDF) - (选看)

二维正态分布的 PDF 公式非常复杂，通常不需要背诵，但有助于理解：
$$
f(x, y) = \frac{1}{2\pi \sigma_X \sigma_Y \sqrt{1-\rho^2}} \exp\left( -\frac{1}{2(1-\rho^2)} \left[ \frac{(x-\mu_X)^2}{\sigma_X^2} - \frac{2\rho(x-\mu_X)(y-\mu_Y)}{\sigma_X \sigma_Y} + \frac{(y-\mu_Y)^2}{\sigma_Y^2} \right] \right)
$$
* 当 $\rho=0$ 时，这个式子可以分解为两个一维正态密度 $f_X(x) \cdot f_Y(y)$ 的乘积。

#### 3.4.4 重要性质

1.  **边缘分布**：
    * 如果 $(X, Y)$ 服从二维正态分布，那么它的两个边缘分布**必定**是一维正态分布。
    * $X \sim N(\mu_X, \sigma_X^2)$
    * $Y \sim N(\mu_Y, \sigma_Y^2)$
    * （反之不成立：$X$ 和 $Y$ 都是正态分布，$(X, Y)$ **不一定**是二维正态分布）
2.  **独立性 $\Leftrightarrow$ 不相关**：
    * **一般 R.V.**：独立 $\implies$ 不相关（$\rho=0$），但不相关 $\not\implies$ 独立。
    * **二维正态 R.V.**：独立 $\iff$ 不相关（$\rho=0$）。

## 4. 边缘分布 (重点)

> [!note] 费曼重点：从“联合”到“单独”
> 这是二维变量中**最核心**的操作之一。
>
> **问题**：我们有了 $(X, Y)$ 的“全息地图”（联合分布），但我现在**只**关心 $X$（比如，我拿到了全班的“身高-体重”数据表，我现在只想知道“身高”这一个变量的分布）。
>
> **策略**：**“降维打击”**。把我们不关心的那个维度 $Y$ 给“**压扁**”或“**消除**”。
>
> * 对于离散型：消除 $Y$ = 把 $Y$ 的所有可能取值**求和**。
> * 对于连续型：消除 $Y$ = 把 $Y$ 的所有可能取值**积分**。
>
> 这“压扁”后得到的新分布，就叫“**边缘 (Marginal)**”分布。

### 4.1 边缘分布函数 (一般定义)
* $X$ 的边缘分布函数：
    * $F_X(x) = P(X \le x) = P(X \le x, Y < +\infty) = F(x, +\infty)$
* $Y$ 的边缘分布函数：
    * $F_Y(y) = P(Y \le y) = P(X < +\infty, Y \le y) = F(+\infty, y)$

### 4.2 离散型：边缘分布律
* **费曼理解**：看联合分布表。想知道 $P(X = x_i)$？就把 $X=x_i$ **这一列**的所有概率（不管 $Y$ 是谁）**加起来**。
* **公式**：
    * $X$ 的边缘分布律 ($p_{i \cdot}$)：
        * $p_{i \cdot} = P(X = x_i) = \sum_{j=1}^\infty p_{ij}$  (按**行**求和，得到**列**变量 $X$ 的分布)
    * $Y$ 的边缘分布律 ($p_{\cdot j}$)：
        * $p_{\cdot j} = P(Y = y_j) = \sum_{i=1}^\infty p_{ij}$  (按**列**求和，得到**行**变量 $Y$ 的分布)
* **例题 (必会)**：
    * $(X, Y)$ 的联合分布律如下表：

| $Y$ \ $X$ | 0 (i=1) | 1 (i=2) | **$p_{\cdot j}$ (Y的边缘)** |
| :--- | :---: | :---: | :---: |
| 0 (j=1) | 0.1 | 0.3 | $0.1+0.3=$ **0.4** |
| 1 (j=2) | 0.4 | 0.2 | $0.4+0.2=$ **0.6** |
| **$p_{i \cdot}$ (X的边缘)** | $0.1+0.4=$ **0.5** | $0.3+0.2=$ **0.5** | **1.0** |

    * **$X$ 的边缘分布** (看底行)： $P(X=0) = 0.5, P(X=1) = 0.5$
    * **$Y$ 的边缘分布** (看右列)： $P(Y=0) = 0.4, P(Y=1) = 0.6$

### 4.3 连续型：边缘概率密度
* **费曼理解**：我们有 $f(x, y)$ 这个“概率之山”。想知道 $X$ 在 $x$ 处的边缘密度 $f_X(x)$？
* **策略**：在 $x$ 点，沿着 $y$ 轴方向把这座“山”**从 $y=-\infty$ 到 $y=+\infty$ 积起来**，把所有 $Y$ 的贡献“压”到 $x$ 这一点上。
* **公式**：
    * $X$ 的边缘密度：$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \,dy$
    * $Y$ 的边缘密度：$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \,dx$
* **例题 (必会)**：
    * 设 $(X, Y)$ 在 $D = \{(x, y) | 0 \le x \le 1, 0 \le y \le 1\}$ 上**均匀分布**。
    * *分析*：区域 $D$ 面积为 $1 \times 1 = 1$。均匀分布意味着 $f(x,y)$ 是个常数 $c$。
    * 根据规范性 $\iint_D c \,dxdy = c \cdot (\text{Area}) = c \cdot 1 = 1$，得 $c=1$。
    * $f(x, y) = \begin{cases} 1 & 0 \le x \le 1, 0 \le y \le 1 \\ 0 & \text{else} \end{cases}$
    * **求 $f_X(x)$**：
        * 当 $x \notin [0, 1]$ 时， $f(x, y)$ 恒为 0，所以 $f_X(x) = \int_{-\infty}^{+\infty} 0 \,dy = 0$。
        * 当 $x \in [0, 1]$ 时：
        * $f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \,dy = \int_0^1 1 \,dy = [y]_0^1 = 1$
        * **结论**：$f_X(x) = \begin{cases} 1 & 0 \le x \le 1 \\ 0 & \text{else} \end{cases}$。 ( $X \sim U[0, 1]$ )
        * 同理可得 $Y \sim U[0, 1]$。

## 5. 条件分布

> [!note] 费曼开篇：当“不确定”变为“已知”
> **问题**：边缘分布告诉我们 $X$ *总的* 分布。但如果**新信息**来了（比如，我们**已经知道** $X = x$ 了），$Y$ 的分布会发生什么变化？
>
> **策略**：**“降维打击”的另一种形式——“切片”与“归一化”**。
>
> 1.  **切片 (Slicing)**：在 $(X, Y)$ 的联合分布（表格或“山”）上，只看 $X=x$ 那一条“线”或那一个“截面”。
> 2.  **归一化 (Renormalizing)**：这个“切片”上的概率（或密度）加起来（或积分）不等于1。我们必须**除以这个切片自身的“总和”**（即 $P(X=x)$ 或 $f_X(x)$），使其成为一个总和为1的、合法的“新分布”。

### 5.1 离散型：条件分布律
* **定义**：在 $P(X = x_i) = p_{i \cdot} > 0$ 的条件下， $Y$ (给定 $X=x_i$) 的条件分布律为：
    * $$P(Y = y_j | X = x_i) = \frac{P(X = x_i, Y = y_j)}{P(X = x_i)} = \frac{p_{ij}}{p_{i \cdot}}$$
* **例题 (接4.2)**：
    * 求 $X=1$ 时，$Y$ 的条件分布。
    * *1. 切片*：看 $X=1$ 这一列：$p_{11}=0.3$ (Y=0), $p_{12}=0.2$ (Y=1)。
    * *2. 归一化*：这一列的总和是 $P(X=1) = p_{1 \cdot} = 0.5$。
    * **结果**：
        * $P(Y=0 | X=1) = \frac{p_{11}}{p_{1 \cdot}} = \frac{0.3}{0.5} = 0.6$
        * $P(Y=1 | X=1) = \frac{p_{12}}{p_{1 \cdot}} = \frac{0.2}{0.5} = 0.4$
    * (检查：$0.6+0.4=1$，这是一个新的、合法的分布。)

### 5.2 连续型：条件概率密度
* **定义**：在 $f_X(x) > 0$ 的条件下，$Y$ (给定 $X=x$) 的条件概率密度为：
    * $$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)}$$
* **费曼理解**： $f_{Y|X}(y|x) = \frac{\text{联合密度 (山的高度)}}{\text{边缘密度 (山的截面面积)}}$
* **重要推论（乘法公式）**：
    * $f(x, y) = f_X(x) \cdot f_{Y|X}(y|x)$
    * $f(x, y) = f_Y(y) \cdot f_{X|Y}(x|y)$

## 6. 二维RV的独立性

> [!note] 费曼开篇：什么叫“互不相干”？
> **独立 (Independence)** 是一个非常强的概念。
>
> * **直观**：知道 $X$ 的信息，对 $Y$ 的分布**毫！无！影！响！**
> * **技术**：$Y$ 的 **条件分布** 就等于 $Y$ 的 **边缘分布**。 ( $f_{Y|X}(y|x) = f_Y(y)$ )
> * **检查**：在 $X=1$ 的条件下 (例5.1)，$Y$ 的分布是 (0.6, 0.4)。而 $Y$ 的边缘分布是 (0.4, 0.6) (例4.2)。**两者不相等**！所以 $X, Y$ **不独立**。

* **基本定义**：
    * 如果 $F(x, y) = F_X(x) F_Y(y)$ 对**所有** $x, y$ 成立，则 $X, Y$ 相互独立。
* **等价刻画 (更常用)**：
    1.  **离散型**：
        * $p_{ij} = p_{i \cdot} \times p_{\cdot j}$  (对**所有** $i, j$ 成立)
        * *费曼理解*：**联合概率 = 边缘概率的乘积**。
        * *检查 (例4.2)*： $p_{11}=0.1$。 $p_{1 \cdot}=0.5$, $p_{\cdot 1}=0.4$。
        * $p_{1 \cdot} \times p_{\cdot 1} = 0.5 \times 0.4 = 0.2$。
        * $0.1 \neq 0.2$。**所以，不独立！**
    2.  **连续型**：
        * $f(x, y) = f_X(x) f_Y(y)$ (对**几乎所有** $x, y$ 成立)
        * *费曼理解*：**联合密度 = 边缘密度的乘积**。
        * *检查 (例4.3)*：$f(x,y)=1$。 $f_X(x)=1$, $f_Y(y)=1$ (在[0,1]上)。
        * $f_X(x) f_Y(y) = 1 \times 1 = 1 = f(x,y)$。
        * **所以，在该正方形上均匀分布的 $X, Y$ 是独立的！**
        
> [!warning] 警告
> $f(x, y) = f_X(x) f_Y(y)$ **不仅仅**要求函数表达式可以相乘，**还**要求 $(x, y)$ 的**定义域**是“可分离”的（通常是矩形）。
>
> * **例**：如果 $f(x, y) = 2$ 在 $D = \{(x, y) | 0 \le x \le 1, 0 \le y \le 1, x+y \le 1\}$ (一个三角形) 内，
> * 即使 $X$ 和 $Y$ 的边缘分布 $f_X(x)$ 和 $f_Y(y)$ 都能算出，
> * $X$ 和 $Y$ 也**绝不**独立！因为 $X$ 的取值**限制**了 $Y$ 的取值（$Y$ 必须 $\le 1-x$）。

## 7. 二维RV函数的分布 (重点)

> [!note] 费曼重点：从“原料”到“成品”
> **问题**：我们知道“原料” $(X, Y)$ 的联合分布，现在我们用一个“配方” $g(x, y)$ 把它们组合成一个“成品” $Z = g(X, Y)$。
>
> **目标**：求“成品” $Z$ 的分布 ( $F_Z(z)$ 或 $f_Z(z)$ )。
>
> **通用策略 (CDF法) - 永远的“避风港”**：
>
> 1.  **写出定义**： $F_Z(z) = P(Z \le z)$
> 2.  **替换 $Z$**： $F_Z(z) = P(g(X, Y) \le z)$
> 3.  **确定区域**： 找到 $xy$ 平面上的区域 $D_z = \{(x, y) | g(x, y) \le z\}$
> 4.  **积分**： $F_Z(z) = \iint_{D_z} f(x, y) \,dx \,dy$
> 5.  **求导**： $f_Z(z) = F_Z'(z)$

---
### 7.1 $Z = X + Y$ 的分布 (卷积)

这是最重要的函数。我们直接看**独立**情况下的“捷径”。

* **卷积公式 (Convolution)**：
    * 如果 $X$ 和 $Y$ 是**相互独立**的连续型随机变量，那么 $Z = X+Y$ 的密度 $f_Z(z)$ 等于 $X$ 和 $Y$ 密度的**卷积**：
    * $$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) \,dx \quad (\text{记为 } f_X * f_Y)$$
    * *理解*：为了得到和 $z$， $X$ 取 $x$ 的概率 $f_X(x)$ 与 $Y$ 取 $z-x$ 的概率 $f_Y(z-x)$ 相乘，再对所有可能的 $x$ “求和”（积分）。

* **例题 (独立 $U(0,1)$ 的和)**：
    * 设 $X \sim U(0, 1), Y \sim U(0, 1)$，且 $X, Y$ 独立。求 $Z = X+Y$ 的分布。
    * $f_X(x) = \begin{cases} 1 & 0 \le x \le 1 \\ 0 & \text{else} \end{cases}$, $f_Y(y) = \begin{cases} 1 & 0 \le y \le 1 \\ 0 & \text{else} \end{cases}$
    * **应用卷积**：
    * $f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) \,dx$
    * 被积函数 $f_X(x) f_Y(z-x)$ 要为 1，**必须同时**满足：
        1.  $0 \le x \le 1$
        2.  $0 \le z-x \le 1 \implies z-1 \le x \le z$
    * 积分 $x$ 的区间就是 $[0, 1] \cap [z-1, z]$。
    * **分情况讨论 $z$** (画数轴辅助)：
        1.  **$z < 0$**：区间 $[z-1, z]$ 在 0 的左侧。交集为空。$f_Z(z) = 0$。
        2.  **$0 \le z \le 1$**：交集是 $[0, z]$。
            * $f_Z(z) = \int_0^z 1 \cdot 1 \,dx = z$
        3.  **$1 < z \le 2$**：交集是 $[z-1, 1]$。
            * $f_Z(z) = \int_{z-1}^1 1 \cdot 1 \,dx = [x]_{z-1}^1 = 1 - (z-1) = 2-z$
        4.  **$z > 2$**：区间 $[z-1, z]$ 在 1 的右侧。交集为空。$f_Z(z) = 0$。
    * **结论 (三角分布)**：
        $f_Z(z) = \begin{cases} z & 0 \le z \le 1 \\ 2-z & 1 < z \le 2 \\ 0 & \text{else} \end{cases}$

### 7.2 $Z = \max(X, Y)$ 和 $Z = \min(X, Y)$ 的分布

这两个用 **CDF法** 解决最简单，特别是当 $X, Y$ 独立时。

* **$Z = \max(X, Y)$**
    * $F_Z(z) = P(Z \le z) = P(\max(X, Y) \le z)$
    * *关键转化*：最大值 $\le z$ **等价于** 所有人 $\le z$。
    * $F_Z(z) = P(X \le z, Y \le z)$
    * 如果 $X, Y$ **独立**：
        * $F_Z(z) = P(X \le z) P(Y \le z) = F_X(z) F_Y(z)$
    * $f_Z(z) = F_Z'(z) = f_X(z)F_Y(z) + F_X(z)f_Y(z)$ (求导法则)

* **$Z = \min(X, Y)$**
    * $F_Z(z) = P(Z \le z) = P(\min(X, Y) \le z)$
    * *关键转化 (反向)*：用 $1 - P(Z > z)$ 更简单。
    * $1 - P(\min(X, Y) > z)$
    * 最小值 $> z$ **等价于** 所有人 $> z$。
    * $F_Z(z) = 1 - P(X > z, Y > z)$
    * 如果 $X, Y$ **独立**：
        * $F_Z(z) = 1 - P(X > z) P(Y > z)$
        * $F_Z(z) = 1 - (1 - F_X(z)) (1 - F_Y(z))$
    * $f_Z(z) = F_Z'(z) = f_X(z)(1-F_Y(z)) + (1-F_X(z))f_Y(z)$ (求导法则)
