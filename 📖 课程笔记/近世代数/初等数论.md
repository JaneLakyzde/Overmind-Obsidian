# 01. 整除理论 (Divisibility Theory)

整除理论是数论的基础，主要研究整数集 $\mathbb{Z}$ 上的整除关系及其性质。

## 一、 公理基础

整除理论的推导依赖于自然数集的两个核心公理。这两个公理在本质上是等价的。

### 公理 1: 归纳公理 (数学归纳法)
> [!abstract] 第一数学归纳法
> 设 $S$ 是自然数集 $\mathbb{N}$ 的一个子集。若 $S$ 满足：
> 1. $1 \in S$ (或起始值 $n_0 \in S$)；
> 2. 若 $k \in S$，则 $k+1 \in S$；
> 则 $S$ 包含所有的自然数 (或所有 $\ge n_0$ 的自然数)。

### 公理 2: 良序原理 (Well-Ordering Principle)
> [!abstract] 定义
> 每个非空的**自然数**子集都有一个最小元素。
> $$\forall S \subseteq \mathbb{N}, S \neq \emptyset \implies \exists m \in S, \forall x \in S, m \le x$$

**注**：良序原理常用于证明“不存在无穷递降序列”，也是证明素数分解存在性的关键。

## 二、 整除的定义与性质

### 1. 定义
设 $a, b$ 为整数，且 $b \neq 0$。
如果存在整数 $c$ 使得 $a = bc$，则称 **$b$ 整除 $a$**，记作 $b \mid a$。
* $b$ 称为 $a$ 的**因子 (Divisor)** 或因数。
* $a$ 称为 $b$ 的**倍数 (Multiple)**。
* $c$ 称为**商**。
* 若 $b$ 不能整除 $a$，记作 $b \nmid a$。

> [!example] 例子
> * $3 \mid 12$，因为 $12 = 3 \times 4$。
> * $3 \nmid 13$，因为不存在整数 $c$ 使 $13 = 3c$。

### 2. 基础性质

#### 1.1 商的唯一性
若 $b \mid a$ 且 $b \neq 0$，则满足 $a=bc$ 的整数 $c$ 是唯一的。
* **解释**：这是整数环无零因子性质的体现。

#### 1.2 传递性 (Transitivity)
若 $a \mid b$ 且 $b \mid c$，则 $a \mid c$。
> [!proof]- 证明
> 设 $b = ax, c = by$ ($x, y \in \mathbb{Z}$)。
> 则 $c = (ax)y = a(xy)$。因为 $xy \in \mathbb{Z}$，所以 $a \mid c$。

#### 1.3 倍数的无穷性
对于任意 $b \neq 0$，$b$ 的倍数有无穷多个（$0, \pm b, \pm 2b, \dots$）。

#### 1.4 显然除数与真除数
对于任意整数 $a \neq 0, \pm 1$：
* **显然因数 (Trivial Divisors)**：$1, -1, a, -a$ 总是 $a$ 的因数。
* **真因数 (Proper Divisors)**：除了显然因数以外的因数。

#### 1.5 整除不等式
若 $b \mid a$ 且 $a \neq 0$，则 $|b| \le |a|$。
> [!info] 重要推论
> 一个正整数 $n$ 的正因数不可能超过 $n$。这是算法中遍历因数时的边界依据。

#### 1.6 整除的线性组合 (Linear Combination)
这是整除理论中最强大的性质之一。
若 $d \mid a$ 且 $d \mid b$，则对于任意整数 $x, y$，有：
$$d \mid (ax + by)$$
> [!proof]- 证明
> 设 $a = dm, b = dn$。
> $ax + by = (dm)x + (dn)y = d(mx + ny)$。
> 因为 $mx+ny$ 是整数，所以 $d \mid (ax+by)$。

## 三、 素数与合数

### 1. 定义
在正整数 $\mathbb{Z}^+$ 中：
* **素数 (Prime)**：一个大于 1 的整数 $p$，如果它的正因数只有 1 和 $p$ 本身，则称 $p$ 为素数。
* **合数 (Composite)**：一个大于 1 的整数 $n$，如果除了 1 和 $n$ 以外还有其他正因数，则称 $n$ 为合数。
* **单位元**：**1 既不是素数也不是合数**。

### 2. 核心定理

#### 定理 1: 最小真因子定理
> [!thm] 定理内容
> 设 $n > 1$ 是合数，则 $n$ 的**最小**正真因数（不为 1 的最小因数）必为素数。
> **推论**：若 $n$ 为合数，则 $n$ 必有一个小于等于 $\sqrt{n}$ 的素因数。

> [!proof] 证明 (推论)
> 设 $n$ 是合数，则 $n$ 必有正真因数。设 $d$ 是 $n$ 的最小正真因数。
> 由定理可知 $d$ 是素数。
> 因为 $d \mid n$，故存在整数 $k$ 使得 $n = dk$。
> 由于 $d$ 是最小的，所以 $k \ge d$。
> 因此 $n = d \cdot k \ge d \cdot d = d^2$，即 $d \le \sqrt{n}$。

> [!task] Homework: Python 实现
> 基于定理 1 的推论，我们可以优化素数判定算法（试除法）。

```python
import math

def is_prime(n: int) -> bool:
    """
    判断整数 n 是否为素数
    时间复杂度: O(sqrt(n))
    """
    if n <= 1:
        return False
    # 2 和 3 是特例
    if n <= 3:
        return True
    # 排除偶数，步长可以加倍
    if n % 2 == 0:
        return False
    
    # 只需要检查到 sqrt(n)
    limit = int(math.isqrt(n))
    
    # 从 3 开始，每次 +2 (只检查奇数)
    for i in range(3, limit + 1, 2):
        if n % i == 0:
            return False
            
    return True

# 测试
print(f"17 is prime? {is_prime(17)}")  # True
print(f"121 is prime? {is_prime(121)}") # False (11*11)
````

#### 定理 2: 素数有无穷多个

这是欧几里得最著名的定理之一。

> [!proof] 证明 (反证法)
> 
> 1. 假设素数只有有限个，设为 {p1​,p2​,…,pk​}。
>     
> 2. 构造一个新的整数 N=p1​p2​…pk​+1。
>     
> 3. 显然 N>1。根据算术基本定理（或定理 1），N 必有一个素因子 q。
>     
> 4. q 必然是 {p1​,…,pk​} 中的某一个。
>     
> 5. 因为 q∣N 且 q∣(p1​…pk​)，根据整除线性组合性质，q 必须整除它们的差： $$ q \mid (N - p_1 \dots p_k) \implies q \mid 1 $$
>     
> 6. q 是素数（q>1），不可能整除 1。矛盾！
>     
> 7. 故假设不成立，素数有无穷多个。
>     

#### 定理 3: 算术基本定理 

> [!thm] 定理内容 任何大于 1 的整数 n 都可以唯一地表示为素数的乘积（不计次序）。 标准分解式：n=p1a1​​p2a2​​…pkak​​

> [!proof] 证明 (存在性部分) **使用归纳公理或良序原理：** 假设存在大于 1 且不能被分解为素数乘积的整数。 根据**良序原理**，必存在一个最小的此类整数 m。
> 
> 1. 若 m 是素数，则 m=m 已经是素数乘积，矛盾。
>     
> 2. 若 m 是合数，则 m=ab，其中 1<a,b<m。
>     
> 3. 由于 a,b 都小于 m，且 m 是“不能分解的最小数”，所以 a 和 b **都能**分解为素数乘积。
>     
> 4. 将 a,b 的分解式相乘，即得到 m 的分解式。矛盾。 故假设不成立，所有 n>1 均可分解。 _(注：唯一性的证明通常需要用到欧几里得引理，即 p∣ab⟹p∣a 或 p∣b)_
>     

#### 定理 4: 带余除法

整除是整数间的一种特殊关系（余数为 0）。带余除法定理告诉我们，对于任意两个整数，即使不能整除，也总能找到一种规范的“除法”表达方式。

### 1. 定理表述
> [!thm] 带余除法定理
> 设 $a, b$ 为整数，且 $b > 0$。
> 则**存在**且**唯一**的整数 $q$ (商) 和 $r$ (余数)，使得：
> $$a = bq + r, \quad 0 \le r < b$$

* **$a$**: 被除数 (Dividend)
* **$b$**: 除数 (Divisor)
* **$q$**: 商 (Quotient)
* **$r$**: 余数 (Remainder) - **关键点：余数必须是非负的**。

### 2. 证明思路
这个证明分为两部分：**存在性**和**唯一性**。

#### (1) 存在性证明 (基于良序原理)
> [!proof]- 证明细节
> 构造集合 $S = \{ a - bk \mid k \in \mathbb{Z}, a - bk \ge 0 \}$。
> 也就是说，这是 $a$ 减去 $b$ 的倍数后，所有非负结果的集合。
> 
> 1.  **S 非空**：
>     * 若 $a \ge 0$，取 $k=0$，则 $a \in S$。
>     * 若 $a < 0$，取 $k = a$ (因为 $b \ge 1$)，则 $a - ba = a(1-b) \ge 0$，故 $S$ 非空。
> 2.  **应用良序原理**：
>     根据公理 2，$S$ 中必有一个**最小元素**，记为 $r$。
>     设对应的 $k$ 为 $q$，即 $r = a - bq$。
>     此时已满足 $a = bq + r$ 且 $r \ge 0$。
> 3.  **证明 $r < b$**：
>     假设 $r \ge b$，则 $r - b \ge 0$。
>     $r - b = (a - bq) - b = a - b(q+1)$。
>     这意味着 $r-b$ 也属于集合 $S$。
>     但 $r-b < r$，这与 $r$ 是 $S$ 中的最小元素矛盾！
>     
>     $\therefore$ 假设不成立，必须有 $r < b$。

#### (2) 唯一性证明 (反证法)
> [!proof]- 证明细节
> 假设存在两组不同的商和余数 $(q, r)$ 和 $(q', r')$ 满足条件：
> $a = bq + r = bq' + r'$，且 $0 \le r, r' < b$。
> 
> 移项得：$b(q - q') = r' - r$。
> 这说明 $b$ 整除 $(r' - r)$。
> 
> 考虑绝对值：$|r' - r|$。
> 因为 $0 \le r, r' < b$，这两个数的距离必然小于 $b$，即 $|r' - r| < b$。
> 
> 既要是 $b$ 的倍数，绝对值又要小于 $b$，唯一的可能是 $|r' - r| = 0$。
> 即 $r = r'$。
> 代回原式，可得 $q = q'$。证毕。
