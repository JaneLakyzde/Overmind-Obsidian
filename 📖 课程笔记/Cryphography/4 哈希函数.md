这两算法虽然在安全性上已经“退役”，但它们的底层架构——**Merkle-Damgård 结构**，依然是理解现代哈希函数（如 SHA-2）的基石。

它们的核心思路是一致的：**分块处理、链接变量、非线性压缩**。

---

## 一、 通用结构：Merkle-Damgård

在深入具体算法前，必须理解它们都遵循的宏构：

1. **消息填充**：使消息长度符合 512 bit 的倍数。
    
2. **初始向量 (IV)**：预设的一组寄存器初始值。
    
3. **压缩函数**：将 512 bit 的消息块与当前的链接变量混合，输出新的链接变量。
    

---

## 二、 MD5 算法实现细节

MD5 将消息处理为 512 bit 的分组，每个分组又分为 16 个 32 bit 的子分组。其核心逻辑由 **4 轮循环**组成，每轮 16 步，共 64 步。

### 1. 初始化 (Initial State)

使用 4 个 32 bit 的寄存器 $A, B, C, D$（小端序存储）：

- $A = 0x67452301$
    
- $B = 0xefcdab89$
    
- $C = 0x98badcfe$
    
- $D = 0x10325476$
    

### 2. 四个非线性函数

每轮使用不同的函数处理数据：

- **第一轮 (F)**：$(X \wedge Y) \vee (\neg X \wedge Z)$
    
- **第二轮 (G)**：$(X \wedge Z) \vee (Y \wedge \neg Z)$
    
- **第三轮 (H)**：$X \oplus Y \oplus Z$
    
- **第四轮 (I)**：$Y \oplus (X \vee \neg Z)$
    

### 3. 核心步函数 (Step Function)

每一步的操作如下（以 $A$ 为例）：

$$A = B + ((A + f(B, C, D) + M[j] + T[i]) \lll s)$$

- $M[j]$：当前消息分组的第 $j$ 个子块。
    
- $T[i]$：基于 $abs(\sin(i))$ 的常数表。
    
- $\lll s$：循环左移 $s$ 位。
    
- **最后**：将 $A, B, C, D$ 的结果与上一个分组的输出相加（模 $2^{32}$）。
    

---

## 三、 SHA-1 算法实现细节

SHA-1 的设计深受 MD5 影响，但更加复杂，输出长度增加到 160 bit。它同样处理 512 bit 分组，但核心循环增加到 **80 步**。

### 1. 初始化 (Initial State)

使用 5 个 32 bit 寄存器 $A, B, C, D, E$（**注意：SHA-1 使用大端序**）：

- $A, B, C, D$ 与 MD5 类似，增加 $E = 0xc3d2e1f0$。
    

### 2. 消息扩展 (Message Schedule) — 关键差异

SHA-1 不直接使用原始消息子块，而是将 16 个 32 bit 字扩展为 **80 个字** ($W_0 \sim W_{79}$)：

- 对于 $t < 16$，$W_t = M_t$。
    
- 对于 $t \ge 16$，$W_t = (W_{t-3} \oplus W_{t-8} \oplus W_{t-14} \oplus W_{t-16}) \lll 1$。
    

> **注**：最后的 `lll 1` 是 NSA 后来增加的（SHA-0 到 SHA-1 的进化），正是为了增加非线性，防止早期破解。

### 3. 核心循环

80 步操作分为 4 组（每组 20 步）：

- **逻辑函数**：随组变化（包含与、或、异或、选择函数）。
    
- 步操作：
    
    $$TEMP = (A \lll 5) + f_t(B, C, D) + E + W_t + K_t$$
    
    $$E = D, \quad D = C, \quad C = B \lll 30, \quad B = A, \quad A = TEMP$$

## 四、 MD5 vs SHA-1：为什么它们先后倒下？

|**特性**|**MD5**|**SHA-1**|
|---|---|---|
|**摘要长度**|128 bit|160 bit|
|**计算步骤**|64 步|80 步|
|**字节序**|小端序 (Little-endian)|大端序 (Big-endian)|
|**抗碰撞攻击**|**完全崩溃**。普通电脑秒级产生碰撞。|**已被攻破**。Google 已演示生成两份不同 PDF 但 SHA-1 相同。|
|**王小云教授贡献**|发现了 MD5 差分路径，使其破解从理论变为现实。|提出了类似的模差分分析法，极大降低了寻找碰撞的复杂度。|

### 💡 核心弱点

它们都属于 **Merkle-Damgård** 结构，这种结构的通病是：

1. **长度扩展攻击**：给定 $H(M)$，攻击者可以在不知道 $M$ 的情况下计算出 $H(M \| \text{padding} \| M')$。
    
2. **迭代结构的脆弱性**：一旦找到压缩函数的碰撞，整个算法就彻底失效。

### ## 现状与建议

- **MD5**：绝对不能用于存储密码或签名。目前仅能在对安全性无要求的场景（如判断两个大文件是否极大概率相同）下作为快速校验使用。
    
- **SHA-1**：各大浏览器已停止信任 SHA-1 证书。
    
- **推荐**：
    
    - **SHA-256 / SHA-512**：目前工业界的标准。
        
    - **SHA-3**：采用了完全不同的 **海绵结构 (Sponge Construction)**，天然免疫长度扩展攻击，是未来的防御重点。
