## 1. 一阶逻辑基本概念

### 1.1 命题逻辑的局限性
> [!NOTE] 为什么要引入一阶逻辑？
> **命题逻辑 (Propositional Logic)** 将简单命题作为原子，无法深入分析命题的**内部结构**（如主语和谓语的关系）以及**数量关系**（如"所有"、"存在"）。
> * *例子*：在命题逻辑中，“苏格拉底是人”只是一个原子命题 $p$，“所有人都会死”是另一个原子命题 $q$。我们无法推导出“苏格拉底会死”。
> * **一阶逻辑 (First-Order Logic, FOL)**：亦称**谓词逻辑 (Predicate Logic)**，通过引入个体、谓词和量词来解决这一问题。

### 1.2 个体词、谓词与量词 (Individuals, Predicates, Quantifiers)

#### 个体词 (Individual)
表示研究对象中可以独立存在的具体或抽象客体。
* **个体常项 (Individual Constant)**：表示特定个体的符号，通常用小写字母 $a, b, c$ 表示。
    * *例*：$a$: 张三, $b$: 2.
* **个体变项 (Individual Variable)**：表示泛指个体的符号，通常用小写字母 $x, y, z$ 表示。
* **个体域 (Domain of Discourse/Individual Domain)**：个体变项的取值范围，记为 $D$。
    * **有限个体域**：$D = \{a, b, c\}$
    * **无限个体域**：$D = \mathbb{N}$ (自然数集)
    * **全总个体域 (Universal Domain)**：包含所有可能事物的集合。
        * *注意*：使用全总个体域时，必须引入特性谓词（如 $M(x)$: $x$ 是人）来限制范围。

#### 谓词 (Predicate)
用来刻画个体性质或个体间关系的词。
* **谓词常项**：表示具体性质或关系的符号，如 $F(x)$ 表示 "$x$ 是父亲"。
* **谓词变项**：表示抽象性质或关系的符号。
* **元数 (Arity)**：
    * **一元谓词**：$P(x)$，表示性质（如 "$x$ 是偶数"）。
    * **$n$ 元谓词**：$L(x, y)$，表示关系（如 "$x$ 喜欢 $y$"）。

#### 量词 (Quantifier)
表示个体数量特征的词。
* **全称量词 (Universal Quantifier)**：$\forall$ (For All)。
    * $\forall x P(x)$：对于个体域中的所有 $x$，$P(x)$ 都成立。
* **存在量词 (Existential Quantifier)**：$\exists$ (Exists)。
    * $\exists x P(x)$：个体域中存在（至少有一个）$x$，使得 $P(x)$ 成立。

### 1.3 一阶逻辑命题符号化 (Symbolization)

> [!WARNING] 符号化黄金法则
> 1.  **全称量词 $\forall$ 通常搭配蕴含词 $\to$**。
>     * "所有的人都会死" $\Rightarrow$ $\forall x (Human(x) \to Mortal(x))$
>     * *错误写法*：$\forall x (Human(x) \wedge Mortal(x))$ (这意味着宇宙万物都是人且都会死)。
> 2.  **存在量词 $\exists$ 通常搭配合取词 $\wedge$**。
>     * "有些人是快乐的" $\Rightarrow$ $\exists x (Human(x) \wedge Happy(x))$
>     * *错误写法*：$\exists x (Human(x) \to Happy(x))$ (如果在空集或有一个不是人的东西，这式子恒真，失去了意义)。

### 1.4 一阶逻辑公式与分类

#### 一阶语言 (First-Order Language)
由字母表（常项、变项、函数符号、谓词符号、量词、联结词、括号）构成的形式语言。

#### 合式公式 (Well-Formed Formula, wff)
符合语法规则的公式。定义如下：
1.  原子公式是合式公式。
2.  若 $A, B$ 是合式公式，则 $\neg A, A \wedge B, A \to B$ 等也是。
3.  若 $A$ 是合式公式，$x$ 是个体变项，则 $\forall x A$ 和 $\exists x A$ 也是。

#### 辖域、指导变元与自由/约束出现
对于公式 $\forall x A$ 或 $\exists x A$：
* **指导变元 (Bound Variable)**：量词后面的变元 $x$。
* **辖域 (Scope)**：量词的作用范围 $A$。
* **约束出现 (Bound Occurrence)**：在辖域中出现的指导变元 $x$。
* **自由出现 (Free Occurrence)**：不被任何量词约束的变元。

> [!EXAMPLE] 实例分析
> 公式：$\forall x (P(x) \to Q(y))$
> * **$\forall x$ 的辖域**：$(P(x) \to Q(y))$
> * **$x$**：是约束变元（被 $\forall x$ 约束）。
> * **$y$**：是自由变元（没有 $\exists y$ 或 $\forall y$ 约束它）。

#### 闭式 (Closed Formula / Sentence)
**不含任何自由变元**的公式。只有闭式才有确定的真值（在给定解释下）。

### 1.5 解释与逻辑类型

#### 一阶语言 $L$ 的解释 (Interpretation)
一个解释 $I$ 包含：
1.  **非空个体域 $D$**。
2.  **映射**：将常项映射为 $D$ 中特定元素，将谓词映射为 $D$ 上的特定关系。

#### 公式的分类
* **永真式 (Valid / Tautology)**：在**任何**解释下真值都为真的公式。亦称逻辑有效式。
    * 例：$\forall x P(x) \to \exists x P(x)$
* **矛盾式 (Contradiction / Unsatisfiable)**：在**任何**解释下真值都为假的公式。
    * 例：$\forall x P(x) \wedge \exists x \neg P(x)$
* **可满足式 (Satisfiable)**：**至少存在一个**解释使得公式为真。
    * *注*：永真式一定是可满足式。

#### 代换实例 (Substitution Instance)
如果将命题逻辑中的重言式（如 $P \vee \neg P$）中的命题变项 $P$ 用一阶逻辑公式 $A$ 替换，得到的 $\Phi = A \vee \neg A$ 是一阶逻辑的永真式。

## 2. 一阶逻辑等值演算

### 2.1 等值式与基本规则
如果公式 $A$ 和 $B$ 在任何解释下真值都相同，称 $A$ 与 $B$ 等值，记为 $A \Leftrightarrow B$。

### 2.2 基本等值式 (Key Equivalences)

#### 1. 量词否定律 (De Morgan's Laws for Quantifiers)
量词穿过否定号时要变身。
* $\neg \forall x P(x) \Leftrightarrow \exists x \neg P(x)$
* $\neg \exists x P(x) \Leftrightarrow \forall x \neg P(x)$

#### 2. 量词辖域的扩张与收缩
假设 $Q$ 中**不含**自由变元 $x$（即 $x$ 对 $Q$ 没影响）：
* $\forall x (P(x) \vee Q) \Leftrightarrow (\forall x P(x)) \vee Q$
* $\forall x (P(x) \wedge Q) \Leftrightarrow (\forall x P(x)) \wedge Q$
* $\exists x (P(x) \vee Q) \Leftrightarrow (\exists x P(x)) \vee Q$
* $\exists x (P(x) \wedge Q) \Leftrightarrow (\exists x P(x)) \wedge Q$
* **蕴含式的特殊情况**（注意变号）：
    * $\forall x (P(x) \to Q) \Leftrightarrow (\exists x P(x)) \to Q$ （前件提出来，量词翻转）
    * $\forall x (Q \to P(x)) \Leftrightarrow Q \to (\forall x P(x))$ （后件提出来，量词不变）

#### 3. 量词分配律
* **$\forall$ 对 $\wedge$ 可分配**：$\forall x (P(x) \wedge Q(x)) \Leftrightarrow \forall x P(x) \wedge \forall x Q(x)$
* **$\exists$ 对 $\vee$ 可分配**：$\exists x (P(x) \vee Q(x)) \Leftrightarrow \exists x P(x) \vee \exists x Q(x)$
* > [!DANGER] 注意
    > $\forall$ 对 $\vee$ **不可**分配：$\forall x (P(x) \vee Q(x)) \not\Leftrightarrow \forall x P(x) \vee \forall x Q(x)$
    > *反例*：整数域，$P(x): x$是偶数，$Q(x): x$是奇数。左边为真，右边为假。

### 2.3 变形规则

1.  **置换规则 (Rule of Substitution)**：用等值公式替换子公式，原公式真值不变。
2.  **换名规则 (Rule of Renaming)**：
    * $\forall x P(x) \Leftrightarrow \forall y P(y)$
    * **目的**：避免变量名冲突。
    * **限制**：新变量 $y$ 不能在 $P(x)$ 中自由出现。
3.  **代入规则**：针对永真式的自由变元进行代换。

### 2.4 前束范式 (Prenex Normal Form)

**定义**：一个公式具有如下形式：
$$Q_1 x_1 Q_2 x_2 \dots Q_k x_k M$$
其中 $Q_i$ 是量词 ($\forall$ 或 $\exists$)，$M$ 是不含量词的公式（称为母式）。
简而言之：**所有量词都提到最前面，辖域延伸到整个公式**。

> [!EXAMPLE] 化前束范式步骤例题
> 将公式 $F = \forall x P(x) \to \exists x Q(x)$ 化为前束范式。
>
> 1.  **换名**（防止变元冲突）：
>     $$\forall x P(x) \to \exists y Q(y)$$
> 2.  **消去蕴含**（$A \to B \Leftrightarrow \neg A \vee B$）：
>     $$\neg \forall x P(x) \vee \exists y Q(y)$$
> 3.  **量词内移/否定深入**：
>     $$\exists x \neg P(x) \vee \exists y Q(y)$$
> 4.  **量词左移**（辖域扩张）：
>     $$\exists x (\neg P(x) \vee \exists y Q(y))$$
>     $$\exists x \exists y (\neg P(x) \vee Q(y))$$
> **结果**：$\exists x \exists y (\neg P(x) \vee Q(y))$ 就是前束范式。
