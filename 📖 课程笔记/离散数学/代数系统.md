## 1. 二元运算及其性质 (Binary Operations and Their Properties)

### 1.1. 运算的定义

- **二元运算 (Binary Operation)**
  - **定义**: 设 `S` 是一个非空集合，一个从 `S × S` 到 `S` 的函数 `*` 被称为集合 `S` 上的一个二元运算。
  - **关键点**:
    - **输入**: 两个来自集合 `S` 的元素。
    - **输出**: 一个**仍然属于**集合 `S` 的元素。
    - 这个“输出仍在集合S内”的特性，就是运算的**封闭性 (Closure)**。因此，封闭性是二元运算的**内在属性**。
  - **实例**:
    - 整数集 `ℤ` 上的加法 `+` 是二元运算，因为任意两个整数相加结果还是整数。
    - 整数集 `ℤ` 上的除法 `÷` **不是**二元运算，因为 `1 ÷ 2 = 0.5`，结果不属于 `ℤ`，不满足封闭性。

- **一元运算 (Unary Operation)**
  - **定义**: 一个从 `S` 到 `S` 的函数被称为集合 `S` 上的一元运算。
  - **实例**:
    - 实数集 `ℝ` 上的取负 `-` 是一元运算。
    - 逻辑代数中，对布尔值取非 `¬` 是一元运算。

### 1.2. 运算的表示

对于元素个数有限的集合，其上的二元运算可以用**运算表 (Operation Table)** 或 **凯莱表 (Cayley Table)** 来直观表示。一个好的运算表不仅能定义运算，还能帮助我们快速判断其性质。

**例题：整数模3加法**

- **代数系统**: `<S, +₃>`
- **集合**: `S = {0, 1, 2}`
- **运算**: `a +₃ b = (a + b) mod 3`

**运算表**:

| **+₃** | **0** | **1** | **2** |
| ------ | ----- | ----- | ----- |
| **0**  | 0     | 1     | 2     |
| **1**  | 1     | 2     | 0     |
| **2**  | 2     | 0     | 1     |

---
##### 如何通过运算表分析性质

这个运算表比之前的例子更具代表性，我们可以从中直观地分析出很多性质：

1. **封闭性 (Closure)**
    - **观察**: 表格中的所有运算结果（0, 1, 2）都属于集合 `S`。
    - **结论**: 运算 `+₃` 在 `S` 上是封闭的。
        
2. **单位元 (Identity Element)**
    - **观察**: 第 **0** 行和第 **0** 列的内容，与表头和行头完全一致 (`0+a=a`, `a+0=a`)。
    - **结论**: `0` 是这个代数系统的单位元。
        
3. **逆元 (Inverse Element)**
    - **观察**: 在每一行和每一列中寻找单位元 `0`。
        - `0 + 0 = 0` => 0的逆元是0。
        - `1 + 2 = 0` => 1的逆元是2。
        - `2 + 1 = 0` => 2的逆元是1。
    - **结论**: 集合 `S` 中的每个元素都存在逆元。
        
4. **交换律 (Commutativity)**
    - **观察**: 整个表格**沿主对角线（左上到右下）对称**。例如，`1+₂` 的值（为0）和 `2+₁` 的值（也为0）是相同的。
    - **结论**: 运算 `+₃` 满足交换律。
        

总结：
通过这张清晰的运算表，我们可以得出 <{0, 1, 2}, +₃> 不仅是一个代数系统，它还是一个阿贝尔群 (Abelian Group)，因为它满足封闭性、结合律（整数加法本身满足）、有单位元、所有元素都有逆元，并且满足交换律。

### 1.3. 二元运算的性质

设 `*` 是集合 `S` 上的一个二元运算，其常见性质如下：
- **封闭性（Closure）**
- 定义：一个运算 `*` 在集合 `S` 上是**封闭**的，意味着对于_任意_ `a, b ∈ S`，其运算结果 `a * b` 仍然属于 `S`。
- 反例：自然数集减法、整数集除法、奇数集加法、二维向量叉乘

- **结合律 (Associativity)**
- 定义: 对任意 `a, b, c ∈ S`，都有 `(a * b) * c = a * (b * c)`。
- 实例: 整数加法满足，整数减法不满足。

- **交换律 (Commutativity)**
- **定义**: 对任意 `a, b ∈ S`，都有 `a * b = b * a`。
- **实例**: 实数乘法 `×` 满足交换律。矩阵乘法 **不**满足。

- **单位元 (Identity Element)**
- **定义**: 存在一个元素 `e ∈ S`，对任意 `a ∈ S`，都有 `e * a = a * e = a`。`e` 称为单位元。
- **注意**: 单位元是唯一的。
- **实例**:
	`<ℤ, +>` 的单位元是 `0`。
	`<ℝ, ×>` 的单位元是 `1`。
	某集合 `A` 的幂集 `<P(A), ∪>` 的单位元是空集 `∅`。

- **逆元 (Inverse Element)**
- 定义: 若 `S` 上存在单位元 `e`，对于某个元素 `a ∈ S`，如果存在一个元素 `b ∈ S` 使得 `a * b = b * a = e`，则称 `b` 是 `a` 的逆元，记作 `a⁻¹`。
- 实例:
	在 $<ℤ, +>$ 中，`5` 的逆元是 `-5`。
	在 $<ℚ-{0}, ×>$ 中，`5` 的逆元是 `1/5`。
	在 $<ℤ-{0}, ×>$ 中，`5` 没有逆元。

- **幂等律 (Idempotence)**
- 定义: 对任意 `a ∈ S`，都有 `a * a = a`。
- 实例: 逻辑运算 `∧` 和 `∨` 都满足幂等律，如 `p ∧ p = p`。

- **零元 (Zero / Annihilating Element)**
- 定义: 存在一个元素 `z ∈ S`，对任意 `a ∈ S`，都有 `z * a = a * z = z`。`z` 称为零元。
- 实例:
	`<ℤ, ×>` 的零元是 `0`。
	某集合 `A` 的幂集 `<P(A), ∩>` 的零元是空集 `∅`。

## 2. 代数系统 (Algebraic System)

- **定义**: 一个非空集合 `S` 与 `S` 上的 `k` 个一元或二元运算 `f₁, f₂, ..., fₖ` 所组成的系统，称为一个代数系统。
- **记法**: `<S, f₁, f₂, ..., fₖ>`。
- **实例**:
- `<ℤ, +>`: 整数集与加法运算构成一个代数系统。
- `<ℝ, +, ×>`: 实数集与加法、乘法运算构成一个代数系统。
- `<B, ∧, ∨, ¬>`: 布尔代数，`B={0,1}`。

### 2.1. 子代数与同态
[[群论｜同态与同构]]
- **子代数系统 (Subalgebra)**
- **定义**: 设 `<A, *>` 是一个代数系统，`B` 是 `A` 的一个非空子集。如果 `B` 在 `*` 运算下是封闭的（即对任意 `x, y ∈ B`，`x * y` 仍然在 `B` 中），那么 `<B, *>` 就被称为 `<A, *>` 的子代数系统。
- **实例**: 偶数集和加法 `<𝔼, +>` 是整数集和加法 `<ℤ, +>` 的子代数。

- **同态 (Homomorphism)**
- **定义**: 设有 `<A, *>` 和 `<B, ∘>` 两个代数系统，一个从 `A` 到 `B` 的映射 `f: A → B` 
	如果保持运算结构，即对任意 `a, b ∈ A`，都有 `f(a * b) = f(a) ∘ f(b)`，则称 `f` 为一个同态映射。
- **核心思想**: 运算的结构被"保持"或"模拟"了。
- **实例**: `f(x) = 2ˣ` 是从 `<ℝ, +>` 到 `<ℝ⁺, ×>` 的同态映射，因为 `f(x + y) = 2ˣ⁺ʸ = 2ˣ × 2ʸ = f(x) × f(y)`。
- 自同态：映射的起点和终点是同一个代数系统


- **同构 (Isomorphism)**
- **定义**: 如果一个同态映射 `f` 既是单射又是满射（即双射），则称 `f` 为一个同构映射。此时称 `<A, *>` 与 `<B, ∘>` 同构。
- **核心思想**: 两个代数系统在结构上是**完全相同**的，只是元素的"名字"不同。

## 3. 几个典型的代数系统

代数系统根据其运算满足的性质可以进行分类，形成一个层次结构。

| 代数系统名称 (英文名) | 结构 | 必须满足的性质 | 实例 |
| :--- | :--- | :--- | :--- |
| **广群 (Magma/Groupoid)** | `<S, *>` | 封闭性 | `<ℤ, ->` (整数减法) |
| **半群 (Semigroup)** | `<S, *>` | 封闭性 + **结合律** | `<ℤ⁺, +>` (正整数加法) |
| **独异点 (Monoid)** | `<S, *>` | 半群 + **存在单位元** | `<ℕ, +>` (自然数加法，含0) |
| **群 (Group)** | `<S, *>` | 独异点 + **每个元素都有逆元** | `<ℤ, +>`, `<ℚ-{0}, ×>` |
| **阿贝尔群 (Abelian Group)** | `<S, *>` | 群 + **交换律** | `<ℤ, +>`, `<ℝ, +>` |

### 详细解释

- **半群 (Semigroup)**
- 运算满足结合律，这是最基本也最重要的性质之一。它保证了表达式 `a * b * c` 的值是唯一的，无需括号。
- **实例**: 所有字符串的集合与字符串连接运算构成一个半群。

- **独异点 (Monoid)**
- 在半群的基础上增加了单位元。单位元像是一个运算的"起点"或"中性"元素。
- **实例**:
  - `<ℕ, ×>` (自然数乘法)，单位元是 `1`。
  - 字符串集合与连接运算，单位元是空字符串 `""`。

- **群 (Group)**
- 群是代数系统中结构最丰富、性质最优美的系统之一。它要求在独异点的基础上，每个元素都必须是"可逆的"。
- **群的四个公理 (G1-G4)**:
  1.  **封闭性**: `a, b ∈ G ⇒ a * b ∈ G`
  2.  **结合律**: `(a * b) * c = a * (b * c)`
  3.  **单位元**: `∃e ∈ G, ∀a ∈ G, a * e = e * a = a`
  4.  **逆元**: `∀a ∈ G, ∃a⁻¹ ∈ G, a * a⁻¹ = a⁻¹ * a = e`
- **实例**:
  - 整数集与加法 `<ℤ, +>` 是一个阿贝尔群。
  - 非零有理数集与乘法 `<ℚ-{0}, ×>` 是一个阿贝尔群。
  - 2x2的可逆实数矩阵集合与矩阵乘法构成一个**非**阿贝尔群。
